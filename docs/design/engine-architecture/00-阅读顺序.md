```text
热更新当前实现基线按 201 理解：当前没有完整线上热更；IR hotfix / Project UI Hot Logic WASM 是后续目标。
IR 只存在于 Contract-bound RuleSlot 中，是受限规则数据，不是脚本语言。
复杂算法、系统框架、事务原语和复杂 UI 交互机制默认用 Rust。
固定 Contract 内的受限业务交易编排可以进入 IR RuleSlot 热更。
AUI Document 是 UI 结构真相；AUI Runtime Core 用 Rust；Binding 只读 ProjectUiStateSnapshot。
AUI 可视化编辑以 209 为准：不新增独立 AUI Designer，不新增 AUI 专用编辑模式，Scene / Hierarchy / Inspector 是统一 authoring surface。
复杂 AUI 控件复用以 211 为准：用户体验可以像 Prefab，自由组合 AUI subtree；工程真相仍是 AUI Document subtree，不把一个 AuiNode 当成 GameObject Component 容器。
ScreenCamera / WorldSpace AUI 只是长期 schema 预留；当前可执行 authoring / render domain 不把它们当成已支持能力。
System Blueprint 旧称按 System Contract / Gameplay System Contract 理解，不按 UE Blueprint 式节点脚本理解。
Feature Folder 只作为编辑期组织和 AI patch scope，不是新的运行时层。
```
