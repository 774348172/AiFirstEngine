
## 4. P0 必须优先解决的问题

### Q1：真实用户级闭环没有被稳定验收

来源：

```text
148 第 8 节：真实用户级闭环没有被稳定验收。
```

问题说明：

```text
目前很多系统已经通过 headless 测试和模块测试。
但还没有一个稳定的真实项目证明：
编辑器编辑 -> 保存 -> 构建 -> 导出 -> 打开 player -> 输入 -> 渲染 -> 报告
整条链路持续可用。
```

为什么重要：

```text
这是能否做出复杂打飞机 Windows 可玩项目的核心门槛。
如果没有这条闭环，继续补单点能力会让工程看起来很强，但用户仍然无法得到可玩的游戏。
```

建议下一步讨论：

```text
Complex Shooter Real Project End-to-End Gate v1
```

应覆盖：

```text
headless golden
native window smoke
exported package gate
AI-readable report
```

```text
editor_ui_model 按 launcher / workspace / panels / commands / diagnostics / assets / inspector / viewport 拆文件。
editor_ui_renderer 按 layout / panels / hit_test / draw_commands / text / theme 拆文件。
editor_wgpu_renderer 按 render_graph / draw_plan / font_system / texture_atlas / headless / real_wgpu 拆文件。
行为不变，测试不减少。
```

### Q20：测试保护网充足但集中在大文件内部

现状：

建议：

