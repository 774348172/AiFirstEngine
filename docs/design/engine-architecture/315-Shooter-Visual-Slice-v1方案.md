# 315 打飞机可试玩视觉样例

用户确认按314后的建议施工：统一飞机/敌机/背景/子弹美术、显示比例、HUD与开火/命中/爆炸反馈，实际窗口验收。
本次是项目表现层施工，复用已验证的Sprite/AUI/Prefab/延迟mutation能力，不重做Renderer，不增工具。
素材优先风格统一且许可明确的现成素材；当前内置image_gen不可用，不自行调用收费API。素材原图、许可和来源保留于项目。
保留既有Asset ID，替换sourceImage到清晰素材；新反馈资源用正式asset/prefab进入Compiler。旧8像素图留作历史，不手改RuntimePackage。
项目侧使用短生命周期Prefab表达枪口闪光/爆炸，生命周期规则控制缩放与清理；HUD保持只读binding和非交互覆盖。
目标是一屏可审查的视觉样例，不承诺完整关卡、音频、性能、粒子系统或其它平台。核心引擎若出现新失败先定向诊断再决定是否必要修复。

实际新素材暴露两处必修呈现缺陷：Player纹理收集漏Prefab依赖、GPU纹理上传忽略sRGB。315将其纳入现有owner最小修复；保留纯RGBA线性上传用于字体等既有consumer，cooked纹理按明确format上传。项目分数字体采用可正确呈现的24px，28px路径记录后续缺口。
