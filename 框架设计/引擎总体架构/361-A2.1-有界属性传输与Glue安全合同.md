# 361 A2.1：有界属性传输与Glue安全合同

日期：2026-09-24。承接[A1常驻属性](361-A1-typed控件与常驻属性实际合同.md)。本段实现模块侧缓冲、序列化及真实实例consumer；尚未把生产会话自动接到此consumer，不能视为A2完成或塔防已提速。

## 所有权与调用

`UiTextRef`等现有typed引用不变。新增SDK内部`UiWriteBuffer<R: UiRead>`承接setter，按句柄/属性覆盖合并；getter优先读本段写入。每个访问节点最多缓存一次类型查询，缓存最多4096节点，重复setter不逐次调用host。读未修改属性仍由reader提供；普通setter不生成全树快照。

段内写失败清空全部pending并保留首个错误，后续读写及finish失败。丢弃buffer不改变宿主。finish由后续Glue消费，不要求项目手工维护delta、revision或调用引擎commit。当前buffer并未比较宿主原值，因此可能发送同值属性；已有AuiEdit在宿主侧剔除同值及恢复原值后的无效写，不能把此段描述为“同值零传输”。

`UiUpdateBatch`只允许经校验构造或解码。引擎`AuiInstance::apply_update_batch`复用已有独占AuiEdit，重新验证全部句柄、节点类型、binding所有权和容量，一次提交。任何晚到错误都丢弃前面的暂存写，不留下失效队列。绑定冲突目前在宿主提交点返回，不保证模块setter即时发现。

此consumer一次仅处理一个实例；跨实例句柄拒绝。多个实例跨回调的宿主编排由A2.2决定，不能循环调用本方法冒充跨实例原子提交。reader须在本次回调中保持身份稳定，结构事件屏障在C实施。

## 传输合同

JSON UTF-8只作为内部字节载荷，Rust对象/集合/trait不跨ABI。没有为本段增加新的C函数表字段。

| 字段/上限 | 合同 |
| --- | --- |
| version | 精确为1，拒绝其它值 |
| updates | `(handle, property, value)`数组；同一handle/property不得重复 |
| handle | instance:u64、slot:u32、generation:u32；源资产ID不替代运行实例身份 |
| property/value | text/Text、translation/有限二维f32、interactable/Bool、visibility/Visible或Hidden或Collapsed；JSON枚举名camelCase |
| 属性数 | 最多4096；数组解码过程中限制增长 |
| 文本 | 最多256KiB原始UTF-8总和；替换值释放旧预算 |
| 编码总量 | 最多4MiB；解码前检查；覆盖控制字符最坏6倍JSON转义及属性元数据 |
| 无效输入 | 未知字段、错类型、重复属性、非有限数值、过期/串实例句柄、绑定冲突均拒绝 |

边界解码错误使用紧凑UiError（非法payload为InvalidValue，解码前字节超限为CapacityExceeded）；serde解码期间的数量/文本超限归为InvalidValue。引擎错误保留相应handle/property，不在热路径生成长诊断。

`UI_UPDATE_SCHEMA`纳入既有`project_runtime_contract_digest`；ABI布局与major/minor保持原值，因为没有改变函数表。新旧SDK合同摘要不同，既有host摘要检查会拒绝错配，新源码交付必须重新派生Glue/项目模块，不能复用旧模块冒充兼容。

## FFI安全修复

`ffi_boundary_with_capacity_floor`改为unsafe函数，并明确descriptor、backing storage及独占借用的调用方义务。空指针仍返回InvalidArgument；不足缓冲在进入项目回调之前返回BufferTooSmall；panic仍由既有边界截获。

生成模板的rule/AUI/fixed/lifecycle四个调用点分别建立闭包，再通过显式unsafe调用该辅助函数；没有增加allow压制Clippy，也未手改生成产物。原先256KiB回调输出容量不变。4MiB上限的UI批次不能塞入它；A2.2必须使用独立有界host传输或另行校验的输出设计，并在宿主接受回调后才提交UI。

## 接续与验证边界

A2.2仍须实现HostApi访问、会话挂载与销毁、GameCallContext UI入口、自动提交/丢弃、生成typed view refs、真实模块加载验收；尤其要验证callback错误、panic、输出不足及宿主拒绝时不残留UI更新。此段直接调用apply_update_batch的源码测试不是这些生产链证据。

B–E仍负责增量布局/呈现、事件扩展、真实项目和性能。生成Glue现有编译测试是实际生成代码的rlib ABI调用，不是DLL动态加载、更不是窗口证据。执行结果见[A2.1记录](施工文档/证据/361/A2.1-执行记录.md)。
