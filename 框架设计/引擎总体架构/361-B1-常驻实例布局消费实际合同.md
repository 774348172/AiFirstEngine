# 361 B1 常驻实例布局消费实际合同

日期：2026-09-25。承接A1/A2的常驻属性与成功提交边界，复用原AuiLayoutSolver/Taffy算法。本段只完成基础布局消费，B及361整体未完成。

## 实际接口与owner

`AuiInstance::layout(canvas, measure)`消费已提交属性，返回借用的`AuiLayoutSnapshot`。`layout_snapshot`可读取最近成功几何，`layout_stats`读取最近布局调用计数；`AuiSession::layout_document(document, canvas, measure)`提供会话层消费，不公开任意修改实例的方法。项目SDK/ABI不变化，普通项目仍通过typed setter操作。

源AuiDocument在mount时校验，随后只读。实例按合法canvas惰性持有原solver；首次消费从静态源构造树，并应用此前已提交的属性。后续文本/visibility提交通过slot更新已有运行节点，按节点去重登记失效，不查找字符串节点、不比较或clone整份源文档。布局消费独立于paint/hit invalidation队列，不能提前吞掉后续呈现所需工作。

| 变化 | B1布局行为 |
| --- | --- |
| clean/同值赋值 | 直接借用已有snapshot，不validate/扫描源节点、不measure、不收集几何 |
| Text | 更新单节点运行文字，清除该节点到根的必要缓存；原Taffy复用无关子树 |
| Visible↔Hidden | 不重算基础布局，更新snapshot局部显隐字段；仍保留占位 |
| 进入/离开Collapsed | 更新原Taffy display，重新计算受影响布局，恢复后尺寸正确 |
| Translation/Interactable | 基础布局不变；transform/style/paint/hit脏标记留后续consumer |
| 未提交/失败/被宿主拒绝的写入 | 布局不更新 |

固定尺寸父节点下文字变化不能导致无关文本重新measure；内容尺寸父节点必须传播大小与兄弟位置。B1仍清除受影响祖先缓存，未声称严格固定子树dirty根截断或全链O(变化量)。

## 计数、失败与生命周期

`AuiLayoutStats`增加文档校验、源节点装载、去重属性更新及几何收集计数。`visited_nodes`改为实际Taffy compute调用次数（包括缓存探测），不再通过扫描reachable节点计数；不是去重节点数。成功的clean调用各工作计数为0。首次布局装载整树；有变化时仍收集整个当前canvas的几何snapshot，这项O(N)明确留到后续B阶段。

失败测量/预算超限不安装半份snapshot；保留最近一次成功几何，首次失败无有效snapshot。错误路径清除可能受错误测量污染的Taffy缓存；retained失效集合保留，后续正确测量可重试。该错误恢复不宣称已经实现C的自定义控件8轮调度及故障子树隔离。

多个canvas分别缓存；迟到的canvas第一次消费也必须看到已提交状态。多个实例彼此隔离；dispose清除全部layout缓存。内存上限按实例当前节点数×已消费canvas数量增长，不保存历史revision。单canvas源树中的不可达节点目前仍占初始化存储，后续可优化；失败清cache允许O(N)，不属于clean热路径。

ProjectRuntimeSession原合同要求Send。Taffy 0.12.2的普通尺寸内部使用tagged pointer导致无法自动Send；私有RuntimeTree采用带安全说明的Send实现：所有Style只由本owner纯数值schema构造，未存储外部Style、calc指针、借用或回调，移动后仍独占访问。没有增加Sync或跨线程并发UI写入口。测试验证已挂载solver随独占owner移动后继续正确布局。

## 当前边界与下一段

B1的measurer外部字体/样式输入必须在该布局生命期保持稳定；动态字体、主题和viewport/DPI依赖失效属于后续接线，不可仅换measurer期待clean缓存自动发现变化。返回的是post-layout translation之前的基础矩形与局部visibility，不是最终world变换/clip/hit结果。

Player/Editor生产Presenter仍走原文档输入，尚未消费本入口；原入口的整树比较/校验也尚未删除。下一段继续贯通常驻文字/几何/transform/clip/hit和UiProjection，之后替换旧入口而非长期维护双生产实现。源码headless通过不能证明当前塔防已提速、真实窗口或GPU上传已增量。
