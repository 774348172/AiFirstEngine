# 361 B5 位移子树几何与文字复用实际合同

日期：2026-09-25。属于361 R2 Gate B；施工与验证见[执行记录](施工文档/证据/361/B5-执行记录.md)，当前源码和安装状态只见49/54。

## 实际链路

`AuiInstance已提交translation → Player/Editor共用AuiPresentCache → AuiC2Runtime → 原AuiLayoutResult → 原绘制/命中consumer`。

C2 owner保留最近成功输入的一份基础几何、一份当前几何和最终文字段落；新私有`aui_geometry_cache`只负责布局后的位移及继承裁剪，不新增solver、公开项目接口或渲染路径。源文档与真实字体集合身份不变时跳过solver、snapshot汇总和全树几何重建。原legacy路径保持。

几何索引在基础布局成功后建立，parent/children/clip owner以canvas+node定位；一个源树用于多个画布时分别处理其几何。源node ID映射到全部画布slot。对变化translation及撤销的translation收集后代，以父先子后的顺序去重更新；原始矩形加当前绝对累计位移，避免反复拖动累积误差。裁剪形状和半径、可见性、可见/裁剪统计及已有滚动条矩形同步更新。绘制和命中继续读取相同layout，不创建独立命中几何真相。

最终段落保持共享身份。移动不改变段落宽高，不请求已有段落的缓存查询或shaping。没有文字的控件也记录已完成的空文字状态，避免移动时反复建立paragraph context。尚未最终排版的文字从裁剪区移入时，按原paragraph owner补齐最终段落；不能把固有尺寸测量段落误当最终绘制段落。字体默认ID或集合共享身份变化时，丢弃几何、solver测量和paragraph缓存，防止公开COW资源替换沿用旧结果。失败布局/段落不安装成功几何缓存。

## 计数与边界

`AuiC2Runtime::geometry_update_stats()`返回紧凑的`base_reused`与`nodes_updated`；后者指本次处理的几何slot数，初次/失效重建为全部slot数，位移复用为受影响slot数，同值为0，不代表整条呈现链的扫描总量。`layout_stats(canvas)`在几何快路径返回clean和零solver工作；paragraph计数不增加证明连缓存查询也跳过。

缓存只保存当前输入，不累积历史revision；几何、索引和保留段落数量随当前文档/画布规模受限，旧输入被替换或runtime丢弃即释放。最终段落强引用可能使已移出裁剪区的本树文字继续驻留；不是全局paragraph LRU字节预算内的零成本引用。

本块没有完成整个B：观察已拥有typed属性、binding/theme/viewport适配、C2源文档比较、返回Vec/Map复制仍有全量成本；尺寸/文字/主题变化仍走现有全量基础几何汇总；变化帧draw/glyph组装、反馈主题处理和整stage投影仍待局部化；命中查询仍按既有实现筛选，不宣称空间索引完成。新缓存优化的是纯位移下几何与段落重建，不宣称整个更新链O(变化量)、零分配或游戏FPS达标。

## 验证要求

1000个静止兄弟节点场景中，叶节点位移更新1个slot、父与子同时变化更新2个slot，同值更新0个；测量/solver几何汇总/paragraph查询为0。与新runtime从头重建比较完整layout、clip、overlay/glyph及命中；覆盖移出/恢复、重复运动、dispose撤销、双画布共享根。真实字体COW失效/失败恢复、文本/尺寸/可见性/viewport既有回归及两端实际缓存入口共同限定本合同。

安装仍为360，旧塔防交付未重建。没有本轮真实窗口、GPU或整帧性能资格；未修改的ABI/Glue/GPU owner证据仅按原身份和原声明范围复用。
