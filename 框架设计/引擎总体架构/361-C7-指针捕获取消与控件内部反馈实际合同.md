# 361 C7：指针捕获/取消与控件内部反馈实际合同

日期：2026-09-28。范围：AUI 指针捕获/取消语义、typed control/显式拖动节点的内部反馈，以及 Player 的真实 winit `CursorLeft` 输入接线。接续[361 总施工文档](施工文档/当前/361-AUI-R2-总施工文档.md) Gate C；执行证据见[C7 记录](施工文档/证据/361/C7-执行记录.md)。本合同不代表塔防迁移、真实窗口观察、性能、安装或 Gate D/E 已完成。

## 1. 单一捕获 owner

primary press、active drag、scroll capture 和 hover 继续由 `AuiInteractionState` 持有，没有新增第二套 capture registry、项目属性或跨 DLL 回调。捕获按 pointer ID 与 device kind 匹配；Button、Toggle、Slider、InputField 及显式 draggable 节点仍走同一命中、路由和业务 action 链。

`PointerLeave` 清除 hover，并把匹配 press 的 `inside` 置为 false，但不释放 press、drag 或 scroll capture。后续 PointerMove 返回原控件可恢复 inside；最终 PointerUp 才按落点决定 Click/Drop。leave 本身不产生 Click、Drop 或项目 action。

`PointerCancel`（包括既有 FocusLost 转换）只清理匹配 capture。press 至多输出一次内部 `PointerCancel`，已经开始的 drag 至多输出一次内部 `DragCancel`，不输出 Click/Drop；重复 cancel 无命令、无 action、无残留状态。显隐、删除/回收、session/scope 变化继续沿既有 reconciliation 回收 transient state，不把生命周期回收伪造成项目业务意图。

## 2. 控件内部反馈

`AuiControlFeedbackModule` 的反馈资格统一为四类 typed control：Button、Toggle、Slider、InputField，以及任意显式 `draggable` 节点。普通 Panel/Text/Image 不因可见、interactable 或命中而自动套用按钮动效；`feedback=none` 仍可显式关闭。

Disabled > Pressed > Hovered > Normal 的优先级、focus/activation 合成、主题 profile、cancel/release 时长、retained node index 和 presentation cache 均保持。非 Button 控件与拖动字牌使用同一内置 profile/项目 profile 解析，不增加节点业务属性、动画 owner 或 GPU 通道；反馈仍只覆盖 presentation visual，不写回项目基础值。

## 3. Player 平台接线

真实窗口 `RealWindowApp` 保存最近一次 `CursorMoved` 的物理像素位置。winit 发出 `WindowEvent::CursorLeft` 时，Player 生成既有 `RawInputEvent::mouse_leave` 并立即请求 redraw；事件进入 `InputDeviceState -> RuntimePointerPhase::Leave -> AuiInteractionSystem` 原链。CursorLeft 不携带位置，优先使用最近位置；窗口尚无鼠标位置时使用确定的 `(0,0)`。suspend 清空 pending input 时也清空该位置。

该接线不新增输入 schema。FocusLost 仍由既有 `RawInputEvent::focus_lost` 生成 pressed mouse/touch 的 Cancel，不与 CursorLeft 混用：离开窗口只撤销 hover/inside，失焦才释放 capture。

## 4. 验证边界

owner 测试证明 leave 保留 capture 并可重新进入完成一次 Click；cancel 对 press/started drag 各输出一次内部取消且重复幂等；四类 typed control 和 draggable Panel 获得反馈而普通 Panel 被排除。Player 全部 79 项 lib 测试覆盖 raw leave helper、同帧反馈和既有 focus loss；`real-window` feature 编译证明真实 winit 分支消费 CursorLeft。

本块没有运行真实窗口、GPU截图、安装、旧塔防包、FPS、全 workspace 或 Local CI。109 项去重测试、两个受影响 crate check、定向 Clippy、rustfmt 和 diff/whitespace 检查通过；既有 lint warning 预算未因 C7 增长。
