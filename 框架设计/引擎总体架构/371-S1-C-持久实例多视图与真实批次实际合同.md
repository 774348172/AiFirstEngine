## 1. 生产所有权与数据链

World → 既有 Spatial Presentation／RenderProjectionAdapter → RenderScene → ProductionGeometryCache → Arc<ProductionGeometrySnapshot> → FramePacket／原渲染线程 → GeometryFrame／RHI → 原 wgpu geometry owner。没有平行 Renderer、资源 registry、退休器或项目专用 API。

ProductionGeometryCache 保留每个 proxy 的 MeshProjection、PreparedMeshRenderer、binding key 和 RetainedInstance。实例身份含运行时实体 generation、mesh／submesh；变换变化保持实例 ID，绑定变化才重新生成 binding key 和 Prepare。无变化复用同一 Arc snapshot；稀疏变化只替换受影响实例，全量变化仍保留合法身份。snapshot 保存 content_version 和 updated_instances，并冻结相机、实例和准备资源引用。失效绑定不能偷用旧 projection；修复后可正常恢复。

GeometryFrame 按冻结 views 做 CPU 可见性、每视图相对坐标转换和 viewport 缩放；不会重新读取 World 或当前相机。CPU 可见性与描述符仍按视图评估，不宣称 clean 帧完全无 CPU 工作或相机变化零组装。

## 2. 多视图与历史

主视图和辅助视图沿用 RenderScene view registry。EngineHostLoop.project_auxiliary_camera_view 注册 typed 相机请求，后续 tick 自动刷新；remove_auxiliary_camera_view 可移除。相机禁用／销毁删除旧 view，非法活相机拒绝。辅助接口拒绝主相机与 Game kind，上限 15 个辅助加 1 个主视图。

RetainedGeometryView 冻结 camera、previous_camera、history_version。origin、viewport／projection／相机来源变化重置历史；相机停止后 previous_camera 收敛为当前值。CameraProjection 的 origin 与 coordinate_origin、MeshProjection 的 coordinate_origin 区分表现坐标基底和视图原点，未准备表现时保留 state.anchor。合法域继承 WorldPosition 的全局 1e12、局部 32768、精度 0.005 检查；测试覆盖 1,000km anchor，不授正式 BM 大世界精度／性能资格。

辅助 Preview／ViewportTexture 元数据写入冻结 typed view。当前真实消费是同 backing target 的多相机／viewport；独立 render texture 资源图、跨目标依赖与完整 temporal rendering 留给 S1-D／S2。观察接口仍选择 Game 主相机。

## 3. 排序、材质与实际合批

opaque 且写 depth 的连续区间按 pipeline／baseColorTexture／material binding／完整 batch identity 层次分桶；完整 identity 仍包含 mesh／submesh 等原兼容字段。透明 back-to-front 不重排，alpha 和 TestOnly／Disabled depth 构成排序屏障。GPU 仅合并同 view 的相邻兼容 indexed draws；兼容还包含镜像 winding、alpha／depth、attachments，独特 mesh 与不同 material 不错合批。连续同 view geometry commands 共用 pass。

## 4. GPU 内容与预算

原 geometry owner 懒分配固定参数 arena：65536 个 (view_id, instance_id) slot × 80B（MVP 64B + color 16B），另有 65536 个 u32 slot 索引 × 4B。合计 5,505,024 GPU bytes；这是参数与索引驻留／峰值，不包含 mesh、pipeline、depth、texture 或总显存。

稳定 slot mapping，dirty 相邻 slot 合并 queue.write_buffer range；不变参数／索引零上传。静态帧零参数／索引上传，单实例参数改变上传 80B；清色不变零上传，改变上传 16B。clear uniform／bind group 驻留。

上传前拒绝重复 (view,id)、超过 65536 instances、超过 16 views 和不满足 device limits 的计划。固定 arena 在空计划时保持，不反复重分配。资源全生命周期／completion 退休关闭仍由 S1-D 处理。

内容策略是不可变 packet + 同 queue 有序 write → encode → submit：后端立即提交，不暴露可延期提交的 encoder。后续上传不能污染已提交旧 packet；重放旧 packet 会重新安装旧内容。不是给任意外部 deferred encoder 的 COW 保证。连续三次不等待 completion 提交后分别读回正确画面，旧→新→旧也匹配。

RetainedGeometryStats 的 draws／passes／bind_groups_created／parameter_uploads／parameter_uploaded_bytes／index_uploaded_bytes／clear_uploaded_bytes／installed_content_version／instances／resident_parameter_bytes／peak_parameter_bytes 来自实际后端操作。passes 包含 geometry depth／color clear；RhiBackendReport.draw_count 仍为逻辑意图数，不用于真实合批结论。
