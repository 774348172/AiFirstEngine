# 371 S2-A 材质与采样实际合同

2026-10-15。依据总施工§0.24/§8、371-G与本次用户授权。Windows源码能力；Android延期，不更新安装。此文冻结本次实际支持范围，不授S1/S2完整资格。证据与结论见[阶段记录](阶段完成记录/2026-10-15-371-S2-A-Material/00-总览.md)。

## 1. 资产入口与版本拒绝

正式入口为普通项目的`model-import.v1`，显式选择`materialStrategy: standardLit`，读取glTF/GLB metallic-roughness材质。仍走既有Importer/Cook、`ProjectRuntimePackageAssembler`、RuntimePackage索引/哈希/依赖、`RuntimeAssetLoader`异步闭包、`RuntimeRenderAssetProducer`、不可变GeometryFrame/RHI及生产geometry renderer。不新增资产权威、shader脚本、独立资源寿命系统或安装入口。

`strictUnlit`仍拒绝PBR；`baseColorOnly`仍是用户显式接受语义损失的降级策略并给出丢弃清单；KHR_materials_unlit仍导为Unlit。独立`material-asset.v2`本轮仍仅提供原有Unlit高层入口，StandardLit使用模型材质导入或严格原生CookedMaterial合同，不能把尚未增加的高层入口记成已实现。

旧CookedMaterial字段缺省/空map不改变旧序列化；旧DrawGeometry的新可选字段缺省None且不写出。新`standardLit`、`alphaMask`、mipmap过滤枚举与必要`textureSampling`/`standardLit`数据由严格enum/deny_unknown_fields使不支持的旧reader明确拒绝；不伪装成旧Unlit。内部pipeline recipe为`draw-geometry.v4.retained-storage256-slot-u32`，参数/纹理身份不成为pipeline变体；贴图存在mask、布局、render state成为变体。

## 2. StandardLit字段、坐标与数值

CookedMaterial中`preset: standardLit`、`shaderSource: engine_runtime/src/wgpu_backend/real/geometry/lit.rs#shader`（`STANDARD_LIT_SHADER_SOURCE`）；`parameters`采用既有typed MaterialParameter：

| 参数 | 类型/范围 | glTF来源 |
| --- | --- | --- |
| baseColor | vector4，[0,1]有限数 | baseColorFactor，默认[1,1,1,1] |
| metallic | float，[0,1] | metallicFactor，默认1 |
| roughness | float，[0,1] | roughnessFactor，默认1；BRDF计算下限0.045 |
| normalScale | float，有限且≥0 | normalTexture.scale，默认1 |
| occlusionStrength | float，[0,1] | occlusionTexture.strength，默认1 |
| emissive | vector4，[RGB≥0,w=0]有限数 | emissiveFactor，默认[0,0,0] |
| alphaCutoff | float，[0,1]，仅mask必须有 | glTF默认0.5 |

五个可选texture slot分别为`baseColorTexture`、`normalTexture`、`metallicRoughnessTexture`、`occlusionTexture`、`emissiveTexture`。每个存在的slot必须同时有`textureSampling[slot]`；不借用其它slot的sampler。不允许未知参数/slot或类型错配。因子乘顶点COLOR_0（颜色为线性数值）；基色和自发光纹理按sRGB硬件解码，normal/ORM按线性数据读取。metallic=B、roughness=G、AO=R；AO仅乘间接漫反射，不遮蔽直接光或自发光。

需要真实NORMAL；用world矩阵逆转置变换法线，view必须为刚体相机矩阵。正交相机使用固定观察方向，透视相机使用相机位置至片元方向。只支持UV0；有贴图时必须有TEXCOORD_0，不能补零。normal map是glTF +Y、完整XYZ；在世界位置与UV导数上重建T/B，保留handedness，normalScale缩放XY后归一化。没有normal map不要求切线；有normal map时由选定子网格验证UV三角形非退化。显式TANGENT、其它UV、纹理变换、未支持扩展、skin/morph等仍按原导入边界明确拒绝，不悄悄丢弃。

受光评估为GGX分布、Smith几何项和Schlick Fresnel，金属度混合F0/漫反射；不会把baseColor直接当最终PBR结果。S2-A本块不实现项目照明；当前场景Light消费者见[灯光实际合同](371-S2-B-灯光与多视图实际合同.md)，shadow/IBL/HDR及tone mapping仍待后续。`set_material_preview_illumination`是显式backend诊断接口，默认三个照明向量全零，只保留emissive；改变预览光会使相应参数/bundle失效，不偷偷开启测试灯。S2-B之后生产snapshot附带场景灯光（含零灯），该诊断光只作用于没有场景lighting packet的显式预览draw，不混入场景直射或环境照明。

## 3. Alpha、mip与格式

opaque忽略glTF alpha输入并输出alpha=1；mask不启用颜色混合，保持深度测试/写入；blend使用既有透明排序、标准alpha混合及只测不写深度。mask采用因子×顶点色×baseColor贴图alpha，小于cutoff discard，等于保留；fragment alpha保留，不转成blend。cutoff作为不可变draw参数改变，不新建pipeline。旧原生Unlit的opaque alpha输出行为保持，不追溯改为glTF规则。

首期Windows实际格式仅RGBA8 UNORM/sRGB；不宣称BC压缩、KTX、HDR纹理输入或跨平台压缩Cook。其它格式在既有payload/metadata入口拒绝。原生v1曾允许`rgba8Unorm + srgb metadata`并按UNORM采样，该历史输入与字节行为继续保留；StandardLit逐slot显式归一化format/colorSpace。sRGB格式不能标linear。

mip是从base到1×1的紧密连续RGBA8层，宽高逐级`max(1,floor(n/2))`，完整层数`floor(log2(max(w,h)))+1`。奇数尺寸采用覆盖原图的面积权重，颜色RGB在线性光下滤波再编码sRGB，alpha/数据在线性空间滤波。normal XYZ编码的线性平均等价于向量平均，采样后解码归一化；接近零的mapped向量回退表面法线。无覆盖率保真的alpha mip或高级normal方差处理声明。

glTF六种minFilter以及两种magFilter、Repeat/ClampToEdge/MirroredRepeat均保留；mip minFilter产生并要求完整层链。non-mip使用仅暴露base层的texture view，LOD上限不强制置0，以免误改min/mag选择。逐层范围/字节/mip数/采样器在提交前验证；所有层都真实分配和上传，不能仅有mipCount枚举。

## 4. 增量、共享与寿命

沿既有增量缓存按消费输入失效：材质因子不重解码几何，图片变化进入纹理产品/新资源generation，CookedMaterial不因不变引用文本而伪造变化。Material/Texture binding随新版本更换，旧packet的参数、mesh和texture lease保持原内容。

VerifiedTexturePayload对颜色/数据各保留一个有界弱mip memo；同语义/不同sampler共享实际像素Arc，色域不同不别名，弱memo不钉住退休数据。GPU身份仍含真实像素、格式/色域/采样器和既有generation；lit组合binding包含五slot实际handle，缓存布局至多31种非空mask，不新增资源注册权威。

旧纹理替换、lit bind group、recorded bundle、参数版本沿既有最后真实submission/completion退休。全部mip字节计入resident/staging/在途/退休，不只计算base；分片上传跨level映射正确，保持原每帧/队列上限，共享ticket取消一个不撤销另一个。统一retained instance参数为256字节、65536slot；含slot索引buffer的实际参数存储为17039360字节（16.25MiB），不是原80字节布局。内存/性能历史资格只归旧源码/旧包，不能外推给该新布局。

完整backing观测、GPU帧间峰值、正式三轮、OS显示关联与完整lit-v1规模资格按371-G延期。新增可访问存储的全面接入由S2-D接收；不能把bind group/驱动内部不透明分配的0计数字节解释为实际分配为0。
