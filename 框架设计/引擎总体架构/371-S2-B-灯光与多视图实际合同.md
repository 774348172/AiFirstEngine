# 371 S2-B 灯光与多视图实际合同

2026-10-15，S2-B状态`functional_chain_verified / qualification_deferred`。Windows only，Android延期，不改安装。依据总施工§8、S0-CD的Clustered Forward+冻结；Windows离屏源码功能链已验证，BM04与联合预算等正式资格延期，不授完整阶段完成。

## 已贯通的场景光链路

普通Scene/Prefab的Light3D，沿既有RuntimeSpatial、World archetype、RenderProjectionAdapter、CameraProjection、ProductionGeometrySnapshot、DrawGeometry进入生产StandardLit。场景光与backend诊断预览光分离，不制造默认项目光。

Light3D使用light3d.v1，线性RGB色，方向光intensity为lux，点/聚光为candela（轴向发光强度），世界米制；局部-Z为发射方向，点光忽略方向。局部光range为严格有限影响半径，衰减为max(1-(d/r)^4,0)^2/max(d²,0.01)，聚光使用内外半角余弦smoothstep，0≤inner<outer<90度。颜色/强度非负有限；world变换只取独立旋转pose不随scale改变发光角度；`castShadows`默认false、false不序列化；true由本续窗生产阴影链路消费，不支持的point投影明确拒绝。

逐view灯光上限256（覆盖BM04的145灯），超限拒绝而非截断。16×9×24 clip-depth cluster，局部光用球体与六个clip cell平面保守相交；聚光先按range球保守入桶，fragment再测锥角。方向光入所有桶；每桶固定8×u32位集、可表达256灯，完整最坏重叠可容纳；没有隐式fallback。clip-depth线性分层是首期明确策略，不宣称log-depth或GPU compute分桶。每个plan最多8组不同内容的灯光数据（整体view上限仍16），相同内容按摘要复用；超限在提交前失败。单buffer最大127056字节，新建初始化总量≤1MiB/plan；该上限属于renderer参数初始化，不冒充mesh/texture流式上传、staging及在途上限的联合验收。

不可变分桶存储与view矩阵/viewport/原点配套，灯光变更失效snapshot；旧帧保留旧数据，GPU每版本只读buffer，退出active集合沿真实completion退休，不原地queue.write覆盖在途灯光。受影响资源观测保留实际buffer容量，不以不透明bind group零计数冒充零分配。

## 当前功能范围与剩余

普通项目方向四级联、八spot总atlas、相机外caster及真实阴影采样已贯通，算法和附件合同见下节。主相机draw剔除不截断shadow caster候选；普通项目双相机不同origin/resize、独立四atlas、mask/PCF像素与三个在途提交已有证据。独立多color-target光影消费、跨输出最后receiver、输出resize/退休也已验证，合同见下节。BM04原规模及视觉资源联合预算未资格，由S2-D接收；不再阻断S2-C功能开发，S2-C尚未开工。

SDK沿现有Spatial deferred transaction增加set_light_enabled、set_light_color（线性RGB）、set_light_intensity（方向lux，点/聚candela），不改变光源种类/层/范围。既有generation、overlay、整批验证和commit检查继续生效；旧reader对新intent明确失败。AI空间inspection返回typed light值。

场景光历史证据见[灯光记录](阶段完成记录/2026-10-15-371-S2-B-Lighting/00-总览.md)，当前阴影功能及缺口见[阴影续窗记录](阶段完成记录/2026-10-15-371-S2-B-Shadows/00-总览.md)。独立多输出续窗见[多输出记录](阶段完成记录/2026-10-15-371-S2-B-MultiTarget/00-总览.md)；不以功能链通过授BM04/完整阶段资格。

## 已实现的阴影算法与附件合同（Windows离屏功能范围）

ShadowMap是真正无颜色附件的Depth32Float writer，RH/-Z、clip z=0..1、clear=1、LessEqual；透明blend不投影，opaque/mask沿原材质UV/alpha cutoff/纹理mip，mask执行discard；Unlit可投射、StandardLit接收，投影pass强制TestAndWrite，不继承主材质Disabled/TestOnly。深度clear与load独立表达；同atlas首view整图clear，随后tile load，tile必须不重叠，禁止后续clear破坏先前tile。RenderGraph显式DepthTarget+Sampled，writer→所有receiver读依赖保留至最后view；native不分配dummy color。

方向4级联使用一张总4096² atlas的2×2 tile（各2048²）；8 spot使用一张总4096² atlas的4×2 tile（各1024²，占用上半图），两张总逻辑128MiB，不是每投影4096²。首期1方向投影/8 spot，point不投影；超过冻结上限拒绝。级联采用lambda=0.5 practical split（相机near/far）、包围球稳定正交、light-space中心结合f64世界原点按绝对tile texel网格对齐，避免原点重基使静止阴影跳动；深度包围需包含相机外caster，不从主camera已裁draw取caster。spot near=0.05m且range必须大于near，outer half-angle决定FOV。receiver使用3×3 comparison PCF、tile内半texel钳位，receiver z bias=0.0005，几何法线偏移=0.01m；每次只抑制对应灯的direct，emissive/其它灯不受影响。不授IBL或S2-C。首期硬级联切换，不包含cascade混合。独立f64参考验证九点深度覆盖与PCF边缘、RGBA8容差±2，普通项目对照分别验证方向/spot的变化；不以非黑统计授物理正确性。


## 消费、上限、兼容与资源寿命

`Light3D.cast_shadows`经原typed Scene/Prefab→Compiler DTO→RuntimePackage→World/Projection消费；没有新registry或包旁路。旧项目省略字段仍为false，冻结旧strict Light reader遇到true字段拒绝，未知字段与point投影/spot range≤0.05m拒绝。尚无专门切换castShadows的Game SDK setter；源资产决定投影，既有SDK enable/颜色/强度与Transform可用。测试中直接修改World的cast_shadows只用于验证snapshot失效，不冒充已交付SDK能力。

`ClearPolicy::Depth`、`ExecutableRenderView.depth_clear`明确clear/load；typed3D ShadowMap允许NativeGeometry，legacy2D ShadowMap标签保持旧合同。`DrawGeometry.shadows`是不可变Arc数据；pipeline recipe升级`draw-geometry.v6.depth-only`，身份包含depth-only及采样atlas槽，不支持新字段的strict旧reader拒绝。图检查格式/shape、writer矩阵/viewport/先后、明确reads；raw RHI也在提交前复核。首tile清1、其它tile Load；重叠、重清、未初始化、错误sample/格式或writer晚于receiver均拒绝；graph cache身份包含load语义。整帧生产构建错误沿RenderThread report报`three_d.production_frame_failed`，清空命令并not_submitted，不靠空白帧算成功。

单相机最多12个shadow view、2张atlas；单plan最多16个普通color view、192个shadow view。不同相机atlas逻辑ID独立；现有native depth alias判断包含所有shadow sampler最后使用，不能按writer结束点提前复用。不可变shadow参数buffer与atlas views沿既有真实GPU completion退休；单投影参数176字节、每新增投影96字节。CPU快照backing、native buffer/texture resident与retiring纳入既有census去重；driver/bind-group隐藏分配不冒充可见完整分配。

两atlas逻辑128MiB/相机，不包含普通color/depth、灯光/材质/geometry参数、其它texture及退休峰值。**新增renderer资源尚未取得与原streaming/staging/in-flight上限的联合预算资格**，不能仅因固定atlas上界就授完整内存通过。原上传/队列owner与预算不改；完整观测/全运行峰值/正式三轮/OS显示继续按371-G在S2-D等接收，6GiB门槛保持，未重测不授新余量资格。

## 独立颜色输出与生产消费者（本续窗冻结）

`EngineHostLoop::set_geometry_view_target(view, Some(RenderTarget))`将已投影空间相机绑定至独立离屏目标，None解除；未绑定相机保留原主target语义。这是host消费者API，不是新增Game SDK setter、Scene字段或AI Tool。未知/nonspatial view即时拒绝；空ID/零尺寸/Surface/主target冲突、同ID描述冲突及颜色format/space不一致在生产帧构建时拒绝，失败帧不提交。绑定冻结入既有ProductionGeometrySnapshot，变更输出revision同时失效packet/history而不修改旧快照；resize、解除及相机移除清理原owner绑定。没有新registry或包版本；RenderResourceFormat新增RGBA/BGRA sRGB枚举，不支持它们的旧enum reader明确拒绝。

按目标相机组分别计算viewport basis/extent，生产graph声明各自ColorTarget及depth，原点/cluster/shadow独立；共享shadow读依赖持续到所有输出的最后receiver。native在原geometry owner分配单mip、sampleCount=1、RENDER_ATTACHMENT|COPY_SRC输出并定向执行clear/draw。最后mesh卸载后仍保留活相机clear/depth，不能残留上帧。输出resize/移除沿原GPU completion及退休准入，不原地破坏旧在途资源；resident/retiring实际纹理容量进原census。

最多15个额外输出、16个普通view、192个shadow view；额外输出必须为Texture且同backend实际format（RGBA8/BGRA8各linear/sRGB），同帧混format拒绝。secondary只支持typed World3d几何与clear，secondary Window/Present、legacy/UI/particle及Sampled/Depth用途明确拒绝。`read_geometry_color_target_rgba`是当前驻留输出的有界GPU读回消费，不暴露native handle；未接跨颜色目标材质采样/UI嵌入/第二OS窗口。普通默认host tick的RGBA离屏链已验证；Bgra surface/window组合未资格，四format native单元不冒充真实窗口证明。

独立World/相机参考对照：主输出800×480保持，辅助800×480→960×576→800×480，origin分别1,000,000与1,000,100m并补偿local pose；四独立atlas，辅助与单相机参考差>2的像素20/25/20、总差294/389/294，固定阈值≤128像素且总差<面积/10。主输出跨resize、旧两输出帧重放逐字节相同。卸载最后mesh双输出清黑；销毁辅助相机输出退出驻留。退休测试按真实completed/submitted分支观测，不声称每次都人为延迟GPU。仍未取得新增color/depth/atlas与流式/在途联合预算资格，原128MiB退休及16在途准入不变。
