# 371 S3 角色与模拟实际合同

本合同冻结371既定S3-A–E首期实现边界，服从v1总方案、总合同及49/54。状态：首期施工完成、资格遗留已登记（`construction_completed_with_deferred_items`），2026-10-26；见[完成记录](阶段完成记录/2026-10-26-371-S3-Simulation/00-S3角色与模拟施工完成.md)。本文件不代替规模/平台资格。

## 角色与呈现

- `character3d.v1`为Cooked资产；Runtime只读取包内字节和内容哈希。稳定joint key、拓扑顺序、bind/inverse-bind、影响权重、clip/event/graph均有校验与预算。
- Step、Linear、CubicSpline按非均匀关键帧采样；四元数归一化并沿短弧插值。事件按固定tick、时间、作者等时顺序派发。seek只改变采样起点，不重放跳过的事件。
- 首期graph提供命名状态/参数、条件转换、crossfade、mask和additive层；不引入项目通用脚本图。
- GPU在mesh空间先线性morph，再skin。current/previous输出不可变；旧packet保留自己的缓冲和内容。动态bounds覆盖实际变形位置。
- 模拟IK与视觉IK分离。玩法挂点读取最终模拟pose；纯表现查询读取视觉pose。两段IK支持正均匀缩放、连续三骨链和显式pole；不可达目标夹取，退化链拒绝。retarget必须显式声明源/目标rig和joint映射。
- 动画LOD只跳过可选视觉IK/姿态更新；固定tick采样与必需事件继续。零固定tick呈现按alpha插值previous/current视觉pose，不推进时钟或事件。
- previous skin以最近实际呈现的skin为历史；play/seek/模式切换/teleport/history reset清空历史。S2首期AA是空间FXAA，没有依赖previous skin的时域效果，不能声称已验证不存在的运动模糊/TAA。历史缓冲正确性用GPU读回和旧packet回放验证。

## 空间写入权与根运动

- 每固定tick执行：项目意图 → 导航请求 → Character.prepare（一次采样/根运动）→ Jolt body/motor step及World提交 → Character.publish（最终模拟IK/pose/skin）→ World tick发布。
- `animated`：动画拥有骨骼local pose，motor接受项目/导航输入。
- `rootMotion`：绑定声明一个直接位于motor owner下的骨架根及translation axes；按clip未回绕时间积分、补完整循环位移、按crossfade/层权重混合，经显式retarget translationScale后旋转到world，交给原motor。已消费轴从骨骼pose移除，受阻位移不叠加、不留债。根旋转提取不在首期声明中。
- rootMotion模式下根运动拥有该tick的motor移动；animated模式下手工motor命令优先于导航。seek/play重新确定积分起点，不生成跨seek传送。
- `ragdoll`：绑定声明2–64个连通骨骼的、初始禁用的dynamic Body3D及相邻关节。切换先停用motor、启用声明的骨骼body；Jolt负责骨骼空间，动画时钟/事件不推进，skin读取物理提交后的local pose。切回退役这些body/关节、启用motor、恢复动画并重置历史；首期按保留的角色owner位置恢复，不宣称自动起身/主动布娃娃。
- 未声明的dynamic骨骼与动画竞写拒绝。普通项目SetLocalTransform和bulk写入不能绕过dynamic写入权；显式teleport是独立的历史重置操作。

## 物理

- 固定Jolt5.6.0、oxijolt1.0.1、deterministic、单精度求解；一World持久solver，保留contact/sleep私有状态。
- static/dynamic/kinematic；box/sphere/capsule/convex及static nonsensor triangle mesh。碰撞资产为`collision3d.v1`，内容哈希验证、按scale/motion/sensor共享native shape。正缩放、无shear；motor以world米为单位，要求单位缩放。
- 质量/惯量、摩擦、恢复、CCD、sensor、睡眠、fixed/point关节、ray/sweep/overlap及紧凑contact/motor结果。sensor+CCD组合拒绝，符合冻结Jolt后端约束。
- 项目通过既有WorldRead按需读取只读`engine.physics3d_state`投影：当前tick、body速度/睡眠、motor接受位移/grounded和该实体contact事件；读取时从实际提交的PhysicsFrame生成，motor/body结果均须匹配当前实体generation，不每tick把全量结果JSON复制进ECS。native query接口保持PhysicsModule所有权，不允许项目持有solver句柄。
- S5原BM06消费者补齐沿既有WorldRead/world_query接入有界同步物理批查询，单次最多256项raycast或box/sphere/capsule sweep。PhysicsModule仍是唯一solver owner；FrameLoop只借出只读引用，不复制或重建solver，也不把基准玩法放入Core。
- 查询返回真实最近已提交的physics tick及逐请求最近命中，查询时不推进模拟；FixedUpdate发生在本tick物理step前，因此通常读取上一个已提交tick。尚未初始化的solver返回明确notReady状态，不把空列表冒充已执行查询。命中只保留World当前同generation实体；World更换、缺owner或不支持的平台明确拒绝，不复活旧solver命中。
- 所有请求先校验数量、有限世界原点/位移、正尺寸和合法四元数，再调用真实Jolt；保留f64原点与现有局部包络。批次保持输入顺序，未命中为None；不持有裸solver/body句柄，不引入异步结果或隐含跨tick队列。
- CharacterVirtual负责重力、跳跃、坡度/阶梯/低顶、移动地面速度和实际accepted displacement；导航和动画不直接写motor transform。
- 世界位置先用f64减solver origin，再转局部f32；局部32km是输入包络，不是完整BM-09精度资格。rebase移动既有solver对象，不重造World。
- 冻结Jolt默认contact penetration slop为20mm；地面上半径0.5m的球可能静止在中心y≈0.48m。BM-09的近远锚点误差相对同配置零锚点基线计算，不把contact policy误当浮点误差。
- 求解错误为终止故障；不声称对已经step的native solver做无损回滚。项目字段恢复、backend重建与连续求解回放分别记录。

## 导航与音频

- 固定Recast/Detour1.6.0、64位poly ref；Recast真实离线bake，Detour真实tile/query。recipe=`recast1.6.0-detour64-monotone.v1`。
- AgentProfile精确匹配；同key不同参数拒绝。Nav surface首期仅translation，X/Z按tile网格放置，旋转/scale离线烘焙。多tile接缝、off-mesh link、未驻留/不可达有明确结果；到达off-mesh入口时停止自动steering并发布`linkRequired`、入口及出口；项目自行选择跳跃/攀爬意图，完成后重新请求路径，不假装通用motor可以跨任意断层。
- 一个有界工作线程、64任务/完成队列；entity generation、目标revision、nav revision、deadline和取消联合检验。tile卸载或障碍变化使旧路径失效；旧结果不能恢复已取消的运动。
- 局部避让按有界邻居分离，输出原motor请求；已加载区动态障碍用保守poly flags更新，不全世界rebake。
- BM07沿原A合同：每代理steering/avoidance以0.1秒周期更新并保留方向，60Hz固定模拟逐tick接受motor位移；新路径及路径拐点立即刷新，取消、失效、off-mesh与到达仍逐tick检查，手工motor命令仍优先。既有owner的代理容量扩至2048、动态障碍128，以容纳原1000/50及2倍压力；worker的64项队列和overflow结果保持，不新增调度服务。
- 空间音频为线性距离衰减、listener right基向量的constant-power stereo pan。世界位置f64相减；空间stereo先下混mono，普通非空间stereo保留。5ms增益平滑，初始增益在设备排队前发布。
- Windows WASAPI与Android AAudio/CPAL共用真实PCM游标适配。位置变化不重播或复制PCM；全局暂停保留游标并与项目pause叠加；显式设备重开从仍存活且正在播放的clip起点重放；旧generation不复活。无listener空间源静音，多个enabled listener拒绝。
- 离线声道数值、Windows静音设备smoke、Android构建及Android真机听感是不同证据，不能互相替代。

## Cell事务

- 延续原RuntimeInstanceLoader/PreparedRuntimeEntities/cell ticket和资源释放owner。Physics/Nav domains必须由本FrameLoop实际的模块准备，缺owner拒绝；不使用空占位ACK。
- Physics准备验证并持有native shape和有界容量reservation；Navigation准备在隔离Detour对象中装入真实tile，保留已转换字节和reservation。准备期间不进入活跃World、碰撞或路径集合。
- 提交前重查World/资产epoch、身份、父空间、budget和GPU完成。先在原Jolt/Detour激活资源，任何失败撤销本次新增native对象，再进行无回调、不可失败的原World hydration commit，最后登记generation/领域身份。异步query结果仍须通过nav revision校验。
- 双cell可以同时prepare；后续commit按当前同profile网格重定位预备tile，不重Cook。重叠tile在真实Detour add处拒绝并撤销新collider。
- World despawn（含子树）在返回前立即移除对应navigation、character pose、skin及presented skin映射；无需等待下一fixed tick。旧packet所持Arc仍不可变，旧motor读投影须按generation拒绝。
- abort释放未激活资源/reservation；active release沿原World/资产/渲染owner退场并立即退役对应物理/导航对象，失效旧路径与generation。跨cell迁移的进一步大世界语义仍归S4，不冒称S3完成完整流送资格。
