## 2. 真实源码结论与FFI所有权

以下路径均相对锁定的 `spine-cpp/spine-cpp/`，不能用其它分支替换本证据。

| 源码/函数 | 已核对结论 | 引擎处理 |
|---|---|---|
| `src/spine/Animation.cpp` constructor / destructor / hasTimeline | constructor复制timeline指针数组并建立property ID集合；destructor删除timeline | 不能把共享timeline同时交给另一个Animation；新动画必须独立拥有timeline |
| `src/spine/AnimationState.cpp` update / apply / updateMixingFrom / applyMixingFrom | 官方管理活动轨道、来源链、权重与离散轨道应用 | 控制层不再自行混合一次姿态；TrackEntry仅在后端内部可见 |
| 同文件 animationsChanged / computeHold | 依据新动画的property IDs计算First/Subsequent/HoldMix等缓存 | 先构造完整过滤动画，再setAnimation；之后不得改其timeline集合 |
| `CurveTimeline.h` getFrames/getCurves，Rotate/Translate/Deform构造函数 | 允许复制完整帧/曲线数据，构造函数重新建立ID | 已编译/运行深拷贝探针，包括非线性Bezier |
| `DeformTimeline.cpp` constructor / apply | ID含attachment ID；apply核对canonical timeline attachment身份 | clone构造时就使用原只读data中的canonical attachment；不能只setAttachment后沿用旧ID |
| `VertexAttachment.cpp` computeWorldVertices | 分开处理非加权、加权与slot deform | 小三角手算与3组实际网格输入验证；不是自研替代蒙皮 |
| 同文件 getNextID | 函数静态自增ID，不具备一般并发构造保证 | 仅asset构造加锁；实例/data/mask不标Send/Sync，不宣布并行后端资格 |
| `EventTimeline.cpp` apply，AnimationState::queueEvents | 回调按局部区间工作，不能保证一次跨多圈完整枚举 | 源事件索引+单游标；官方内容回调仅计数对照，不对项目重复发布 |
| `SkeletonJson.cpp` readSkeletonData / readAnimation | 假定输入结构/引用/数组合法，部分分支非安全沙箱 | Gate B先验证再FFI；本次入口明确unsafe，不把裸parser直接接工具 |
| `Atlas.cpp` 内存构造与createTexture=false | 可只读atlas元数据，不读取图片/源文件 | A仅metadata；B由原AssetProjection提供包内纹理 |
| `SkeletonClipping.cpp` clipStart / clipEnd / clipTriangles | 以endSlot结束、只允许一个活动clip；按凸分解逐三角生成输出，索引为unsigned short，内部Vector会增长 | B在调用前按凸片/三角的保守输出界限制scratch及16-bit索引；必要时有序分块，不能溢出后才检查或默许嵌套clip |

Rust `Asset`用Rc保留native data/atlas；`Mask`保留Asset，拥有全新Animation/timeline；`Instance`保留Asset与所有仍可能被混合历史引用的Mask。释放顺序为AnimationState→stateData/Skeleton→mask→data→atlas。C边界仅opaque handle、定长数字和调用方缓冲区，不跨STL、异常或borrowed Event/TrackEntry。

Gate A历史探针clone白名单为Rotate、Translate、Deform，64-bit选择仅保留为旧探针API。当前Gate C正式入口为ValidatedSource::mask_plan→Asset::bind_mask，使用显式256骨骼位集、源JSON身份及完整已支持骨骼/slot/约束timeline深拷贝；Event仍走源索引。依赖冲突在plan阶段拒绝，详见§14；D再接作者绑定与Cooked控制表，不把旧探针限制当作当前正式能力。

mask目标按显式源骨骼名称集合绑定，无隐式“所有后代”规则。slot/deform随slot所属骨骼过滤。跨mask的IK/transform/path写集合、选中父骨骼驱动被排除动画子树、跨集合加权影响、全局draw-order与attachment/linked依赖冲突必须在Cook拒绝；不以删轨道掩盖冲突。普通完整动画仍由官方整体求值。

## 6. 时钟、事件索引、mask与错误隔离

权威时钟为包内tickRate和整数tick；speedPermille为0..4000整数。正mix/fade秒数ceil(seconds*tickRate)，0硬切；仅修正f64乘法≤4ULP的正整数边界舍入，正的不足一tick仍至少一tick。内容事件按`(previous,current]`、入场0键一次、loop末键与下一圈0键分别保留；同跨越时刻按源序号排序。暂停既不推进tick内动画计时也不重复0键。

源索引单位微秒，`round(sourceSeconds*1e6)`；Gate B从JSON源数值构建，使用f64解析后量化，保留源序号/payload；Gate A从官方f32 Event复制时间用于可行性对照。0.5us仅为量化误差，不包含官方f32舍入；对官方单圈回调对照允许`max(1us,2*f32ULP(sourceTime))`时间差，事件身份/数量/排序必须一致。源duration和key统一量化，duration>0，零长动作若含事件拒绝。

事件预估先用每个键的整数循环区间求总数，超预算不分配、不推进游标；实际事件使用同一已预检区间。测试跨越2.25圈时官方回调少于6个应发事件，源游标完整补齐；官方内容事件不重复发布。incoming当前action在有效权重>0时发事件，outgoing一旦混出立即抑制，clear清除待发事件；生命周期只作内部compact信号。

Once计划在`entryTick + ceil(duration/speed*tickRate)`自然结束时启动官方empty fade，在额外fadeTicks后退休；speed=0冻结完成，未恢复前不排自然结束。计划最多一个当前action完成点/层，不使用公开队列。发生中断时取消旧计划，不能让旧callback删除新动作。

**Gate A的delta step只是FFI探针，不是生产时钟实现。** Gate C须从整数entry/mix起点派生每个活动/混出entry的有界clip phase与mixTime，通过已核对的TrackEntry setTrackTime/setMixTime等接缝喂入官方state；循环序号保留在包装，不能把长时间累计f32或无限增长trackTime当权威。C必须增加长时钟、多loop、fade计划对真实state的组合测试，不能复用A的2.75秒探针冒充长时资格。

| 错误类 | 冻结行为与码 |
|---|---|
| 版本/格式/特性 | `spine.import.version_mismatch / unsupported_format / unsupported_feature`，Cook前拒绝 |
| 源结构/页/依赖 | `spine.import.invalid_structure / atlas_page_missing / dependency_invalid`，不调用不安全parser |
| 动作/绑定 | `animator.binding.unknown_action / unknown_skin / unknown_socket` |
| mask | `animator.mask.unsupported_timeline / dependency_conflict / empty_selection` |
| 混合/预算 | `animator.mix.unsupported_additive / chain_capacity / layer_capacity` |
| 阶段/句柄/事件 | `animator.runtime.invalid_phase / stale_handle / command_capacity / event_capacity / tick_rate_mismatch / backend_failure` |
| 渲染 | `spine.render.geometry_capacity / unsupported_blend / resource_not_ready` |

可预判错误不修改已提交状态；后端可捕获异常返回有限错误，实例isolated，停止发布该tick新姿态/事件/挂点。上一成功对外结果由session owner保留；探针不包含这个session事务。官方容器不具备recoverable OOM保证，适配分配器遇到OOM abort，不把access violation/OOM伪装为可回滚异常。不得据A的有限错误测试宣称已经覆盖OOM恢复。

Spine本地坐标X向右/Y向上、旋转为度；`pixelsPerUnit`只在向引擎局部单位输出时除一次，实体TRS由既有Projection施加一次，屏幕翻转只在既有相机/投影处理。模拟挂点使用同一单位/时刻；A探针读取原始Spine坐标，不是已变换的引擎世界挂点。

颜色/混合在linear空间；源straight/PMA按atlas页声明校验。PMA数据若在源编码空间预乘，Cook按alpha解预乘、转linear再预乘；alpha=0时RGB=0，防止把gamma预乘当linear预乘。顶点tint统一乘skeleton/slot/attachment颜色与alpha一次，禁止重复预乘。

令Cs/Cd为预乘linear颜色，As/Ad为alpha；alpha统一`As+Ad*(1-As)`。normal颜色`Cs+Cd*(1-As)`，additive为`Cs+Cd`，multiply为`Cs*Cd+Cd*(1-As)`，screen为`Cs+Cd*(1-Cs)`。这是冻结的Spine风格GPU blend约定，非其它合成标准的自动等价；真实GPU的straight/PMA、半透明底色、tint与四blend各有B像素case。输出到UNORM时按目标格式钳位，不因截图外观相似跳过方程断言。
