## 1. 目标与基线

目标是完成 U1 的源码合同、原生资产 Cook/Package/Load/Prepare 及 named binding 集成。Mesh 不再从文件大小推算几何，Material 不从空记录伪造默认参数；资产内容、引用、句柄代数与绑定槽位可验证。普通 2D Sprite 和 AUI 消费保持兼容。

U0 已归档，70 项合同与 consumer 测试通过；当前无有效施工，254 历史报告不占槽。357 是当前安装，未包含 U0/U1。工作区存在大量前置修改，保留它们，以 `.artifacts/358-U1/20260922-1809/baseline.json` 和文件副本区分本轮变更，不能以 HEAD 冒充实际源码。

## 2. 实施边界与 owner

| Owner | 最小改动 |
| --- | --- |
| `engine_runtime/src/render_contract` | 复用 render-contract.v1；真实 Mesh/Material payload 校验；typed resource handle 与 named binding 合同；复用 compact error/按需诊断 |
| `render_asset_production.rs` 及子模块 | 新 cooked 入口与既有资源管理器衔接；保留真实 bytes、明确准备状态、digest/version cache key、拒绝 metadata-only Mesh/Material 成功 |
| `runtime_asset_loader.rs` | 提供权威 index 只读接缝供 typed reference 解析；继续使用现有 load/bytes/release |
| `render_resource.rs` | 复用原manager；修复已复现的预算不足重复分配pending句柄，增加只读resident key查询 |
| `project_authoring_execution/src/neutral_assembler.rs` 及 helper | 在唯一 assembler 中接入原生 renderData import/cook，校验依赖并写原有 hash/dependency/source mapping；343 runtimeData 粒子格式仍走原 owner |
| `runtime_package_builder.rs` | 实际 payload 长度写入既有表；使用已有 runtime/cooked manifest 与包 content digest |
| `sprite2d_render_pipeline`、`runtime_renderer`、`rhi_command_plan`、`headless_rhi_backend`、`wgpu_backend` | 迁移 named binding 读写，按槽名取纹理；旧 BindingSet wire 在单一 decoder 归一化 |
| 新 U1 测试与相关 owner 现有测试 | invalid bytes/layout/index/bounds/material/schema、digest/type/missing、stale/deferred/reuse、真实组包加载及 consumer |

Mesh payload 最小支持 triangle-list、显式布局/计数、真实 little-endian vertex/index bytes、u16/u32、submesh ranges、AABB/sphere、坐标约定和 material slot names。计数仅校验，不补占位数据。Material 首批明确 unlit preset，typed 参数和 named texture slots，blend/cull/depth、shader source mapping、派生 pipeline identity；未支持参数显式拒绝。后续 preset 不需要万能 optional 对象。

Import 输入在既有 mesh/material `.asset` 中使用显式 `renderData: { schemaVersion: "render-contract.v1", data: ... }`；不与343的 `runtimeData` 混用。Cook 只对原生数据校验/规范序列化，源码 digest 与 cooker recipe 随 cooked envelope 保存，cooked bytes digest 留在现有 runtime/cooked manifest，避免自引用 hash。依赖复用 GUID/AssetRef/AssetIndex，不新增数据库、resolver 或第二 assembler。

Typed handles 包装既有 kind/index/generation。Named BindingSet 使用槽名与 typed 资源，不另存第二份可写资源向量。旧 wire 只在 decode 时归一化；新序列化输出槽名。Texture/FontAtlas/RenderTarget 共享此绑定接缝和现有资源生命周期；实际纹理上传继续由现有 Texture registry/backend 管理，不增加上传链。

新 prepare 的就绪只声明 CPU payload 与逻辑 resource residency，不能当作 GPU buffer 已上传或可见 3D；真正 DrawGeometry/depth/backend 上传属于 U2/A。默认保留 compact Result，诊断复用 Off/Summary/Trace，禁止新增默认逐帧长报告。
