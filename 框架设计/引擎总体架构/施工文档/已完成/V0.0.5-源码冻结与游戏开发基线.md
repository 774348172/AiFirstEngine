- 排除：引擎功能、主仓库提交/分支重置、安装配置切换、3D预算修复、全量回归和二进制发布资格。
- Gate A：源拷贝遗漏或漂移风险 → 拷贝前后逐文件SHA与文件集合比对；包含 Rust workspace、资源/字体、夹具、SDK/Host、正式架构文档。

- Gate C：交付漂移风险 → 独立Git提交/tag、git archive、ZIP CRC及全文件SHA回读、归档集合比对。
- 旧证据：仅继承49记录的能力/限制；不将历史二进制资格迁移给新源码。源码有变化则旧运行证据不构成本版资格。
