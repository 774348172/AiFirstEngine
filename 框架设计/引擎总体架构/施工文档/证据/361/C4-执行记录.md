## 变更与发现

C4把项目自定义type注册、Describe/Measure/Layout/Paint、主动measure/repaint失效及真实局部mesh接到Project Runtime ABI 1.6。扩展结果归`AuiInstance`，布局复用既有Taffy owner，绘制复用既有UiProjection/Renderer；Generated Glue以空Host context执行只读扩展callback。

施工复核发现原完成声明仍缺五个合同：显式8轮稳定化、项目侧custom property setter及descriptor自动失效、Taffy最终容器/child尺寸反馈、Rect/Image/Text既有绘制路径、绑定property/input/resource identity的last-good。补齐后，presented-frame只在真实重建或稀疏custom dirty存在时调度；clean cache hit不构造扩展frame。相同payload更新identity但不增加revision，输入身份改变且callback失败时不复用旧输出。

## 已证明的行为

- ABI 1.6函数表、schema/digest、SDK、Game SDK、Glue、Editor及native fixture同步；旧1.5失败关闭。
- type/schema/callback/typed属性注册唯一，缺失、不兼容或类型不符在挂载期定位失败。
- custom measure改变既有Taffy最终尺寸；径向layout只改直接子项最终rect；圆形paint的索引三角形进入真实Renderer vertices。
- Layout callback接收最终容器尺寸与直接child实际尺寸；相同presented frame零callback。
- Rect/Image/Text图元进入既有draw paths；mesh仍进入同一UiProjection/Renderer。
- clean cache hit零扩展frame/跨DLL；repaint-only不触发measure/layout；非法输出只在身份匹配时保留last-good。
- 8轮振荡在第8轮禁止发布并输出结构化partial诊断；property/resource identity改变后的失败不复用旧片段。
- 扩展callback无Host context；普通项目回调通过唯一`ui_invalidate`请求measure/repaint并由既有接受边界提交。
- 两个动态模板实例的custom runtime输出隔离；shutdown后dirty、实例和运行输出清空。
