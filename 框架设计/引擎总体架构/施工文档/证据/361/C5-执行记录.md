## 已证明的行为

- `aui-update.v5` ownership 字段与 typed SDK 往返、唯一 key、容量和 poison 语义一致；合同 digest 随 schema 改变。
- ABI 函数表保持 1.6；native Host 与 Generated Glue 复用既有 `ui_stage`，没有新 Host 槽。
- Binding 默认拒绝直接 setter；Controller 接管与首值原子提交，后续 setter 可用；归还 Binding 默认无 Changed。
- 无绑定属性、过期句柄、非法组合、Rejected/Panic 和结构草稿回滚不发布 owner 或值。
- snapshot A -> Controller -> snapshot B 被抑制 -> 归还后显示 B；clean 与无关节点不额外重建。
- 动态实例、删除、shutdown 和模块卸载沿既有生命周期清理 ownership，没有全局 registry。
