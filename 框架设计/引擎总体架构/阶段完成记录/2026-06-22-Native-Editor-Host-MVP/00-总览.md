## 路线更新说明

本记录中的 `editor_ui_backend_egui` 是当时按 B-C 路线实现的 headless adapter。

后续架构已调整为 C-lite 长期路线：

```text
winit + wgpu + 自研 UI renderer 是正式 UI Backend v1。
egui / eframe 不进入真实窗口主线。
editor_ui_backend_egui 保留为 compatibility test adapter。
```

因此，本记录保留为历史执行事实，不代表当前正式 UI backend 方向。
