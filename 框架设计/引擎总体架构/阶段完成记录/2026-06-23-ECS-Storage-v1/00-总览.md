```text
每个关键能力都有最小测试。
```

保留兼容：

```text

spawn_entity / insert_transform / insert_renderable / transform / renderable / alive_renderables 外部 API 保持可用。
RenderSnapshot 继续作为 compatibility output。
```

正式改变：

```text
World 不再以 HashMap<EntityId, Transform / Renderable> 作为正式主存储。
World 通过 ArchetypeTable 保存实体组件行。
添加 / 删除组件会迁移 Entity 所在 Archetype。
Transform / Renderable 写入会记录 dirty hook。
```
