# EngineHostLoop / RendererFeatureBuilder / Minimal Renderer v1 完成记录

## 需求目标

按施工文档完成 Rust Native Runtime 的第一版 CPU 侧正式一帧闭环：

```text
EngineHostLoop
  -> RuntimeFrame / FrameLoop
  -> World / DirtyRecord
  -> RenderExtract
  -> RenderCommandQueue normalize / merge
  -> RenderSceneState.apply_batch
  -> RendererFeatureBuilder
  -> MinimalRendererFrame
  -> RenderFrameReport / RuntimeTrace / FrameHash
```

对应施工文档：

```text
施工文档/已完成/57-当前可自动化施工文档-EngineHostLoop-RendererFeatureBuilder-MinimalRenderer-v1.md
```

## 框架定位

本轮只实现 headless CPU 数据闭环。

本轮不做：

```text
真实 OS window
真实 wgpu surface
真实 Render Thread
真实 RDG / RHI
真实 GPU buffer / texture / shader / pipeline
真实 draw call
Native Editor Viewport texture 嵌入
Asset DB / Importer
IR -> Rust AOT
Android / iOS / Web 打包
```

### A2 RuntimeFrame 正式链路

在 `FrameLoop` 中新增正式 runtime frame 方法：

```text
tick_runtime_frame(
  world: &mut World,
  render_scene: &mut RenderSceneState,
  extract: &mut RenderExtractContext,
) -> RuntimeFrameOutput
```

执行顺序：

```text
FrameBegin
FixedUpdate
Update
LateUpdate
RenderExtract
RenderCommandQueue.normalize_merge
RenderSceneState.apply_batch
RenderFrameReport
FrameHash
FrameEnd
```

旧 `tick(&World) -> FrameOutput` 保留为兼容路径，仍输出 `RenderSnapshot compatibility output`。

覆盖测试：

```text
runtime_frame_consumes_dirty_records_once
runtime_frame_applies_render_commands_to_scene_state
runtime_frame_hash_is_stable_for_same_input
```


`EditorPause` 不推进 runtime，也不消费 dirty records。

## 当前结论

本轮完成了 57 施工文档的要求。

当前正式 runtime CPU 链路已经成立：

```text
EngineHostLoop
  -> FrameLoop::tick_runtime_frame
  -> RenderExtractContext
  -> RenderCommandQueue
  -> RenderSceneState
  -> RendererFeatureBuilder
  -> MinimalRenderer
```

`RenderSnapshot` 仍保留为 compatibility output，但没有成为新 renderer 输入。
