## 关键修正

实现 normalize / merge 时发现一个排序问题：

```text
如果 sort_key 把 RemoveProxy 固定排在 AddProxy 前面，
同帧 AddProxy -> RemoveProxy 会被错误重排，无法归并为 NoOp。
```

最终修正：

```text
RenderCommandSortKey 在同一 entity 内优先按 command_id 保留时间顺序。
lifecycle_order / command_type_order 只作为辅助排序字段。
ObjectCommandSlot 内处理生命周期语义。
```

这符合既定规则：

```text
生命周期命令不能被普通排序破坏。
普通 Update 才允许 last value wins。
```
