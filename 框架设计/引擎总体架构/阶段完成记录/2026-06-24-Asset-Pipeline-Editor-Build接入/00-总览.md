## 已实现能力

### FileChangeBatch / FileChangeImportPlan

```text
added -> import
modified -> reimport
deleted -> mark-missing
moved -> move-and-reimport
unknown moved source -> conflict report
```

删除资源不会物理删除文件，不会自动改引用，只把资源标记为 missing 并输出受影响资源。

### Editor Bridge

```text
beginEditorAssetPipelineImport
applyEditorAssetPipelineImport
createAssetPipelineEditorState
assertEditorProjectMutationAllowed
```

导入期间会进入 AssetImportLock。普通 Project 修改被阻止；导入任务自身可以受控提交结果。

编辑器状态只读展示：

```text
locked
activeTransactionId
recentReports
recentIssues
repairCandidates
```

AI 修复候选仍然是 report-only / requiresUserApproval / canAutoApply=false。

### Build Bridge

```text
createBuildAssetManifest
createBuildAssetPreflightReport
getAffectedRuntimeAssets
```

BuildAssetManifest 从 AssetPipelineDatabase 生成，不重新扫描散文件。

规则：

```text
runtime required missing / failed -> error，构建预检失败。
editor-only missing / failed -> warning，构建预检不失败。
modified -> warning，提示需要 reimport。
无有效 artifact 的 runtime current asset -> error。
dependency cycle 进入 issue。
```

## Golden Scenario

测试中构造了最小 shooter 资源链：

```text
Texture: player_ship.png
Material: player_ship.material.json -> Texture
Prefab: player_ship.prefab.json -> Material
Scene: main.scene.json -> Prefab
Logic: shooter_rule.ir.json -> Texture
```

验证内容：

```text
FileChangeBatch added 能导入全部资源。
DependencyGraph 能生成 Texture -> Material -> Prefab -> Scene 的反向受影响链。
BuildAssetManifest 包含 runtime required assets。
Build preflight passed。
删除 runtime texture 后，preflight failed。
把删除资源标为 editor-only 后，preflight passed with warning。
修改 texture 后，affected runtime assets 能追到 scene。
失败导入能进入 recentReports 并生成 report-only repair candidate。
```
