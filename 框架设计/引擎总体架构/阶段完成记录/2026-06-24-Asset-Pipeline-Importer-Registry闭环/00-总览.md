
### A2 BatchImportReport

新增：

```text
BatchImportReport
createBatchImportReport
```

规则：

```text
批量导入不是整批原子回滚。
成功 AssetImportUnit 提交。
失败 AssetImportUnit 进入 failed report。
依赖失败进入 blocked / dependency_failed。
```

### A3 ImportBatchPlan / ImportQueue / ImportWorker

新增：

```text
ImportBatchPlan
ImportQueue
ImportWorkerResult
createImportBatchPlan
createImportQueue
runImportWorker
```

落点：

```text
src/engine/assetPipelineFileSync.ts
```

行为：

```text
FileChangeBatch 先转换成 AssetImportUnit。
ImportWorker 串行执行 Unit。
成功 Unit 通过 ImportTransaction 提交。
失败 Unit 不污染成功资源。
missing / conflict / dependency_failed 均进入结构化报告。
```

### A7 Golden Scenario

新增测试：

```text
scripts/test-asset-pipeline-importer-registry.cjs
```

新增命令：

```powershell
npm.cmd run test:assetpipelineimporterregistry
```

覆盖场景：

```text
Texture + Material + Prefab 成功导入。
Texture 被 Material 引用，Material 被 Prefab 引用，Registry 能查 referencer / affected assets。
导入失败资源进入 failed。
依赖失败资源进入 blocked。
资源移动时保留 guid，更新 sourcePath，AssetRef 不变化。
Registry rebuild 后与增量 update 结果一致。
GlobalImportBusyState 阻止读写。
```
