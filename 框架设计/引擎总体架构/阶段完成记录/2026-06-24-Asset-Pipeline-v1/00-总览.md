# Asset Pipeline v1 完成记录

## 需求目标

按施工文档完成 Asset Pipeline v1 的最小可测试闭环：

```text
ImportPlan
  -> ImportTransaction
  -> ImporterContract
  -> ImportResult
  -> DependencyRecord
  -> ArtifactRecord
  -> Asset DB atomic commit
  -> ImportReport / CacheReport / DependencyReport
```

对应施工文档：

```text
施工文档/已完成/58-当前可自动化施工文档-Asset-Pipeline-v1.md
```

## 框架定位

本轮实现的是纯数据 / 纯函数 Asset Pipeline v1 最小闭环。

本轮不做：

```text
远程缓存
团队共享缓存
复杂 LRU
完整模型骨骼 / 动画 retarget
完整 shader 编译管线
资源高级预览缓存
运行时动态依赖追踪
依赖图高级可视化
自动修复资源引用
真实 GPU 资源上传
真实 Bundle 构建
真实热更 mount
```

### A1 Asset Pipeline v1 类型边界

新增：

```text
AssetRefV1
SubAsset
ImportedAsset
ImportResult
ImportReport
ReimportReport
AssetPipelineDatabase
AssetPipelineRecord
```

规则：

```text
AssetRefV1 不允许 runtimeHandle / gpuResourceId / bundlePath / cookedPath。
SubAsset 不生成独立 guid。
SubAsset identity = parent guid + kind + id。
```

### A2 ImporterContract Registry v1

新增默认 importer registry：

```text
Texture
Audio
Model
Material
Scene
Prefab
DSL-IR
```

每个 contract 均包含：

```text
id / version / assetType / extensions
settingsSchema / platformSettingsSchema / outputSchema
dependencyPolicy / cachePolicy / reimportPolicy / diagnosticsSchema
```

### A3 ImportResult / SubAsset v1

实现：

```text
Importer 输出 ImportResult。
ModelImporter 输出 Mesh / Material / Animation subAssets。
SubAsset id 稳定生成。
SubAsset ref 使用对象结构，不使用字符串路径。
```

### A4 Artifact Cache D-min

实现：

```text
ArtifactKey
ArtifactRecord
ArtifactStore
ArtifactResolver
CacheReport
Local project-local namespace
```

支持：

```text
cache hit
sourceHash invalidated
dependencyHash invalidated
clear and rebuild
changed input report
```

### A5 Dependency Graph D-min

实现：

```text
DependencyRecord
DependencyGraph
ReverseDependencyIndex
DependencyHash
DependencyReport
```

支持：

```text
直接依赖记录
反向依赖查询
依赖 hash
runtime cycle warning
import cycle error
```

### A6 ImportTransaction 原子提交

实现：

```text
createImportTransaction
runImporterInTransaction
prepareTransactionArtifact
commitImportTransaction
```

规则：

```text
Importer 不直接写 Asset DB。
失败 transaction 不污染旧 AssetPipelineDatabase。
失败生成 ImportReport。
```

### A7 Reimport C 规则

实现：

```text
createReimportReport
```

支持：

```text
main asset guid 保持。
SubAsset 按 kind + id 匹配。
removed / renameCandidate 进入 ReimportReport。
不自动迁移引用。
```

### A8 最小 Importer

实现：

```text

LogicImporter
```

边界：

```text
不做完整美术资源解析。
```
