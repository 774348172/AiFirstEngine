# Asset Pipeline ProjectDock / Console UI 接入完成记录

日期：2026-06-25

## 本轮目标

```text
AssetRegistry -> ProjectDock
ImportReport / BatchImportReport / RegistryReport -> ConsoleDock
Console issue -> ProjectDock asset selection
```

本轮只做 Asset Pipeline UI 数据链路，不做真实 OS file watcher、GPU 上传、Bundle 二进制打包、平台 cook 或完整 Inspector importer setting UI。

```text
Console issue jump target -> existing asset jump path
legacy project.assets -> temporary AssetRegistry fallback
```

## 关键边界

```text
ProjectDock 不直接扫描文件。
ProjectDock 不直接修改 AssetPipelineDatabase。
ConsoleDock 不自动修复资源。
ConsoleDock 只显示 report / issue / jump target。
AI 读取 AssetRegistry / Report 派生 ViewModel，不读取 DOM 或 UI 内部状态。
```

当前 App 还没有真实持久化 AssetRegistry 状态，因此本轮加入了 legacy fallback：

```text
project.assets -> createLegacyAssetRegistryFromProject -> EditorAssetPipelinePanelViewModel
```

这个 fallback 是过渡接线，不是新的资源真相。后续真实 AssetRegistry 进入 App 后，ProjectDock / ConsoleDock 继续消费同一个 ViewModel。
