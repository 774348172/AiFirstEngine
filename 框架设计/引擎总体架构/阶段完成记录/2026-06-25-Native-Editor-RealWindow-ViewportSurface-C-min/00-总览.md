## 关键规则落实

```text
所有 C-min 能力默认 headless 可测。
真实 OS window / real wgpu surface 不作为默认自动化依赖。
real-window feature 仍只作为本机 smoke gate / 平台兼容 gate。
ViewportHost 只保存 viewport 区域、尺寸、焦点、输出类型和占位状态。
Editor UI Renderer 不画 3D world。
Runtime Renderer 不画编辑器面板。
RealWindowGateReport 可 JSON 序列化，供 AI / 人类查错。
```
