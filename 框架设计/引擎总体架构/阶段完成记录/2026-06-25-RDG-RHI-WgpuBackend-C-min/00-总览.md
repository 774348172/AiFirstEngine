
## 当前结论

真实 GPU 输出路线的第一层门禁已经建立：

```text
RenderSceneState
  -> RuntimeRenderer
  -> RDG-min
  -> RHI-min
  -> Headless backend report
```

下一步不应该继续扩大 RDG/RHI 复杂度。  
更高优先级是把 Runtime Package / AssetRegistry / cooked asset 接入 Rust Runtime，并让 Scene / Prefab / Entity 能实例化到 Rust ECS，然后再把 RuntimeRenderer 输出接到真实 viewport texture / surface。
