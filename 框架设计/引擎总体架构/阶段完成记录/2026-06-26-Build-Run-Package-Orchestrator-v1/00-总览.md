```text

  -> BuildRunReport
```

## 关键规则落实

```text
Build / Run v1 只支持 dev-desktop / dev-run。
Runtime 输入边界固定为 staged runtime-package / cooked-assets。
Build / Run 不把编辑器内存 Project Object 交给 Runtime。
Build / Run 不执行项目逻辑，ProjectLogicRunner 仍属于 Runtime 内部。
runtimeExecutable=auto 找不到 Rust runtime binary 时生成 RuntimeExecutableError。
不伪造 ai_first_runtime.exe。
不回退到 TypeScript Runtime。
headless / launch=false 测试只生成 launch command，不打开真实窗口。
```
