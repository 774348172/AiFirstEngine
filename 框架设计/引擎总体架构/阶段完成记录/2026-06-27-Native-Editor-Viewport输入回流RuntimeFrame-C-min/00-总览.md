## 完成内容

本轮完成 Native Editor Viewport 输入进入 Runtime Action / Game Frame 的 C-min 闭环：

```text
EditorInputEvent
  -> ViewportInputGateway
  -> ViewportInputRoute
  -> RuntimeInputFrame
  -> InputResolver
  -> ActionSnapshot
  -> EngineHostLoop / FrameLoop
  -> ProjectLogicRunner
  -> ECS dirty
  -> RenderExtract
```

## 验证覆盖

已覆盖：

```text
UI hit -> UiConsumed，不进入 Runtime。
SceneView pointer -> SceneCameraCommand，不进入 Runtime。
GameView focused KeyDown Space -> RuntimeInputFrame。
GameView unfocused KeyDown Space -> Ignored。
Space -> action.fire。
PointerMove -> action.pointer。
WASD -> action.move。
ActionSnapshot -> ProjectLogicRunner。
ProjectLogicRunner 写 Transform。
Transform dirty -> RenderExtract。
RuntimeTrace 记录 InputSnapshotReady / route / action。
```
