## 本轮目标

把编辑器 Play / Stop 从临时 `playing bool` 收敛为 Editor 侧 PlaySession 编排层。

第一版只实现 C-min：

```text
Toolbar Play / Pause
  -> EditorSession
  -> PlaySessionRequest / Stop
  -> PlaySessionController
  -> DefaultGameRunOrchestrator Headless path
  -> PlaySessionReport
  -> Console / Toolbar 最小反馈
```
