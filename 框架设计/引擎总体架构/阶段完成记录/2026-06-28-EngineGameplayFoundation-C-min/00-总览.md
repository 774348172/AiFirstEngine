# Engine Gameplay Foundation C-min 阶段完成记录

日期：2026-06-28

## 1. 阶段定位

本阶段完成 `engine_runtime` 的通用 ECS 访问底座。

它不是项目玩法框架，也不是 Shooter / RPG / Action 的专用系统。它只提供项目规则访问 Runtime ECS 时需要的中性能力：

```text
Query
Read
Write
Structural Command
Trace
```

硬边界：

```text
引擎只提供底座能力，不为特定项目增加规则。
```

本阶段没有新增 `Bullet / Enemy / Health / Damage / Score` 等项目语义 API。

## 2. 已完成能力

### ComponentValue / RuntimeValue

新增通用运行时值表达：

```text
Null
Bool
I64
F64
String
Vec2
Vec3
Color
EntityRef
AssetRef
Object
Array
```

`Dynamic Component` 从 debug string 升级为可读写的 `RuntimeValue`。

### QuerySpec

新增最小 ECS 查询：

```text
all
none
include_disabled
limit
stable_order = EntityId
```

第一版不支持业务语义查询、字段过滤、距离查询、目标选择等项目规则。

### Generic Read / Write

新增通用组件读取和写入：

```text
read_component(entity, component_type)
write_component(entity, component_type, value)
write_component_field(entity, component_type, field_path, value)
```

`FieldPath v1` 只支持简单点路径，不支持数组表达式和查询表达式。

### GameplayCommandBuffer

新增结构变更命令缓冲：

```text
SpawnEntity
DespawnEntity
AddComponent
RemoveComponent
SetParent
```

结构变化由 `ProjectLogicRunner` 在规则执行后统一 apply。

### GameplayTraceRecord

新增通用 Gameplay Trace：

```text
query
read
write
command_enqueue
command_apply
```

Trace 记录 rule / frame / entity / component / field / before / after / result 等中性字段，不记录项目玩法字段。
