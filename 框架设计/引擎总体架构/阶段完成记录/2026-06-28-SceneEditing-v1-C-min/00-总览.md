## 关键规则落地情况

已落地：

```text
EditorSceneDocument 是编辑真相。
Runtime World 不是编辑真相。
PreviewWorld 是从 EditorSceneDocument 派生的预览结果。
AI / UI / Test 只能生成 SceneEditCommand。
SceneEditCommand 必须进入 SceneEditTransaction。
Transaction 负责验证、应用、dirty、undo、diagnostic。
Save 必须走 SceneSavePipeline。
PreviewWorldSync 不清除 dirty。
```
