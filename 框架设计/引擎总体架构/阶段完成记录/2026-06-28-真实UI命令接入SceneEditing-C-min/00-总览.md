# 2026-06-28 真实 UI 命令接入 SceneEditing C-min 阶段完成记录

## 完成范围

本阶段完成 86 施工文档要求的 C-min 闭环：真实 UI 命令通过 `UiCommandPayload -> EditorSession::execute_command -> SceneEditCommand -> SceneEditTransaction` 进入 85 已完成的 Scene Editing 内核。

## 已实现模块

- `editor_ui_model`：补齐 Scene Editing UI command payload，并验证序列化和 AI 可读结构。
- `editor_core`：`EditorSession::execute_command` 支持 Open / Select / Create / Delete / SetTransform / SetComponentField / Save / Undo / Redo Scene 命令。
- `editor_input`：增加 Hierarchy / Toolbar / Viewport / Inspector 的 C-min Scene Editing 命令路由 helper，不直接写 SceneDocument。
- `editor_host`：验证 Host 只把 `UiCommand` 交给 `EditorSession`，不直接调用 SceneEditTransaction 或写 SceneDocument。

## 明确未实现

- 未实现真实 Viewport Gizmo。
- 未实现复杂 picking。
- 未实现复杂 Inspector schema renderer。
- 未实现 Prefab Mode、Asset 拖入 Scene、多选批量编辑。

## 关键规则落实

- UI 层只表达用户意图，不维护第二套 Scene 状态。
- Scene 源数据修改继续统一走 `SceneEditTransaction`。
- 保存继续走 `SceneSavePipeline`。
- AI 仍可生成 `SceneEditCommand`，但必须由 `EditorSession` 执行。
