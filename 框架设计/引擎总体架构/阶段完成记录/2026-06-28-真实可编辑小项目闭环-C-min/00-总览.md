# 2026-06-28 真实可编辑小项目闭环 C-min 阶段完成记录

## 本阶段目标

把已经完成的编辑器、Scene Editing、Play Session、Runtime、Console、Trace 能力串成一个可自动化验证的小项目编辑闭环：

```text
open default scene
  -> hierarchy / inspector
  -> transform edit
  -> dirty
  -> save
  -> undo / redo
  -> play
  -> Console / Trace / EditableProjectLoopReport
```

本阶段不是新增一个大型编辑器系统，而是验证现有长期架构能否支撑 Unity / UE / Godot 式核心编辑工作流。

## 保留的架构边界

```text
EditorSceneDocument 是编辑真相。
Runtime World 不是编辑真相。
UI / AI / Test 不直接写 Scene 文件。
UI 行为必须先转 UiCommandPayload。
EditorSession 是 Editor Core 的统一入口。
Scene 修改必须走 SceneEditTransaction。
Save 必须走 SceneSavePipeline。
Play / Run 必须走 PlaySessionController。
默认自动化测试不依赖真实窗口。
```
