## 架构边界

```text
Game Thread 不直接读写 RenderSceneState。
Render Thread 不直接读 ECS。
跨线程提交边界统一为 RenderFramePacket / RenderSubmissionReport。
RenderFramePacket 是 owned 数据，不持有借用。
Headless / CI 也走同一套 submit / report 边界。
```
