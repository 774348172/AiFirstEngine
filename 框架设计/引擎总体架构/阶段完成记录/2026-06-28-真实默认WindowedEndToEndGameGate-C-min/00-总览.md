## 关键规则落地

```text
用户默认 Run 的长期方向是真实 Windowed Runtime。
默认自动化 Gate 走 Headless Runtime Gate。
Headless 不是第二套引擎，只是不打开真实窗口的测试承载方式。
Windowed / Headless 共享 Runtime Package / Scenario / FrameLimit / EngineHostLoop / Logic / ECS / RenderThread 主链路。
差异只允许存在于 Window / Surface / Present 适配层。
EndToEndGameRunReport 是用户和 AI 查错入口。
```
