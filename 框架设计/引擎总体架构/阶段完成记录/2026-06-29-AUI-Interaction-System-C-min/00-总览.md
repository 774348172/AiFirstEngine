实现规则：

```text
只处理 PointerDown / PointerUp / PointerMove。
只命中 visible=true 且 interactable=true 的节点作为可消费目标。
按 tree_order 倒序命中，后绘制节点优先。
PointerDown / PointerUp / PointerMove 命中后生成对应 AuiCommand。
PointerMove 同时生成 Hover。
PointerDown 与 PointerUp 命中同一节点时生成 Click。
Keyboard / Gamepad / Drag / Scroll / IME / Focus / Capture 暂不实现。
```

## 架构边界

本阶段没有让 `InputResolver` 依赖 AUI。
AUI 只输出 `consumed / commands / trace`，后续 Runtime 主循环或窗口层根据 consumed 决定是否继续交给 Gameplay InputMapping。

AUI Command 保持 UI 通用，不包含项目玩法语义。
