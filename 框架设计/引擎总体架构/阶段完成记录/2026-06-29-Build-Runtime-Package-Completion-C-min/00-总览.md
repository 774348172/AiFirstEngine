扩展原因：

```text
Runtime Package / Runtime Asset 正式 schema 原本只支持 Deserialize。
RuntimePackageBuilder 需要复用同一套 schema 写出包，因此补充 Serialize。
这避免了 Builder 手写第二套 JSON 结构。
```

## 4. 关键规则落实

```text
RuntimePackageBuilder 是内容转换层，不是 BuildRunOrchestrator。
Builder 复用 engine_runtime::runtime_package 的正式 Runtime Package schema。
Builder 不执行项目逻辑。
Builder 不做 IR -> Rust AOT。
Builder 不做平台发布、签名、二进制 bundle。
Runtime 仍通过 load_runtime_package 读取生成包。
```
