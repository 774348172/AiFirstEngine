## 完成内容

本阶段完成 Input Mapping Asset 第一版运行时底座：

```text
Editor Raw Input
  -> RuntimeInputFrame
  -> InputMappingAsset
  -> InputResolver
  -> ActionSnapshot
  -> ProjectLogicRunner / EngineHostLoop
```

具体实现：

```text
1. 新增 engine_runtime::input_mapping 模块。
2. 新增 RuntimeInputFrame / RuntimeInputEvent / RuntimePointerButton。
3. 新增 InputMappingAsset / InputActionDefinition / InputContextDefinition / InputBindingDefinition。
4. 新增 InputProcessorPreset / InputTriggerPreset / PlatformInputOverride。
5. 新增 InputMappingReport / InputMappingDiagnostic / InputResolveResult。
6. 新增 InputResolver，把 RuntimeInputFrame 解析为 ActionSnapshot。
7. 支持 Button / Axis2 / Pointer 的 C-min 解析。
8. 支持 context priority / consume_input 的确定性解析。
9. 支持 keyboard / mouse 基础 device_path 验证，并保留 gamepad device_path 占位。
10. editor_window_winit 不再维护临时 InputResolver，只负责生成 RuntimeInputFrame。
```
