## 架构边界

Runtime Time Service 是引擎底座。
项目侧可以用 TimeContext / Timer / Cooldown helper 自己实现发射间隔、冷却、刷新节奏、生命周期等规则。
引擎不理解 Bullet / Enemy / Wave / Skill 等玩法语义。
