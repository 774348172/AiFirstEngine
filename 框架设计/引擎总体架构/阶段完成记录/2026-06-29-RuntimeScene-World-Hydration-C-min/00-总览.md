## 4. 关键规则落地

```text
RuntimeScene Hydration 是 RuntimePackage 进入 World 的正式入口。
Hydration 底层复用 RuntimeInstanceLoader。
scene_loader 暂保留为历史测试工具，不再作为真实 runtime 入口扩展。
Hydration 通过 World 写入 API 产生 initial dirty records。
Hydration 不执行项目规则，不引入项目玩法概念。
```

## 5. 施工中暴露并修复的问题

旧测试 runtime package 的 `asset-manifest` 为空。

在旧 `scene_loader` 路线下这不会暴露，因为它绕过资源系统；切到 Hydration 后，scene asset 必须存在于 runtime asset index。已修复最小测试包 fixture，把 `scene-main` 作为 `scene` asset 登记进 `startup` bundle。
