## 完成内容

本阶段完成 Sprite2D 第一版 CPU/headless 数据闭环：

```text
SpriteRenderer2D / SpritePayload
  -> RenderSceneState
  -> RendererFeatureDrawItem
  -> deterministic draw item sort_key
  -> MinimalRenderer / RuntimeRenderer report
```

具体实现：

```text
1. 新增 engine.sprite_renderer2d 组件类型。
2. 新增 SpriteRenderer2D 通用视觉组件字段和默认值。
3. 扩展 SpritePayload：
   sprite_ref / material_ref / color / flip_x / flip_y / sorting_layer / order_in_layer / sort_z。
4. 扩展 RendererFeatureDrawItem：
   sprite_ref / sorting_layer / order_in_layer / sort_z / sort_key。
5. 新增 DrawItemSortKey：
   render_domain_order / sorting_layer / order_in_layer / sort_z_quantized / stable_proxy_id。
6. RendererFeatureBuilder 按 sort_key 稳定输出 draw_items。
7. MinimalRenderer report 可读取 sprite_ref / sort_key。
8. RuntimeRenderer 新增 DrawSpriteBasic CPU/headless 命令链路。
9. RHI command plan 新增 SpriteBasic headless draw kind。
```
