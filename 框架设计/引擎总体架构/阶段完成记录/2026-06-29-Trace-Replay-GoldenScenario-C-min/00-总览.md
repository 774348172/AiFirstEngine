## 边界确认

Golden Scenario 不再被定义为万能复杂需求验收系统。

正式规则是：

```text
Golden Scenario 只负责端到端关键流程回归。
复杂需求必须组合 Static Validation / Logic Test / Contract Test / Golden Scenario / Stress Scenario / Trace Diff。
```

本阶段没有新增任何项目玩法语义 API。引擎层保持通用字段：

```text
entity
component
field
trace
query
command
frame
report
```

禁止进入引擎层的玩法词仍然包括：

```text
enemy
bullet
damage
health
score
wave
skill
weapon
inventory
quest
boss
```
