# World Projection Adapter 统一跨域同步收敛完成记录

## 目标

把 RuntimeScene Hydration、RenderExtract、Physics2DBridge、RenderAssetBridge、AUI Render Extract、SpriteRenderer2D Bridge 统一归口到 `World Projection / Projection Adapter` 心智模型下。

本轮不新增项目玩法规则，只补引擎底座能力：

```text
RuntimePackage / ECS World = 主真相
RenderSceneState / Physics2DWorld / GPU Resource / AUI DrawList = 派生运行域
跨域同步统一用 Projection / Projection Adapter 描述
旧 Bridge 命名可作为历史代码名保留
```

## 暴露问题

`serde(rename_all = "camelCase")` 会把 `sprite_renderer2d` 转成 `spriteRenderer2d`，但项目数据约定使用 `spriteRenderer2D`。

处理方式：

```rust
#[serde(default, rename = "spriteRenderer2D", alias = "spriteRenderer2d")]
```

这保留正式字段名，同时兼容自动 camelCase 形式。
