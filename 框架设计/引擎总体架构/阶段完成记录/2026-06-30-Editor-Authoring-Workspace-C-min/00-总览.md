## 2. 真实行为变化

NativeEditorApplication 现在持有 `EditorAuthoringWorkspace`。

命令链路变为：

```text
WindowEvent / HitRegion / AI Proposal / Test Command
  -> UiCommand
  -> EditorAuthoringWorkspace::normalize_command
  -> EditorCommandSystem
  -> EditorSession
  -> SceneEditTransaction / CommandTransaction
  -> EditorAuthoringWorkspace::record_command_result
  -> EditorUiModel rebuild
```

Hierarchy 面板产生的旧 `SelectEntity` 会在 Workspace 归口为：

```text
SelectSceneEntity
```

这确认了面板级命令不再直接作为编辑真相入口。
