## 行为变化

点击 disabled command 不再静默失败。

第一版行为：

```text
enabled hit region -> 继续生成 UiCommand 并进入 EditorSession / Transaction
disabled hit region -> 不生成 UiCommand，生成 EditorCommandFeedback
no hit region -> 保持 no-hit diagnostic
```

现在 `NativeEditorApplicationReport` 可以直接告诉 AI / 用户：

```text
最后点击的 command_id
命令是否 disabled / rejected / failed / committed
disabled 或失败原因
当前 hover / pressed 的 hit region
```
