## 2. 架构结论

当前 Native Editor 不再只是静态 UI 展示器。

新的长期入口是：

```text
WindowEvent
  -> NativeEditorApplication
  -> FocusInputSystem
  -> EditorCommandSystem
  -> EditorSession
  -> EditorTransactionService
  -> EditorUiModelComposer
  -> SelfUiRenderer / UiDrawList
  -> WGPU present
```
