# 2026-06-30 Native Editor FontSystem v1 完成记录

## 目标

把 Native Editor 文本从 112 的内置 ASCII 点阵 fallback，升级为第一版真实 FontSystem：

```text
DrawCommand::Text
  -> EditorFontSystem
  -> ab_glyph rasterize
  -> CPU glyph atlas
  -> WGPU R8 glyph atlas texture
  -> textured glyph quads
```

## 实际修改

代码：

```text
rust/crates/editor_wgpu_renderer/Cargo.toml
rust/crates/editor_wgpu_renderer/src/lib.rs
```

主要内容：

```text
新增 ab_glyph 依赖。
新增 EditorFontSystem / CpuGlyphAtlas / GlyphKey / GlyphAtlasEntry。
UiGpuDrawPlan 新增 font_backend / font_source / glyph atlas / text_glyphs 等字段。
headless 路径可生成真实 glyph layout 与 atlas alpha 数据。
real-wgpu 路径新增 R8Unorm glyph atlas texture、text bind group、text pipeline、TextVertex。
系统字体加载失败时继续使用 112 BuiltinDebugFont fallback。
```
