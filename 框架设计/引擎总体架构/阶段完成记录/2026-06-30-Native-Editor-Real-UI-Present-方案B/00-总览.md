## 本轮完成

新增正式 UI GPU present 层：

```text
rust/crates/editor_wgpu_renderer
```

核心能力：

```text
UiDrawList -> UiGpuDrawPlan
HeadlessUiGpuRenderer
RealUiPresentReport
RealWgpuUiRenderer
Rect -> GPU triangles
ViewportTextureSlot -> placeholder rect
Text -> skipped_text_count
```

接入：

```text
editor_window_winit 依赖 editor_wgpu_renderer。
HeadlessNativeEditorWindowApp 使用 HeadlessUiGpuRenderer。
real-window 路径创建 RealWgpuUiRenderer。
RedrawRequested 调用 renderer.present(draw_list)。
真实窗口路径不再把“生成 DrawList”伪装成 presented。
editor_host real-window feature 测试不在单元测试线程直接创建 winit EventLoop。
```

## 架构边界

确认规则：

```text
editor_window_winit = OS Window / EventLoop / Surface lifecycle。
editor_ui_renderer = EditorUiModel -> UiDrawList / HitRegion。
editor_wgpu_renderer = UiDrawList -> GPU commands -> present。
Editor Core 不依赖 winit / wgpu。
UI GPU renderer 不读取 EditorSession，不执行 UiCommand，不调用 engine_runtime。
```

## 当前限制

```text
真实文字渲染。
字体 atlas。
真实 viewport texture sampling。
复杂 clipping / batching。
多窗口。
完整 Dock / Panel 控件。
```

真实窗口第一版可见目标：

```text
clear color
panel rect
toolbar / hierarchy / inspector / bottom panel 几何
viewport placeholder rect
```
