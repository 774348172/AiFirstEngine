## 本轮完成

在 `editor_wgpu_renderer` 中完成 Native Editor 第一版文本绘制：

```text
DrawCommand::Text
  -> BuiltinDebugFont
  -> TextGlyph rects
  -> existing WGPU rectangle pipeline
```

新增能力：

```text
UiGpuDrawableRectSource::TextGlyph
BuiltinDebugFont
TextRenderStats
UiGpuDrawPlan.text_command_count
UiGpuDrawPlan.rendered_glyph_count
UiGpuDrawPlan.unsupported_glyph_count
RealUiPresentReport.text_command_count
RealUiPresentReport.rendered_glyph_count
RealUiPresentReport.unsupported_glyph_count
```

行为规则：

```text
ASCII 文本不再默认 skipped。
Text C-min 只支持 ASCII 32..126。
小写字母按大写字形绘制。
不支持字符使用 '?' fallback，并计入 unsupported_glyph_count。
rect 太小或 size 太小才计入 skipped_text_count。
```

## 当前限制

这不是最终 Font System。

第一版不支持：

```text
真实字体文件。
字体 atlas。
中文渲染。
复杂 shaping。
文本换行。
富文本。
clipping。
SDF / MSDF。
```
