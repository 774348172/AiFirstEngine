# Runtime WGPU Surface 注入 / Windowed Player Present v1 完成记录

## 目标

把真实 `wgpu::Surface` 接入 Runtime `RealWgpuBackend`，形成：

```text
WindowedRuntimeHost
  -> winit Window / wgpu Surface
  -> EngineHostLoop
  -> RuntimeRenderer
  -> RhiCommandPlan v2
  -> RealWgpuBackend
  -> surface present
```

长期边界保持不变：

```text
RuntimeRenderer 不知道 winit / wgpu Surface / swapchain。
WindowedRuntimeHost 持有窗口和 surface 生命周期。
RealWgpuBackend 执行 RHI command plan。
Headless 自动化测试继续作为默认稳定路径。
真实窗口路径通过 feature gate 和 ignored smoke 测试验证。
```
