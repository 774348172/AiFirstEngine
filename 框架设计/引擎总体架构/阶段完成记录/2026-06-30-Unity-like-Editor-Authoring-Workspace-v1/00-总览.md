# Unity-like Editor Authoring Workspace v1 完成记录

## 目标

把 `126-Unity-like Editor Authoring Workspace v1` 落到代码层，让 Project Launcher 打开/创建项目之后进入可编辑工作区，并具备最小 Unity-like 闭环：

```text
ProjectBrowser
-> open .scene.json
-> Hierarchy / Inspector / Viewport refresh
-> Toolbar Save / Undo / Redo / Play command surface
-> Console / AI context readable
```

## 实际修改

```text
rust/crates/editor_ui_model
  - 新增 ProjectBrowserModel / ProjectBrowserEntry / ProjectBrowserEntryKind。
  - 新增 WorkspaceViewMode。
  - EditorUiModel 增加 project_browser / workspace_view_mode。
  - UiCommandPayload 增加 SelectProjectBrowserEntry / OpenProjectBrowserEntry / SetWorkspaceViewMode。
  - UiCommandSource 增加 ProjectBrowser。

rust/crates/editor_core
  - EditorSession 增加 selected_project_browser_path / workspace_view_mode。
  - 打开/创建项目后构建 ProjectBrowser 条目：Assets、Scenes、Settings、Scenes/Main.scene.json。
  - OpenProjectBrowserEntry(.scene.json) 复用已有 OpenSceneDocument 链路。
  - Toolbar 增加 Save / Undo / Redo。
  - AI WorkspaceContext 读取 ProjectBrowser selected_path。

rust/crates/editor_ui_renderer
  - AuthoringWorkspace 右下区域绘制 ProjectBrowser。
  - 增加 ProjectBrowser row select 和 Open button hit region。

rust/crates/editor_input
  - ProjectBrowser hit -> SelectProjectBrowserEntry / OpenProjectBrowserEntry。
  - Toolbar hit 支持 Save / Undo / Redo。

rust/crates/editor_window_winit
  - 应用壳认识 ProjectBrowser focus panel。
  - EditorCommandSystem / command id 映射补齐 ProjectBrowser 新命令。
```

## 当前边界

```text
ProjectBrowser v1 只显示固定 C-min 条目，不做完整文件树扫描。
OpenProjectBrowserEntry v1 只支持 .scene.json。
SceneView / GameView 当前已有 WorkspaceViewMode 数据结构，但渲染表现仍是语义占位。
ProjectBrowser 暂时绘制在右下区域，后续可在 Dock/Layout 系统成熟后迁入正式 ProjectBrowser panel。
```
