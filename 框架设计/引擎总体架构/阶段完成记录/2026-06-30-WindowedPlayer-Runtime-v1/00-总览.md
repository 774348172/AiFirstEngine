# Windowed Player Runtime v1 完成记录

## 目标

按照 `118-WindowedPlayer-Runtime-v1完整方案.md` 建立 Player Runtime 主线的 engine-side gate：

```text
RuntimePackage
  -> Runtime World
  -> Asset Load
  -> GPU Resource Binding Descriptor
  -> RenderProjection
  -> RuntimeRenderer
  -> RhiCommandPlan
  -> RealWgpuBackend / Windowed Surface Gate
  -> Player FrameLoop
```

施工规则是方案 C 的长期架构，但按 gate 一个模块一个模块完成并测试。

## 当前边界

已完成的是 Player Runtime 主线的 engine-side gate，不是最终真实 Windowed Player，也不是最终商业级 Player：

```text
真实 OS window / surface lifecycle 仍在 editor_window_winit / native host 层。
engine_runtime 不直接依赖 winit / wgpu Surface。
GPU Resource Binding 目前产出 RenderResourceRequest descriptor，不在 runtime core 真实创建 GPU object。
真实 texture / mesh / material 的完整 backend upload 和可见游戏样例仍可继续加强。
```
