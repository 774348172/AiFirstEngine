## 2. 真实行为变化

EditorAuthoringWorkspace 现在持有：

```text
PropertyTree
PropertyEditBuffer
PropertyEditingWorkspaceState
```

字段编辑链路变为：

```text
InspectorField / HitRegion
  -> FocusTarget::TextField
  -> EditorAuthoringWorkspace::begin_property_edit
  -> PropertyEditBuffer
  -> PropertyEditCommand
  -> UiCommandPayload::SetSceneTransform / SetSceneComponentField
  -> EditorSession
  -> SceneEditTransaction
  -> EditorUiModel rebuild
```

这确认了：

```text
Inspector 控件不直接写 EditorSceneDocument。
属性编辑不绕过 EditorSession / Transaction。
完整 IME / 富文本 / 数组 / 嵌套对象 / 颜色 / 曲线 / 自定义 Inspector 插件后续都挂在同一套 Property Editing Framework 下。
```

## 3. 已验证能力

已验证：

```text
PropertyPath 能解析 transform.localPosition。
PropertyTree 能从 InspectorModel 构建属性节点。
PropertyValue 覆盖 Color / Array / Object / Curve / RichText 等高级类型。
PropertyEditBuffer 能 begin / input / commit / cancel。
TextCompositionState 能记录 IME preedit / committed text。
Transform Vec3 能提交为 SetSceneTransform。
Component 单层字段能提交为 SetSceneComponentField。

点击 InspectorField 能聚焦属性编辑缓冲。
提交聚焦字段能通过 Transaction 修改 Scene。
```
