# M3 Native Windowed Player Productization v1 完成记录

## 完成内容

按照 `133-M3-Native-Windowed-Player-Productization-v1方案.md` 和施工文档完成第一版 Native Player 产品化入口。

新增能力：

```text
runtime_cli run-native-player
--package 可选覆盖 RuntimePackage
--report 可选覆盖报告路径
--frames 控制自动化帧数
--headless-gate 走 WindowedPlayerHost headless gate
--mode windowed 返回 native host handoff 结构化报告
```

默认路径：

```text
package:
  1. --package
  2. current_exe_dir/data/runtime_package
  3. current_dir/data/runtime_package

report:
  1. --report
  2. current_exe_dir/reports/windowed-player-run-report.json
  3. current_dir/reports/windowed-player-run-report.json
```

## 关键边界

`engine_runtime` 继续不创建 OS window，不拥有 winit/wgpu surface。

M3 v1 固定的是产品化启动契约：

```text
RuntimePackage
  -> Native Player launch contract
  -> path discovery
  -> headless automation gate
  -> windowed native host handoff
  -> structured report
```

真实 OS window / WGPU surface / continuous present 仍属于后续 native host 接入，但必须复用本阶段的 request/report/path contract。
