# M4 Native Player WindowHost / Runtime Present Integration v1 完成记录

## 完成内容

按照 `134-M4-Native-Player-WindowHost-RuntimePresentIntegration-v1方案.md` 和施工文档完成第一版 Native Player Host 集成。

新增：

```text
rust/crates/runtime_player_winit
```

核心能力：

```text
NativePlayerWindowConfig
NativePlayerWindowRunRequest
NativeWindowHostReport
run_headless_native_player_from_package
run_windowed_native_player_from_package
```

默认路径：

```text
RuntimePackage
  -> load_runtime_package
  -> hydrate_active_scene_into_world
  -> EngineHostLoop
  -> render_thread_for_target(RenderTarget::surface)
  -> NativeWindowHostReport
```

real-window feature 路径：

```text
winit EventLoop
  -> OS Window
  -> wgpu Surface
  -> RealWgpuBackend::execute_plan_to_surface_view
  -> surface present
```

## 关键边界

`engine_runtime` 继续不创建 OS window，不依赖 `winit`，不拥有 `wgpu::Surface`。

`runtime_player_winit` 是正式 Player Host，不是 Editor Host。

`runtime_cli` 默认 feature 不依赖 `runtime_player_winit`；只有 `real-window` feature 启用时才接入真实 Player Host。
