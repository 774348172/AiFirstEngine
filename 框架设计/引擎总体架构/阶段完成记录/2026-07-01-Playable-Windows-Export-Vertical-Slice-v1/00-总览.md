## 完成能力

```text
DesktopExportRequest::windows_dev(project_root)
DesktopExportPipeline::export(request)
DesktopPackageManifest
DesktopExportReport
desktop-export-report.json
package-manifest.json
windowed-player-run-report.json
```

导出目录：

```text
<project>/Build/Windows/<profile>/
  Game.exe
  data/runtime_package/
  data/assets/
  reports/desktop-export-report.json
  reports/windowed-player-run-report.json
  package-manifest.json
```

关键修正：

```text
EditorSceneDocument -> RuntimePackageBuildInput 时，active scene 会作为 scene 类型 runtime asset 注册。
RuntimePackageBuilder 写出的 scenes/<scene-id>.json 同时作为 scene asset 的 cooked path。
这样 RuntimePackage load 和 RuntimeScene Hydration 使用同一套 RuntimeAssetIndex 契约，不绕过 player gate。
```

## 当前边界

```text
这是 Windows 可玩导出 C-min 纵向切片，不是最终发布系统。
Game.exe 目前复制已构建的 runtime_cli；如果可执行文件不存在，导出报告会 warning，但 package 数据与 reports 仍可生成。
暂不做 installer、签名、商店包、多平台 profile、完整真实资源 cook。
暂未接入 Native Editor 的 Build / Export UI。
```
