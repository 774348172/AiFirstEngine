## 本阶段完成内容

```text
1. 新增统一 RuntimeRenderAssetProducer 系统。
2. 新增 RuntimeRenderAssetKind / RuntimeRenderAssetUsage / RuntimeRenderAssetRequest。
3. 新增 typed render asset payload：
   Texture / Material / Mesh / AUI image / Font atlas / Particle texture / Render target。
4. 新增 RenderBindingSet / RenderBindingKind。
5. 新增 RuntimeRenderAssetProductionReport / Event / Stage / Code。
6. 接入 RenderResourceManager，统一创建或复用 RenderResourceHandle。
7. RHI SpriteTextured payload 支持携带 RenderBindingSet。
8. HeadlessRhiBackend / WgpuBackend report 增加 binding/resource 统计字段。
9. WindowedPlayer GPU binding 路径从旧 RenderAssetBridge 收敛到 RuntimeRenderAssetProducer。
```

## 关键边界

```text
没有新增 TextureBridge / MeshBridge / FontBridge / AuiBridge 等平级桥。
AUI image 和 Particle texture 作为 Texture 系 usage 接入。
Font atlas 复用 texture resource 生产。
WgpuBackend 不读取 RuntimePackage、AssetRef 或项目路径。
Producer 只产出 backend-neutral typed render asset，不创建 wgpu object。
旧 RenderAssetBridge 保留为兼容旧测试和旧路径的历史入口，没有继续扩展为正式系统。
```
