## 本轮完成内容

新增：

```text
rust/crates/engine_runtime/src/sprite2d_render_pipeline.rs
```

实现：

```text
Sprite2DRenderPipeline
Sprite2DRenderFrame
Sprite2DDrawPlan
Sprite2DRenderDiagnostic
Sprite2DRenderCounters
```

接入：

```text
RuntimeRenderer 使用 Sprite2DRenderPipeline 生成 Sprite2D draw pass。
RenderGraph DrawSpriteTextured 支持携带 RenderBindingSet。
RhiCommandPlan 优先使用 RenderGraph command 的 binding。
RuntimeRenderFrameReport 合并 Sprite2D diagnostics。
```

第一版支持：

```text
visible sprite 生成 DrawSpriteTextured。
missing sprite_ref 产生 sprite_missing_ref，而不是 fallback 到测试几何。
view layer_mask 不匹配产生 sprite_layer_mismatch。
sprite draw plan 携带 Sprite2DTexture fallback binding。
RHI SpriteTextured payload 携带 RenderBindingSet。
AUI overlay 仍在 Sprite2D pass 之后、Present 之前。
Mesh 渲染旧行为保持。
```
