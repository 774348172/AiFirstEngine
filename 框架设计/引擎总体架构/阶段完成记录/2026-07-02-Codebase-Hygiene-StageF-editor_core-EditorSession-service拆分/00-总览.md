# Codebase Hygiene Stage F editor_core / EditorSession service 拆分完成记录

## 1. 目标

本阶段执行：

```text
Codebase Architecture Hygiene Gate v1 - Stage F1
```

目标不是新增编辑器功能，而是先把 `editor_core/src/lib.rs` 从实现承载文件收敛为 crate public facade：

```text
lib.rs:
  只保留 mod declaration / pub use / test module 入口。

session.rs:
  承接 EditorSession、CommandTransaction、CommandResult、CommandStatus 等当前 session 主体。

tests.rs:
  承接原 lib.rs 内的大测试模块。
```

本阶段刻意不继续深拆 project / scene / build / play / ai / ui model composer service。原因是 Stage F1 的验收边界是“入口 facade 化”，不是一次性重写 EditorSession 内部所有领域服务。

## 2. 实际修改

代码修改：

```text
rust/crates/editor_core/src/lib.rs
rust/crates/editor_core/src/session.rs
rust/crates/editor_core/src/tests.rs
```

完成结果：

```text
editor_core/src/lib.rs:     5331 行 -> 130 行
editor_core/src/session.rs: 新增 3361 行
editor_core/src/tests.rs:   新增 1845 行
```

结构变化：

```text
EditorSession public API 继续从 editor_core crate root 导出。
CommandResult / CommandTransaction / CommandStatus / UndoPolicy 等类型继续从 crate root 导出。
原 lib.rs 内部测试迁移到 tests.rs。
原外部调用路径不改变。
```

为保证测试模块迁移后仍可验证内部状态，`EditorSession` 的部分字段调整为 `pub(crate)`。这是 crate 内部可见性，不是 public API 扩大。

## 5. 暴露问题

Stage F1 完成后仍存在的结构风险：

```text
editor_core/src/session.rs: 3361 行
editor_core/src/scene_editing.rs: 2404 行
editor_ui_model/src/lib.rs: 2289 行
editor_core/src/tests.rs: 1845 行
editor_core/src/inspector_details.rs: 1644 行
```

其中最重要的是：

```text
EditorSession 仍然是编辑器事实聚合根。
UI model composition、project launcher、runtime package、scene、play、build、AI panel 仍在 session 主体附近集中。
```

这不是 Stage F1 失败，而是 Stage F1 暴露出的下一层治理对象。

## 6. 下一步建议

推荐继续：

```text
Codebase Hygiene Stage F2: EditorSession service 拆分第一轮
```

优先顺序：

```text
1. transaction / command result 类型独立到 transaction.rs。
2. ui model composition 独立到 ui_model_composer/。
3. project launcher / project session 独立到 services/project_service.rs。
4. runtime package / run state / tick flow 独立到 services/runtime_service.rs。
5. scene selection / inspector model 独立到 services/scene_service.rs。
```

验收原则继续保持：

```text
不改变 EditorSession public API。
不改变 UI command 入口。
不改变用户可见行为。
每拆一块就跑对应模块测试和 editor_window_winit 回归。
```
