# M11 Physics2D Collider Authoring / Visualization C-min 阶段完成记录

## 目标

完成 Physics2D Collider 从编辑器创作、可视化、保存重载到 Runtime Physics2D 验证的 C-min 闭环。

## 实际修改

```text
editor_ui_model
  - ViewportModel 增加 collider_overlay。
  - 新增 ColliderOverlayModel / Item / Shape / Diagnostic。

editor_core::scene_editing
  - SceneEditTransaction 支持安全 dot path component field 写入。
  - 新增 ColliderDebugDrawList / Item / Shape / Diagnostic。
  - 支持 Aabb / Circle collider overlay 数据生成、selected 标记和诊断。
  - 增加 Collider2D save / reload / runtime pair report 验证。

editor_core::inspector_details
  - 增加 Collider2D Inspector schema 覆盖测试。

editor_core::lib
  - EditorSession::build_viewport_model 接入 collider overlay。
  - Runtime snapshot viewport 保持空 overlay 兼容。

editor_input / editor_window_winit
  - 补齐 InputMapping UI command id 映射，修复新增 UiCommandPayload 后的非穷尽匹配。

editor_ui_renderer / editor_ui_backend_egui / editor_input / editor_window_winit
  - 补齐测试 fixture 的 input_mapping_authoring 字段。
```

## 暴露问题

```text
1. UiCommandPayload 新增枚举后，editor_input 和 editor_window_winit 各自维护的 command_id 映射容易漏补。
2. EditorUiModel 测试 fixture 分散在多个 crate，新增字段时需要多处同步。
```

这两个问题不阻塞 M11，但后续可以考虑把 UI command id 映射和测试 fixture builder 收敛到公共能力，减少重复维护。
