## 设计结果

```text
Schema 是字段定义来源。
PropertyTree 是 Inspector 视图结构。
PropertyHandle 是字段读写入口。
TransactionRouter 是写入出口。
PrefabInstance 编辑通过 PrefabOverride 表达。
RuntimeObjectReadonly 默认拒绝写入。
缺失 Schema 走 JsonFallback，并产生 InspectorReport diagnostic。
```
