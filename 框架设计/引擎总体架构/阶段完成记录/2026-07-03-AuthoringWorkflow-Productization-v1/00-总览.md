## 2. 完成内容

```text
AuthoringWorkflowModel

  -> UiCommandPayload / ProjectPatch

```

## 3. 代码改动

### 3.1 editor_ui_model

新增：

```text
workflow_command.rs
WorkflowCommandResolver
WorkflowCommandResolution
```

规则：

```text
无参命令或上下文明确命令可解析为 UiCommandPayload。
需要用户补参数的命令返回 FocusDomainPanel。
Disabled command 不会生成 payload。
Unsupported command 返回结构化原因。
```

### 3.2 editor_core

补齐核心域 workflow command 覆盖：

```text
Project: open_project
Scene: open_scene_document
Input: create_default_input_mapping
Play: play
Build: export_desktop_package
Report: open_build_report / clear_console
```

`Prefab / Rule / AUI` 第一版只提供 focus panel 型命令，不伪造复杂编辑能力。

### 3.3 editor_ui_renderer

新增 workflow command hit target：

```text
HitTarget::AuthoringWorkflowCommand
```

Workspace panel 现在会为 step primary command 和 recommended task command 生成 hit region。

### 3.4 editor_input

新增 workflow command 路由：

```text
AuthoringWorkflowCommand hit
  -> WorkflowCommandResolver
  -> UiCommandPayload
```

需要参数的 command 不会被伪造成 payload。

### 3.5 editor_window_winit

focus system 识别：

```text
AuthoringWorkflowCommand -> authoring_workflow panel
```
