# Codebase Hygiene Stage F4 - EditorSession 剩余 command service 拆分完成记录

## 目标

继续收敛 `editor_core/src/session.rs`，在不改变 `EditorSession` public facade、不改变 `execute_command` / `execute_ui_command_direct` 统一入口、不改变 `UiCommandPayload` / transaction 语义的前提下，把剩余 console / build / play / AI command method 迁移到 `services/*`。

## 实际修改

代码落点：

```text
rust/crates/editor_core/src/session.rs
rust/crates/editor_core/src/services/mod.rs
rust/crates/editor_core/src/services/console_service.rs
rust/crates/editor_core/src/services/build_service.rs
rust/crates/editor_core/src/services/play_service.rs
rust/crates/editor_core/src/services/ai_service.rs
```

迁移结果：

```text
services/console_service.rs:
  clear_console

services/build_service.rs:
  export_desktop_package
  open_build_output
  open_build_report

services/play_service.rs:
  start_play_session
  stop_play_session

services/ai_service.rs:
  submit_ai_prompt
  accept_ai_proposed_command
  reject_ai_proposed_command
  plan_ai_response
  extract_quoted_text
  extract_name_after_keyword
```

保留在 `session.rs`：

```text
EditorSession struct / Default / new
execute_command / execute_ui_command_direct
read-only accessors
begin_transaction / finish_transaction
push_info / push_error / make_diagnostic
push_play_session_report
diagnostic_to_console_entry
```

`push_info`、`push_error`、`make_diagnostic`、`diagnostic_to_console_entry`、`push_play_session_report` 暂时保留在 `session.rs`。原因是这些 helper 被多个 service 或 session 入口共用，强行拆到独立 service 会制造额外依赖绕路，不符合本阶段“不为行数强拆 helper”的施工规则。
