# Codebase Hygiene Stage I - editor_core 测试 domain 迁移完成记录

## 目标

把 `editor_core` 中集中在单一 `tests.rs` 的集成测试迁移到 `src/tests/` 目录，按 domain 组织测试，保持测试数量、测试语义和断言强度不变。
