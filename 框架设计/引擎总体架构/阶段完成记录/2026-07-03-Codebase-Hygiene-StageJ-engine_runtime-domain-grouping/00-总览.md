# Codebase Hygiene Stage J - engine_runtime domain grouping 完成记录

## 目标

为 `engine_runtime` 建立稳定的 domain facade，让 ECS / FrameLoop / Render / Asset / Input / Physics / Package / Logic / Validation 有清晰入口。

本阶段只新增 re-export facade，不物理移动 runtime 文件，不改变 runtime 行为，不破坏现有 public module 路径。

## 实际修改

新增：

```text
rust/crates/engine_runtime/src/domain/mod.rs
rust/crates/engine_runtime/src/domain/ecs.rs
rust/crates/engine_runtime/src/domain/frame_loop.rs
rust/crates/engine_runtime/src/domain/logic.rs
rust/crates/engine_runtime/src/domain/render.rs
rust/crates/engine_runtime/src/domain/asset.rs
rust/crates/engine_runtime/src/domain/package.rs
rust/crates/engine_runtime/src/domain/input.rs
rust/crates/engine_runtime/src/domain/physics.rs
rust/crates/engine_runtime/src/domain/validation.rs
```

修改：

```text
rust/crates/engine_runtime/src/lib.rs
```

新增入口：

```rust
pub mod domain;
```

domain facade 采用模块别名式 re-export：

```text
engine_runtime::domain::ecs::world
engine_runtime::domain::frame_loop::engine_host_loop
engine_runtime::domain::logic::project_logic
engine_runtime::domain::render::render_command
engine_runtime::domain::asset::runtime_asset_loader
engine_runtime::domain::package::runtime_package
engine_runtime::domain::input::input_mapping
engine_runtime::domain::physics::physics2d
engine_runtime::domain::validation::golden
```

选择模块别名式 re-export 的原因：

```text
避免 pub use * 带来的 ambiguous glob re-export。
避免把不同模块里的同名类型合并到同一命名空间。
保留 AI 和人类检索所需的稳定 domain 路径。
不改变现有 crate 下游调用路径。
```
