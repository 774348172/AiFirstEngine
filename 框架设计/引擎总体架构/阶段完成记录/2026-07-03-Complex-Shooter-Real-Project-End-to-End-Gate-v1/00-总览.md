## Gate 覆盖能力

当前 gate 已证明：

```text
真实项目目录可以被读取并统计 scene / entity / prefab / asset / rule / input / AUI。
真实项目可以经 DesktopExportPipeline 导出 staged Windows package。
导出过程会生成 RuntimePackage。
RuntimePackage 可以重新 load。
headless native player 可以从导出的 RuntimePackage 连续运行多帧。
运行报告可以统计 frames_run / present_count / rhi_command_count。
真实窗口 smoke 被明确记录为 optional skipped，而不是假装通过。
```

engine_runtime::complex_project_validation 仍是历史/兼容验证逻辑，后续应迁出或降级为历史路径。
