## 2. 关键结论

```text
最终通过依据必须来自导出的 Game.exe 进程。
直接调用 runtime_player_winit 内部函数只允许作为模块测试，不能作为最终导出验证。
验证模式只影响 PlayerHost 外壳：frame limit、report path、process timeout。
RuntimePackage、EngineHostLoop、Renderer/RHI、Input route 必须继续走正常运行路径。
```

对外入口：

```text
Game.exe verify-exported-player --mode headless-gate|windowed --frames N
```

verifier 内部验证路径：

```text
exported package dir
  -> spawn exported Game.exe run-native-player --mode headless-gate --frames N
  -> child writes reports/windowed-player-run-report.json
  -> parent writes reports/exported-player-process-verification-report.json
```
