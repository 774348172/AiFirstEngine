## 2. 关键边界

```text
engine_runtime 不创建 OS window，不依赖 winit，不拥有 wgpu::Surface。
截图 readback 是 RHI backend 能力：输入 RhiCommandPlan + size，输出 RGBA bytes。
PNG 写盘和 OS window 仍在 runtime_player_winit。
普通玩家运行不自动截图；只有显式 --screenshot 才写 artifact。
真实窗口环境不可用时报告失败或 feature_not_enabled，不伪装 passed。
```
