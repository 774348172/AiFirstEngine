```text

```

本阶段把真实 / mock LLM 收敛为 ProjectPatchDocument JSON 的薄输入源：

```text
User Prompt
  -> ThinLlmPatchSource
  -> raw ProjectPatchDocument JSON / provider diagnostic
  -> ProjectPatchImportRequest::ai_structured_output

  -> User Confirm

```

## 5. 残留风险

```text
真实 OpenAiCompatible provider 当前只是 stub，不会发起 HTTP 调用。
mock source 只验证链路，不代表真实模型输出质量。
Prompt helper 只是内部 helper，不是完整 Prompt 管理系统。
LLM 目前仍只能生成 Scene / Input 范围内可被 ProjectPatchImportService 接受的 patch。
Asset / Prefab / AUI / Rule / Build patch capability 仍需后续单独讨论和施工。
```

## 6. 下一步建议

如果继续推进复杂打飞机项目落地，下一步不应重复扩展 provider 子系统，建议选择：

```text
manual walkthrough coverage report 指出的真实 authoring domain
或
ProjectPatch Asset / Prefab / AUI / Rule / Build capability v2
```

真实 HTTP provider、Provider Registry、Repair Loop 应在确实需要多 provider / 多轮修复时作为 v4+ 单独讨论。
