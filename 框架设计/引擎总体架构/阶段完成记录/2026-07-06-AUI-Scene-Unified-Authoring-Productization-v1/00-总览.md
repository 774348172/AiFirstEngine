# AUI Scene Unified Authoring Productization v1 完成记录

## 施工范围

本轮按 `209-AUI-Scene-Unified-Authoring-Productization-v1方案.md` 的 C-min-r1 路线完成：

```text
Scene View / Hierarchy / Inspector
  -> AuiNodeAuthoringProxy
  -> WorkspaceSelectionTarget::AuiNode
  -> AUI authoring command / service
  -> canonical AUI Document
  -> existing RuntimePackage / Present chain
```

核心边界保持不变：

```text
不新增独立 AUI Designer。
不新增 AUI 专用编辑模式；2D 只表示 Scene View projection。
AUI Document 仍是 UI 结构真相。
AUI Node 不变成 Runtime ECS Entity。
AuiNodeAuthoringProxy / SceneVisualOrderAuthoringEntry 只存在于 editor view model / report。
当前 runtime 只支持 ScreenOverlay / Modal overlay 域，不假装支持任意 World 前后夹击。
单个 AUI Node 拖到 Scene Entity 前后必须拒绝，并提示 extract_to_aui_layer_group_or_canvas。
```

## 验收结论

```text
AUI 可以进入 Scene 统一 authoring 链路。
Hierarchy / Scene View / Inspector 都能表达和选择 AUI Node。
AUI Node 选择不会把 AUI Node 伪装成 Runtime ECS Entity。
Visual order report 能区分 ScreenOverlay / Modal 可执行域与跨 World deferred gap。
单个 AUI Node 跨 World reorder 被拒绝并给出 extract_to_aui_layer_group_or_canvas。
complex shooter e2e 具备 AUI scene unified authoring report 证据。
```

## 残留风险

```text
本轮不实现 RuntimeRenderer Multi-stage UI Composition Pass，因此 UI 节点夹在 Scene Entity 前后仍只能作为 authoring intent / deferred gap。
本轮不实现拖拽创建控件、拖拽移动/resize、Rect handle、对齐辅助线。
本轮不实现 AUI Prefab / Template Reuse、ScrollView、InputField、IME、UI animation、Theme editor。
真实 GPU screenshot visual diff 仍为后续阶段。
```
