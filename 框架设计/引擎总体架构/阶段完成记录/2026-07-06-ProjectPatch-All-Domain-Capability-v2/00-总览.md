## 6. 关键语义

全域 ProjectPatch 现在可以安全表达：

```text
Asset.GenerateMockImageAsset
Prefab.ValidateReferences / CreateFromSceneSelection 等已有 Prefab command surface
Aui.CreateDocument / AddNode / ValidateDocument 等已有 AUI command surface
Rule.CreateAsset / AddOperation / ValidateAsset / BuildArtifact 等已有 Rule command surface
Build.ExportDesktopPackage / OpenBuildReport / OpenBuildOutput
```

Build 语义固定为：

```text
Build 是验证 / 导出动作。
Build 失败会进入 PatchApplyReport diagnostics。
Build 失败不自动撤销已确认的 Asset / Prefab / AUI / Rule 项目源资产修改。
```

全域 e2e artifact：

```text
complex-shooter-all-domain-project-patch-report.json
```
