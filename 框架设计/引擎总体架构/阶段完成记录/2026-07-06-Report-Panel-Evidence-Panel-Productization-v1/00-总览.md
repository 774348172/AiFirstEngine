## 残留风险

```text
Report Panel 当前是 editor-only 只读聚合视图，没有引入长期 Report DB。
OpenRawReport / RevealReportPath / CopyReportAiContext 当前只提交结构化 info command，未绑定真实 OS 打开/剪贴板动作。
ComplexShooterE2E provider 当前是诚实 placeholder，真实 artifact 由 project_e2e_gate 生成。
新增 provider 仍需通过 ReportProvider 注册，不能再新增独立 report panel。
```
