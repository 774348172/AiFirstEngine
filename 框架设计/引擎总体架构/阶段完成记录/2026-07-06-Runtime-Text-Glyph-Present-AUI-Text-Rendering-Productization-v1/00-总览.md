# Runtime Text Glyph Present / AUI Text Rendering Productization v1 完成记录

## 施工范围

本轮按 `208-Runtime-Text-Glyph-Present-AUI-Text-Rendering-Productization-v1方案.md` 的 C-min 路线完成：

```text
AUI Document
  -> Build-time AuiFontAtlasCookerCmin
  -> RuntimePackage cooked FontAtlas
  -> RuntimeAuiFontAtlasRegistry
  -> AuiRuntimePresenter glyph plan
  -> RuntimeRenderer / RHI glyph evidence
  -> runtime_player_winit / project_e2e_gate report
```

核心边界保持不变：

```text
Runtime 不扫描项目源目录。
Runtime 不扫描系统字体目录。
RuntimePackage 是运行输入真相。
本轮只做 cooked FontAtlas C-min，不做完整 FontImporter / CJK shaping / emoji / rich text / IME / 209 Scene Unified AUI Authoring。
```

## 完成内容

```text
engine_runtime:
  RuntimePackageManifest 增加 fontAtlases index。
  新增 RuntimeFontAtlasManifest / CookedFontAtlasAsset / RuntimeAuiFontAtlasRegistry / load report。
  RuntimePackageBuilder 写出 fonts/font-atlas-manifest.json、*.fontatlas.json、*.fontatlas.r8。
  load_runtime_package 加载并校验 FontAtlas metadata / R8 bitmap / glyph metrics。
  AuiRuntimePresenter 增加带 FontAtlas registry 的 present API。
  AuiOverlayFrame 增加 AuiTextGlyphPlan。
  AuiRuntimePresentReport 输出 font_atlas_present、font_atlas_id、rendered_glyph_count、glyph_plan_hash 等 evidence。
  RenderPassCommand::DrawUiOverlay / RhiDrawPayload::UiOverlay 输出 glyph_count、font_atlas_id、text_pass_inserted。

editor_core:
  新增 AuiFontAtlasCookerCmin。
  ProjectRuntimePackageAssembler 在 AUI document 存在时生成 ui-default-cmin cooked FontAtlas。
  ProjectRuntimePackageAssemblyReport 增加 font_atlas_count。

runtime_player_winit / project_e2e_gate:
  Headless player 使用 package.font_atlases 调用 AUI presenter。
  NativeAuiPresentSummary 输出 font/glyph evidence。
  ComplexProjectE2eMetrics 输出 font_atlas_id、requested/rendered glyph count、glyph_plan_hash。
  complex shooter e2e 不再把 runtime_text_glyph_present 标为 blocking gap。
```


## 残留风险

```text
C-min 使用 engine_builtin_cooked_fallback 生成可见 ASCII glyph，不代表项目 font-main.asset 已被真实解析。
暂不支持完整 FontImporter、TTF/OTF parsing、CJK shaping、emoji、rich text、multi-page atlas、IME。
当前 RHI / RenderGraph 证明 glyph plan 和 draw payload，真实 GPU 字体纹理绘制管线仍是后续阶段。
```
