# RuntimeRenderer Multi-stage UI Composition Pass Productization v1 完成记录

## 施工范围

本阶段完成 210 方案 C-min：把原先单一 AUI ScreenOverlay pass 扩展为固定三段 screen-space UI composition。

```text
AUI BeforeWorld
World / Sprite
AUI ScreenOverlay
AUI Modal
Present
```

核心边界保持不变：

```text
AUI Node 不变成 Runtime ECS Entity。
BeforeWorld 是 screen-space composition stage，不等于 AuiCanvasMode::WorldSpace。
Modal 本阶段只代表 rendering composition stage，不承诺 input blocking / focus trap。
不实现完整 WorldSpace UI / UI Camera / depth-aware UI。
不支持单个 AUI Node 与 Scene Entity 任意混排；209 的 Authoring Proxy / VisualOrder 仍是编辑器 view model。
```

## 完成内容

```text
新增 AuiCompositionStage: BeforeWorld / ScreenOverlay / Modal。
新增 AuiCanvas.composition_stage，默认 ScreenOverlay。
AuiRendererBridge 可构建 AuiCompositionFrame，并按 composition_stage bucket draw items。
AuiOverlayDrawItem 携带 canvas_id / composition_stage；sort_key 接入 AuiCanvas.layer / sorting_order。
RenderGraph / RHI 新增 DrawUiComposition / UiComposition payload。
RuntimeRenderer 支持 BeforeWorld、ScreenOverlay、Modal 三段 UI composition pass，空 stage 跳过。
RuntimeRenderFrameReport 输出 stage item count、pass present、skipped evidence。
RenderThread / EngineHostLoop / runtime_player_winit 转发 AuiCompositionFrame，保留旧 AuiOverlayFrame 兼容路径。
NativeAuiPresentSummary / project_e2e_gate metrics 输出 UI composition stage evidence。
editor_ui_model / editor_core visual order 支持 BeforeWorld。
AuthoringAiContext / project_e2e_gate 不再把 RuntimeRenderer multi-stage composition 作为固定缺口。
complex_project_validation fixture 补齐真实 AUI document body，避免只声明 manifest 的旧不完整输入。
```

## 残留风险

```text
BeforeWorld / ScreenOverlay / Modal 已有 runtime pass 和 report evidence，但还不是完整 WorldSpace UI / UI Camera / depth-aware UI。
Modal 仍是 rendering-only；真实 modal input blocking、focus trap、stack 管理需要后续独立方案。
209 的 Scene visual order 已能展示 BeforeWorld，但单个 AUI Node 跨 World 混排仍必须被拒绝并提示抽成 LayerGroup / Canvas。
AUI Prefab / Template Reuse、复杂 UI 控件交互、完整字体导入 / CJK shaping / rich text 仍是后续缺口。
```
