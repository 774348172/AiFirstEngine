## 关键实现

```text
engine_input：
  RuntimeInputFrame::filter_consumed_events 支持过滤 pointer / MouseWheel / KeyDown / KeyUp / KeyHeld。
  RuntimeInputFrame::filter_consumed_pointer_events 保留兼容旧调用。

engine_runtime::aui：
  新增 AuiFocusState / AuiFocusReason / AuiScrollState。
  AuiInteractionConfig 增加 modal / wheel / key / scroll 配置。
  AuiInteractionState 增加 focus / active_modal_root / scroll_offsets / active_scroll_capture。
  AuiCommandKind / AuiActionEvent 增加 Focus / Blur / Cancel / Scroll。
  AuiInteractionSystem 支持 Modal blocking、focus trap、Escape Cancel、wheel scroll、drag scroll。
  AuiLayoutEngine::layout_with_scroll_offsets 输出 scroll_offset_applied / scroll_applied_node_count / clipped_node_count。

runtime_player_winit：
  AUI interaction 后使用 filter_consumed_events 再进入 gameplay InputResolver。
  NativeAuiPresentSummary 输出 modal/focus/scroll/consumed kind/layout offset 证据。
  交互后按 scroll_offsets 重新计算 layout，用于 report 证明 offset 已应用到 computed rect。

project_e2e_gate：
  新增 aui_complex_controls runner / report / test。
  聚合 modal blocking、focus trap、wheel scroll、drag scroll、layout offset、Scene AUI hit-test evidence。
```
