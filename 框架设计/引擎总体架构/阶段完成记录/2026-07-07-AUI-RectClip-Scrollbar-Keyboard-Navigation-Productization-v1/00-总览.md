## 当前结论

```text
214 后的复杂滚动 UI 缺口已收敛到可运行 B-min。
AUI Runtime Core 现在能证明 clip、hit-test clip rejection、scrollbar visual、thumb drag、keyboard navigation、focus visible auto-scroll。
AUI Document 仍是 UI 结构真相，scroll / focus / capture 状态仍是 runtime transient state。
没有新增 Widget 层，没有让 AUI Node 变成 Runtime ECS Entity，没有把 UI framework 机制交给 IR。
```

## 残留风险

```text
Renderer 侧当前以 headless overlay/report 证明 clip evidence；真实 GPU scissor / stencil screenshot 仍需后续 renderer gate。
Keyboard navigation B-min 使用 deterministic rect candidate，不等价于 Unity Selectable 的完整评分与 gamepad navigation。
ScrollView 只做 vertical scrollbar；nested scroll、inertia、elastic、virtualized list 后续再拆系统。
```
