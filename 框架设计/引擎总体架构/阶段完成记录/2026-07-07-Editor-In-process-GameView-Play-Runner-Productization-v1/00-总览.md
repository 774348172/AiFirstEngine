# Editor In-process GameView Play Runner Productization v1 阶段完成记录

日期：2026-07-07

## 施工范围

本轮完成 `218-Editor-In-process-GameView-Play-Runner-Productization-v1方案.md` 的 `A-min-gameview` 首版产品化链路：

```text
Editor Play 继续使用 217 Preview RuntimePackage 真相。
PlaySessionMode::WindowedUserRun 在项目 Play 场景下接入 editor_in_process_gameview runner，不再返回 not implemented。
Editor 进程内创建 EditorRuntimePlayInstance，并从 RuntimePackage load / hydrate / tick。
GameViewRuntimeFrame 输出 descriptor evidence：frame_hash、renderable_count、ui_draw_item_count、target_id、texture_id。
GameViewPresentReport 写出并链接到 PlaySessionReport。
EditorSession 保存 active runtime instance、last GameView frame、last GameView present report。
Stop 清理 EditorRuntimePlayInstance，并生成 stopped report。
ViewportModel 使用 GameView runtime descriptor evidence。
Report Panel 新增 play.game_view_present provider。
project_e2e_gate 新增 editor_gameview_play_runner gate，验证复杂打飞机样例经过 218 链路。
```

本轮吸收 `其它AI审查目录/36-218-Editor-In-process-GameView-Play-Runner方案审查.md` 后，明确：

```text
不复用 runtime_player_winit 的独立 winit EventLoop / run_windowed 作为 Editor 内嵌 GameView。
A-min 不声称完成真实 GPU texture present。
A-min 不接 GameView input / AUI interaction。
A-min 使用 descriptor evidence 证明 runtime frame 已进入 GameView contract。
```

## 关键结果

```text
新增 editor_gameview_play 模块，集中定义 EditorRuntimePlayRequest、EditorRuntimePlayInstance、EditorGameViewPlayRunner、GameViewRuntimeFrame、GameViewPresentReport。
新增 PlayRunner trait，DefaultGameRunOrchestrator 与 EditorGameViewPlayRunner 通过同一 PlaySessionController runner 边界接入。
项目已打开时，PlayService 先准备 Preview RuntimePackage，再启动 EditorGameViewPlayRunner。
手动打开 RuntimePackage 的 debug/manual path 仍保留 HeadlessGate 行为。
GameViewPresentReport 标记 texture_descriptor_status=descriptor_only、input_bridge_status=deferred，避免把 A-min 伪装成完整 GameView。
EditorRuntimePlayInstance tick 时对齐 runtime AUI present summary，能报告 ui_draw_item_count。
Viewport / Report Panel / e2e gate 均能看到 game view frame descriptor 与 report link。
Stop 会 drop active runtime instance，并把 stop_status 写回 report。
```
