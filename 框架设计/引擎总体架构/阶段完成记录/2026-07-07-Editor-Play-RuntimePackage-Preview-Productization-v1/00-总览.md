# Editor Play / RuntimePackage Preview Productization v1 阶段完成记录

日期：2026-07-07

## 施工范围

本轮完成 `217-Editor-Play-RuntimePackage-Preview-Productization-v1方案.md` 的 `B-min-cache` 首版产品化链路：

```text
Editor Play 自动准备 Preview RuntimePackage
Preview RuntimePackage cache manifest
dirty domain fingerprint
cache hit / missing / stale / rebuilt / failed report
PlaySessionReport 链接 PreviewPackageReport
Toolbar Play 在项目已打开时可用，不再要求手动 Open RuntimePackage
Report Panel 新增 play.preview_package provider
project_e2e_gate 新增 editor Play preview cache gate
```

本轮吸收 `其它AI审查目录/35-217-Editor-Play-RuntimePackage-Preview方案审查.md` 后，明确 217 v1 只做 Preview RuntimePackage cache + 现有 HeadlessGate 接入，不实现真实 WindowedUserRun / Embedded GameView。

## 关键结果

```text
新增 editor_preview_package 模块，负责 Preview RuntimePackage prepare / cache / fingerprint / report。
Preview cache 写入 .aife/editor-preview/<profile>/<active_scene_id>/。
无变更连续 Play 可命中 cache hit，并跳过 RuntimePackageBuilder。
cache missing / stale 时通过 ProjectRuntimePackageAssembler -> RuntimePackageBuilder -> RuntimePackageLoader 准备预览包。
PlayService 在项目已打开时自动 prepare preview package，再启动 PlaySessionMode::HeadlessGate。
无项目且无手动 RuntimePackage 时仍返回 runtime_package_required，保留 debug/manual path。
PlaySessionReport 增加 preview_package_report_path / preview_cache_status / preview_dirty_domains / preview_prepare_duration_ms。
UI model 中项目已打开即可 Play，不再把“未手动打开 RuntimePackage”作为禁用理由。
Report Panel 新增 play.preview_package report provider。
project_e2e_gate 新增 editor_play_preview_runtime_package_cache，验证首次构建、二次 cache hit、Scene dirty stale。
```
