# Editor GameView Full GPU Texture Sharing Productization v1 阶段完成记录

完成日期：2026-07-08

## 完成结论

219 已按 `A-min-gpu-gameview` 完成施工：Editor Play 仍以 217 Preview RuntimePackage 为真相、218 `EditorRuntimePlayInstance` 为 in-process runtime session；真实窗口路径在同一 `wgpu::Device / Queue` 下分配 GameView shared texture，runtime RHI plan 渲染到该 texture，再由 Editor UI renderer 通过 `ViewportTextureSlot` 采样到 GameView 区域。

本轮吸收 `其它AI审查目录/37-219-Editor-GameView-Full-GPU-Texture-Sharing方案审查.md` 的约束：A-min 同步执行、不引入 RenderThreadWorker 跨 crate shared texture、`editor_core` 不持有 wgpu handle、headless/mock 不假装 presented、复用 `RealWgpuBackend::execute_plan_to_surface_view`、resize 只在帧间处理。

## 主要落地

```text
editor_wgpu_renderer
  新增 EditorSharedGpuContext / summary。
  新增 EditorViewportTextureRegistry，支持 mock / real GPU texture allocate、resize、resolve、mark_rendered、unregister。
  DrawCommand::ViewportTextureSlot 生成 UiGpuViewportTextureQuad；缺 texture 时 fallback placeholder。
  RealWgpuUiRenderer 持有 shared context，暴露 shared_context() / shared_context_summary() / viewport_textures()。
  UI present path 新增 viewport texture sampling pipeline。

engine_runtime
  RealWgpuBackend 新增 from_shared_device_queue。
  复用 execute_plan_to_surface_view 渲染 runtime RHI plan 到外部提供的 TextureView。

editor_core
  GameViewRuntimeFrame / GameViewPresentReport 增加 gpu_present_status、shared_gpu_context_status、rhi_command_count、render_graph_pass_count、runtime_target_kind。
  EditorRuntimePlayInstance 保留 last_rhi_command_plan。
  新增运行中 tick 一帧和 GPU present 状态回写 API；editor_core 仍只保存 plan/report/status，不保存 wgpu handle。
  Report Panel 能显示 GameView GPU present evidence。

editor_window_winit
  real window RedrawRequested 中同步执行：runtime tick -> shared texture allocate/resize -> execute_plan_to_surface_view -> mark_rendered -> UI present。
  默认 headless 测试不依赖真实 GPU；真实窗口 smoke 保持 ignored/local-only。

project_e2e_gate
  新增 editor_gameview_gpu_texture_present gate，验证 217/218/219 证据链，禁止 descriptor_only 冒充 presented。
```
