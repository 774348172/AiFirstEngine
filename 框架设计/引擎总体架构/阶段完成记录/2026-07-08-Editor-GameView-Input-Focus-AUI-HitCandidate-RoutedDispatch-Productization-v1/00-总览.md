# Editor GameView Input / Focus / AUI HitCandidate RoutedDispatch Productization v1 阶段完成记录

## 施工范围

本轮按 220 方案和当前施工文档完成 B+-min：

```text
EditorInputEvent
  -> GameView focus / hover gate
  -> GameView-local RuntimeInputFrame
  -> EditorRuntimePlayInstance tick with input
  -> AuiInteractionSystem::process_with_state
  -> filter_consumed_events
  -> InputResolver / gameplay fallback
  -> GameViewPresentReport summary evidence
```

本轮没有新增平行 AUI router，没有实现 WorldPickCollector / EditorOverlayCollector / 完整跨域 RoutedDispatch，也没有修改 RenderFrameReportLevel。

## 完成内容

```text
editor_window_winit:
  GameView pointer window 坐标转换为 GameView-local runtime 坐标。
  RuntimeInputFrame pointer event / pointer_position 不再直接使用 window 坐标。

editor_core:
  EditorRuntimePlayInstance 增加 tick_next_descriptor_frame_with_runtime_input。
  持久化 AuiInteractionState，复用 AuiInteractionSystem::process_with_state。
  AUI consumed 后用 RuntimeInputFrame::filter_consumed_events 过滤，再进入 InputResolver。
  EngineFrameInput 写入 ActionSnapshot / InputTraceSummary / AuiInteractionResult。
  input_bridge_status 从 deferred 收敛为 not_requested / runtime_input_frame / runtime_input_frame_filtered_by_aui。
  GameViewRuntimeFrame / GameViewPresentReport 增加轻量 summary：runtime_input_event_count、filtered_runtime_input_event_count、aui_consumed_event_count、gameplay_action_count、gameplay_action_ids。

EditorSession / project_e2e_gate:
  EditorSession 暴露 active GameView runtime input tick API。
  complex shooter e2e 在 Play 后注入一帧 GameView pointer input，验证 runtime_input_frame 状态和 action.fire gameplay fallback。
```
