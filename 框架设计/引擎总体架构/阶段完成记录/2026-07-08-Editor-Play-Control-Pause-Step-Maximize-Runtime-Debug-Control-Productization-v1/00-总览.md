# Editor Play Control / Pause-Step-Maximize / Runtime Debug Control Productization v1 阶段完成记录

## 施工范围

本轮按 221 方案和当前施工文档完成 B-min：

```text
Editor GameView Play Control
  -> Pause 保留 active EditorRuntimePlayInstance，不再 Stop
  -> Play 在 Paused 状态下执行 Resume
  -> StepFrame 推进 active GameView runtime exactly one frame
  -> StopPlaySession 显式释放 active runtime instance
  -> Maximize on Play 进入 Editor toolbar/view model
  -> GameViewPresentReport / Report Panel / project_e2e_gate 输出 play control evidence
```

本轮没有实现 time scale、breakpoint、timeline、input replay、Runtime state inspector、OS fullscreen、外部 GameView 窗口、多实例 Play 或完整 Debugger 系统。

## 完成内容

```text
skill / 方案 / 施工文档:
  项目 skill 固化“外部审查文档处理流程”。
  读取 38-220 审查文档后判断其为 220 前置约束，221 继承 input/report/headless 约束，不推翻方案。
  生成并自审 221 当前可自动化施工文档。

  UiCommandPayload 新增 StopPlaySession、SetGameViewMaximizeOnPlay、ToggleGameViewMaximizeOnPlay。
  workspace domain、toolbar model、command registry、winit command system 和 editor_input toolbar route 均识别新命令。
  ToolbarModel 新增 GameViewLayoutState，暴露 maximize_on_play、is_game_view_maximized、restore_workspace_region、reason。

editor_core:
  EditorRuntimePlayState 新增 Paused / Stepping。
  GameViewPresentReport 新增 control_state、control_command、runtime_advanced、paused_last_frame_reused、step_count、target_runtime_domain。
  EditorRuntimePlayInstance 新增 pause / resume / step_next_frame / control_state。
  Paused 状态下普通 redraw tick 不推进 EngineHostLoop，只复用 last frame。
  StepFrame 在 Paused 状态下推进 exactly one frame，完成后回到 Paused。
  EditorSession 将 Pause / Stop / StepFrame 语义拆开；Play 在 Paused 时 Resume。
  Maximize on Play 只修改 Editor view model / layout intent，不触碰 RuntimeRenderer、RHI 或 OS fullscreen。

Report / E2E:
  Report Panel 的 play.game_view_present summary/evidence 增加 play control 字段。
  project_e2e_gate 的 editor_gameview 报告覆盖 Play -> Pause -> paused redraw -> Step -> Resume -> Stop，并验证 Maximize on Play 自动最大化与 Stop 后恢复。
```
