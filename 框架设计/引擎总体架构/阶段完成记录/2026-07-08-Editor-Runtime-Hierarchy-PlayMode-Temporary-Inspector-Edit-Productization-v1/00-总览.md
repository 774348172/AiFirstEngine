# Editor Runtime Hierarchy / Play Mode Temporary Inspector Edit Productization v1 阶段完成记录

## 1. 完成范围

本轮完成 `223-Editor Runtime Hierarchy / Play Mode Temporary Inspector Edit Productization v1` 的 C-min：

```text
Play Mode:
  单一 Hierarchy 自动显示 active EditorRuntimePlayInstance live World。
  点击 Runtime Hierarchy 节点选择 active runtime entity。
  Inspector 从 active runtime live World 构建，并支持 temporary_play_session 编辑。
  临时编辑只写当前 Play Session 的 runtime World。
  StepFrame 后临时修改仍在当前 Play Session 生效。
  StopPlaySession 后 runtime instance / runtime selection / 临时编辑全部丢弃。
```

明确未做：

```text
不新增用户可见 Authoring / Runtime / Package domain toggle。
不把 runtime temporary edit 写回 Scene / Prefab / Rule / RuntimePackage。
不做 Apply Runtime Change To Authoring。
不做 runtime undo stack、多选、spawn/despawn、reparent/reorder。
不做 Vec2 Inspector 全链路，Collider2D.offset 仍不进入 C-min。
不新增 FullWorldStateDump / 统一 RuntimeStateSnapshot。
```

## 2. 关键实现

```text
editor_ui_model:
  新增 HierarchySourceDomain。
  HierarchyModel 增加 source_domain / status。
  新增 InspectorPersistence。
  InspectorModel 增加 persistence。
  新增 SelectRuntimeEntity / SetRuntimeComponentFieldTemporary command payload。

editor_core:
  build_hierarchy_model 优先 active EditorRuntimePlayInstance live World，其次 authoring Scene，再其次 opened RuntimePackage。
  Runtime Hierarchy selection 写入 EntitySelectionSource::ActiveGameViewRuntime。
  Active runtime Inspector 从 readonly 升级为 editable + TemporaryPlaySession。
  Opened RuntimePackage Inspector 保持 ReadOnlyRuntimePackage。
  EditorRuntimePlayInstance 新增 apply_temporary_component_edit(...) 窄接口。
  RuntimeTemporaryEditSummary 记录 edited_entity_count / edited_field_count / last edited field / discard policy。
  StopPlaySession 丢弃临时编辑并输出 runtime_temporary_edits_discarded diagnostic。
  Property editing 将 TemporaryPlaySession commit 路由到 SetRuntimeComponentFieldTemporary。

editor_input / editor_ui_renderer / editor_window_winit:
  Hierarchy hit 根据 source_domain 路由 SelectSceneEntity 或 SelectRuntimeEntity。
  Runtime Hierarchy 中禁用 scene create / rename / delete 这类 authoring action。

project_e2e_gate:
  222 readonly inspector evidence 更新为 223 temporary editable evidence。
  增加 runtime hierarchy source、temporary inspector persistence、temp edit commit、stop discard evidence。
```

## 4. 残留风险

```text
Play Mode temporary edit 只覆盖 C-min allowlist，不是完整 Runtime Inspector 编辑系统。
没有 Apply Runtime Change To Authoring，用户想保留 Play 调参结果仍需要后续独立系统。
没有 runtime undo / redo。
没有 runtime hierarchy 搜索、过滤、component badges、多选。
没有 GPU object-id picking、3D depth / transparent picking。
没有跨进程 player inspect 或多 GameView / 多 RuntimeInstance inspect。
```
