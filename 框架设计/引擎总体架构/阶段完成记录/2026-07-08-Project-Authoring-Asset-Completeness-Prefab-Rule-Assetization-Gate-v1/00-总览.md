## 4. 关键边界

```text
ProjectAuthoringAssetCompletenessReport 是 editor / gate / AI 证据，不进入 runtime 热路径。
AssetizationCandidate 是可审查迁移建议，不代表静默自动修改。
Rule authoring assets 是 runtime manifest 的 authoring evidence；本轮没有把 Rust AOT sample gameplay 完整反编译成 IR。
```

重要残留风险：

