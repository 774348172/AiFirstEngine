## 施工范围

本轮按 229 方案 C-min 完成复杂打飞机 P0-2：

```text
RuntimePackage.rules
  -> RuleModuleRegistry
  -> ProjectLogicRunner
  -> EngineHostLoop / FrameLoop
  -> LogicContext + RuntimeCommandContext
  -> RuntimeInstanceLoader prefab instantiate/despawn
  -> Physics2D collision evidence
  -> GameplayRuleRuntimeExecutionReport
  -> project_e2e_gate complex shooter wrapper report
```

本轮不做完整 Rule Graph UI、完整 RuntimeEventQueue、IR VM、动态 DLL 热加载、generated rules crate build、HUD 真实绑定或 Windows golden gate。

## 主要改动

```text
engine_runtime:
  RuntimeRulePhase / ProjectRulePhase 新增 PostPhysics。
  RuleExecutionPlan 新增 post_physics 阶段。
  FrameLoop 在 Physics2D collision pair 生成后执行 PostPhysics rule。
  LogicContext 暴露只读 collision_pairs，不暴露 Physics2DWorld 可变内部对象。
  RuntimeFrameContext / EngineHostLoop::tick_with_runtime_context 接入 RuntimePackage + RuntimeInstanceLoader。
  RuntimeInstanceLoader 支持 prefab 中 structured RuntimeValue、entityRef remap、engine.collider2d typed hydration。
  RuntimePackageBuilder 把 input.prefabs 同步写入 RuntimeAssetManifest / RuntimeAssetIndex / CookedAssetTable，让 InstantiatePrefab 走 RuntimePackage asset 真相。
  新增通用 GameplayRuleRuntimeExecutionReport。

runtime_player_winit:
  从 RuntimePackage.rules + linked static registry 构建 ProjectLogicRunner。
  headless/native tick 通过 tick_with_runtime_context 传入 RuntimePackage 和 RuntimeInstanceLoader。
  linked static sample rules 覆盖 player-move、fire-bullet、linear-motion、lifetime-cleanup、collision-response。

project_e2e_gate:
  新增 complex-shooter-gameplay-rule-runtime-execution report。
  Gate 证明 manifest rules=5、prefab instantiate apply ok、collision pair>0、enemy hp write、session score write、score changed。

samples/complex_shooter_project:
  rule-manifest 补齐 linear-motion / collision-response，并把 fire-bullet 收敛到 Update + action_pressed。
  player_bullet / enemy_scout prefab 补齐 SpriteRenderer2D、Collider2D、linearMotion、lifetime、combatState。
  Main.scene 补齐 player collider/combatState、sessionState、collision evidence enemy placement，以及 lifetime probe。
```
