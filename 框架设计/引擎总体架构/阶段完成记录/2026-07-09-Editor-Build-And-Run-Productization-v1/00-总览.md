## 1. 完成范围

本轮把 Build 面板从只有 `Export / Output / Report` 推进到具备用户可用的 `Build & Run`：

```text
BuildAndRunDesktopPackage
  -> DesktopExportPipeline::export
  -> staged Build/Windows/dev/Game.exe
  -> UserWindowed launch or HeadlessVerification
  -> EditorBuildAndRunReport
  -> Console / Report Panel / project_e2e_gate
```

已完成：

```text
新增 UiCommandPayload::BuildAndRunDesktopPackage { profile_id }。
新增 command id：build_and_run_desktop_package。
BuildExportModel 增加 Build & Run 命令。
editor_input / editor_window_winit 可识别并路由 Build & Run。
EditorSession 新增 build_and_run_desktop_package 入口。
build_service 新增 EditorBuildAndRunRequest / EditorBuildAndRunReport / nested summaries。
UserWindowed 模式从 DesktopExportReport.player_executable 启动 staged Game.exe，working_dir 使用 package_dir。
HeadlessVerification 模式复用导出目录 Game.exe 的 headless gate。
新增 last_build_and_run_report。
Report Panel 新增 build.and_run provider。
project_e2e_gate 新增 editor_build_and_run report 与测试。
```

## 2. 关键边界

```text
Build & Run 不是 Play。
Play 继续走 217 Preview RuntimePackage / in-editor GameView 路线。
Build & Run 复用 DesktopExportPipeline，不新增第二套 build pipeline。
Build & Run 只启动导出目录内 staged Game.exe，不从 target/debug 直接启动 runtime_cli。
用户点击默认 UserWindowed：启动并记录 pid，不默认跑完整 231 golden gate。
自动化测试使用 HeadlessVerification：启动 staged Game.exe run-native-player --headless-gate。
```
