## 主要改动

```text
editor_core:
  PrefabRuntimeBakeReport / PrefabRuntimeBakeInstanceEntry 接入 ProjectRuntimePackageAssemblyReport。
  ProjectRuntimePackageAssembler 先收集 PrefabBakeCatalog，再 prefab-aware bake Scene。
  Scene PrefabInstance 展开时先按 prefab sourceEntityId resolve override，再做 deterministic runtime id remap。
  root sourceEntityId -> Scene placeholder entity id。
  child sourceEntityId -> {scene_placeholder_entity_id}__{sourceEntityId}。
  engine.prefab_instance 不进入 RuntimeScene components。
  "__" 作为 C-min reserved separator，sourceEntityId 命中时输出错误诊断。
  ResolvedPrefabEntity 保留 sibling_order / enabled。

project_e2e_gate:
  新增 complex-shooter-prefab-runtime-bake-report.json gate。
  验证 enemy-a / enemy-b 均由 prefab-enemy-scout bake。
  验证 RuntimeScene 不含 authoring-only engine.prefab_instance。

samples/complex_shooter_project:
  enemy_scout.prefab.json 补齐 SpriteRenderer2D / project.linearMotion。
  Main.scene.json 中 entity-enemy-a / entity-enemy-b 收敛为 prefab-enemy-scout Scene PrefabInstance。
```
