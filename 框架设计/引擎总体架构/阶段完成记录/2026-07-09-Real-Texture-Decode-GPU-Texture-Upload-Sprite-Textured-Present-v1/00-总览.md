## 施工范围

本轮按 228 方案 C-min 完成复杂打飞机 P0-1：

```text
Texture authoring asset / PNG source
  -> ProjectRuntimePackageAssembler build/cook PNG
  -> RuntimePackage cooked texture metadata + rgba8 payload
  -> Runtime texture payload load
  -> Sprite2D real texture binding
  -> RealWgpuBackend texture upload / sampler bind group
  -> project_e2e_gate real_texture_present evidence
```

本轮没有把 Runtime 改成读取项目源 PNG，也没有新增独立 TextureBridge；GPU resident texture 仍留在 RealWgpuBackend / WGPU resource 层，RuntimePackage 继续是运行时真相。

## 主要改动

```text
editor_core:
  ProjectRuntimePackageAssembler 识别 texture descriptor / .png source。
  Build/Cook 阶段使用 png 依赖把 PNG 解码为 RGBA8。
  RuntimePackageBuildInput 增加 texture_payloads 输入。

engine_runtime:
  RuntimePackageBuilder 写出 cooked/textures/*.texture.json 与 *.rgba8。
  RuntimePackage / RuntimeAssetIndex 记录 cooked texture metadata。
  新增 runtime_texture payload loader，校验 byteLength = width * height * 4。
  Sprite2DRenderPipeline 支持 Sprite2DTextureBindingContext，存在真实 binding 时不走 fallback。
  RuntimeRenderer 可传入 sprite_texture_bindings。
  RealWgpuBackend 增加 resident texture store、texture upload、textured shader、sampler bind group。

project_e2e_gate:
  新增 real_texture_present report。
  验证复杂打飞机 sample 至少 4 个 texture payload 被 assemble/load。
  验证 Sprite2D binding ready，并要求 fallback_count = 0。

samples/complex_shooter_project:
  texture .asset 从占位文本收敛为 texture-asset.v1 descriptor。
  新增真实 PNG source：player ship、enemy scout、bullet、starfield。
```
