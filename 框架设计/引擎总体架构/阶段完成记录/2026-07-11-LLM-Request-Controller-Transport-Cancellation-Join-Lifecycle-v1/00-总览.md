## 完成结论

INC-02 已关闭。Editor LLM 请求不再由 detached blocking worker 和 receiver-only cancel 管理；每个 logical request 现在由深 `LlmRequestController` 单一持有 transport cancellation、task、join、generate/repair 决议、prompt/context/credential lease 与 terminal receipt。

`Cancelled` 只在 task stopped、join 完成且 request-owned data 已释放后成立；`Cancelling` 始终保持 busy。普通 Cancel 超过 2 秒会 abort 并继续 join，Session shutdown 使用 5 秒总预算，Drop 使用 25 ms 快速 join 后把仍存活的 handle 交给 owned reaper。请求可能已经发往 provider 时，报告只声明本地执行已停止，远端执行状态保持 `unknown`，不声称远端推理或计费已取消。

## Gate A-F 实现范围

```text
Gate A：llm-patch-request-report.v3、lifecycle state/receipt、无 secret 的 cloneable transport config、不可 Clone 且 zeroizing 的 credential lease。
Gate B：异步 LlmTransport seam、ReqwestAsyncTransport、Tokio executor ownership；移除 ureq blocking transport。
Gate C：深 LlmRequestController，集中 start/poll/resolve_attempt/cancel/shutdown、single-active、single-terminal、panic 与 repair ownership。
Gate D：EditorSession、AiPanelStage::Cancelling、real window close、shutdown 与 Drop reaper 接入。
Gate E：Windows controllable loopback 覆盖 header/body/retry/repair wait、resubmit、shutdown、Drop、join-timeout fail-closed 与 privacy scan。
Gate F：Runtime/Player 依赖隔离审计、默认/all-features 双 workspace 回归、完成记录、入口同步与施工归档。
```

## 深 Module 与 Seam

```text
LlmRequestController interface：start、poll、resolve_attempt、cancel、shutdown。
implementation 隐藏：Tokio runtime、CancellationToken、JoinHandle、abort deadline、reaper、credential/prompt/context owner、repair task 和 race terminal latch。
LlmTransport seam：production ReqwestAsyncTransport + test ControllableLoopbackTransport。
```

caller 不再分别管理 receiver、线程、重试、secret clone 和 terminal UI。删除该 module 会把这些状态与竞态重新散回 `AiService`、`EditorSession` 和 window host，因此它提供了真实 leverage 与 locality；production/test 两个 Adapter 证明 transport seam 是实际变化点。

## Lifecycle 与 Report 证据

```text
schema：llm-patch-request-report.v3
validation schema：llm-worker-lifecycle-report.v1
Cancel deadline：2 s；超时 abort task，再通过 poll 完成 join。
Session shutdown deadline：5 s；超时返回 fail-closed receipt，不回 Idle。
Drop join budget：25 ms；未完成 handle 转交 owned reaper，不 detach。
terminal：Complete、FailedJoined、CancelledJoined、ShutdownJoinTimedOut；single terminal latch。
remote：请求可能已发送后 remote_execution_status=unknown。
credential：LlmCredentialLease 不可 Clone、zeroizing，不进入 Debug/serde/report。
```

loopback Gate 已验证 header wait、body chunk wait、`Retry-After` wait 和 repair second request 均可取消；取消期间第二请求被拒绝，join 后可重新提交。Session shutdown 能 join，Controller Drop 能由 reaper drain，1 ms 强制 join-timeout 场景保持 fail-closed。序列化 validation report 的 privacy scan 未发现测试 secret、prompt 或 context 泄漏。
