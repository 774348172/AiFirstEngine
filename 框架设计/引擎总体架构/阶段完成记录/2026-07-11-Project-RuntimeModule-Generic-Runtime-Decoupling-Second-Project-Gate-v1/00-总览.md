## 深 Module 与所有权

```text
ProjectRuntimeModule interface：descriptor + install。
ProjectRuntimeBootstrap interface：bind(package, linked set) -> BoundProjectRuntime + receipt。
implementation 隐藏：descriptor/digest validation、artifact registry、producer factory、input、diagnostics 和 runner 装配。
Adapter：complex_shooter_project_runtime、switch_puzzle_project_runtime。
```

删除该 module 会把项目身份、artifact、producer、input 和错误处理重新散回 Editor/Player/CLI caller，因此它提供了真实 leverage 与 locality。两个项目 Adapter 使 seam 可验证；Editor linked set 只在 session bind 前 exact lookup，export 为 singleton，不存在 per-frame/per-rule runtime router。
