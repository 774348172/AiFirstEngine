## 4. 耗时与失败收敛

施工耗时主要来自每次 exact-commit run 都要串行执行两套完整 workspace 矩阵，单轮约 8 分钟；clean detached worktree 又暴露了默认 target 旧产物长期掩盖的测试合同问题。

```text
首次运行：非默认 CARGO_TARGET_DIR 下 Project Player 路径硬编码，且深 build cache 使 cleanup 失败。
后续运行：Release/PE 独立 E2E 仍复制 rust/target/debug；内部 release test 在首次 Player build 前截取错误基线。
后续运行：quality_gate target resolver 单测依赖 ambient CARGO_TARGET_DIR。
后续运行：GitHub workflow contract 对 CRLF/LF 不稳定。
```

每次失败都生成 commit-bound artifact 并 fail closed；修复后最终 run 一次性通过，未降低 lint、PE、release、workspace 或 cleanup 合同。
