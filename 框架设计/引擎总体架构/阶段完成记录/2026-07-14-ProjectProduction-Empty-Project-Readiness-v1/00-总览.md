## 1. 结果

250 Phase 1 已完成。空项目和项目 Rust runtime 现在有明确不同的 source contract：

```text
BuiltInEmpty：不要求项目拥有 RuntimeModule/Cargo.toml，使用引擎 empty runtime/player。
ProjectRust：必须拥有受控的 project-relative Cargo manifest 和 src/lib.rs。
```

新项目 manifest 明确写 `sourceKind=builtInEmpty`，不再创建假的 `RuntimeModule/src`。旧 `aife-project.v2` 空项目未写 `sourceKind` 时继续按 `moduleId=engine.empty.runtime` 兼容解析。

新增深 `ProjectReadiness` Module，通过一个 `inspect` Interface 返回 Ready/Incomplete/Invalid/Unsupported、checks、diagnostics 和 next_actions。Project Launcher 的 recent validation 和 open path 共用该 Interface。
