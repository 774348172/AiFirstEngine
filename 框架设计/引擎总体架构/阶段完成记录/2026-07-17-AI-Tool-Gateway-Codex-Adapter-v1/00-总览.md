## 4. 性能与跨进程证据

- Gateway control-plane cold/warm startup、handshake、catalog/search 合同低于 5 秒，并确认未触发 Build、Library import 或 workspace compile；
- unknown-task 单通道预检实测约 2.84 秒，远低于 120 秒合同和两小时竞争预算；
- MCP stdio 真实子进程可通过 discovery + Named Pipe 完成 tools/list 与 catalog 调用；
- CLI 使用相同 discovery 与真实 Named Pipe；Native Editor Adapter 由 frame owner-thread pump；Test Adapter 与其它 Adapter 共享同一 invocation/result 语义；
- Gateway Build/Delivery 首次定向运行曾在 184 秒外层超时，诊断确认是冷链接接近 deadline、无残留 Cargo/Game/test 进程；缓存复跑 10 秒通过。之后外层预算显式覆盖 cold link，不修改引擎语义掩盖问题。

- 历史 Git index 含 `AiFirstEngine` gitlink，但仓库没有 `.gitmodules` 映射；本轮只在冻结清单中如实记录，没有擅自修复或删除。
