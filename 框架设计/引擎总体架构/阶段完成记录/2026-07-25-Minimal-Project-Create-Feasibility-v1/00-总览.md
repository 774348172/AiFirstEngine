F0 证明现有 Native Editor CreateProject owner 可以局部加固，但 production Gateway 在
host、discovery、ClientHello、SessionBinding、request、invocation 与 operation 层均以
已打开项目为唯一身份。launcher/no-project 时 Native Editor 会销毁 Gateway host。

要暴露 `project.create`，必须新增 launcher host/discovery/binding，并定义创建后的
rebind/reconnect 状态转换。这精确命中正式方案的复杂度停止线，因此没有进入功能红测试
或产品源码施工。

## 4. 四项结果

```text

```

关键证据：

- `NativeEditorApplication::reconcile_gateway_host` 在没有 active project 时删除 host。
- `GatewayCore::connect` 在协商前强制读取 active project binding。
- `ClientHello`、`ClientSessionBinding` 和 `GatewayRequest` 均强制 project identity。
- MCP process smoke 在启动 production MCP 前先创建项目和 project discovery。
- CreateProject 骨架创建集中在同步 `ProjectLauncherState::create_project` owner 内。
