# 265 AUI Effective Visibility / Stable GameView Surface / Editor Frame Publication v1 完成记录

## 结果

265 Gate A-E 已完成。AUI computed state 现在区分 local/effective visibility，隐藏父节点的后代
保留 layout rect，但不会 draw、hit、focus、navigate 或 dispatch action；输入批处理前会幂等清理
focus、pressed、drag、scroll capture、InputField/IME 与 modal transient state。

GameView Runtime 内容身份与 Editor surface 生命周期已经分离。相同 `(sessionId,targetId)` 的连续
frame 使用稳定 surface，只有 resize/format/session/target 变化才替换 backing 并推进 generation；
成功 Runtime submit 才推进 publicationIndex。compact typed receipt 绑定 content、surface、
generation、publication、submit serial、extent、format 与 status。

深 `EditorFramePublicationModule` 统一 last-good、redraw reuse、frame regression 和 receipt 校验。
普通窗口与 production authority 都遵循 `publish -> compose -> present -> optional exact readback`；
present getter 和 redraw 不再隐式 tick Runtime。exact readback 会拒绝 stale receipt。
