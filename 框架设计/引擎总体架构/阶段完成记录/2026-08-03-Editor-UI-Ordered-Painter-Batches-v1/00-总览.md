## 结果

相邻有序 batch”。`UiGpuDrawPlan v2` 记录 kind / first item / item count，RenderGraph、
RHI command 和真实 WGPU consumer 保留同一顺序。缺失 viewport/image texture 的
placeholder 也在原 painter 位置绘制。

`Text -> modal Rect -> modal Text` 修复前稳定失败为
`[DrawRectBatch, DrawTextBatch]`，修复后为
`[DrawTextBatch, DrawRectBatch, DrawTextBatch]`。视觉结构哈希已纳入 paint batch 顺序。
