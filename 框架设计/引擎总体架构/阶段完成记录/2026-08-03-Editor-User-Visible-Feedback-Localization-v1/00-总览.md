# Editor User-Visible Feedback Localization v1 完成记录

## 1. 结果

267-R1 已完成。默认 `zh-CN` 下，Native Editor 红色 interaction feedback banner 不再直接
显示未迁移的整段英文错误：已登记消息显示具体中文，未登记动态消息显示中文失败摘要与稳定
诊断码，并引导用户查看控制台。core `CommandResult` 的英文 fallback、路径、模块 ID、command ID
与日志协议均未被翻译或破坏。

截图中的消息：

```text
The running Editor does not contain the requested ProjectRust module.
```

现在显示为：

```text
当前运行的编辑器未包含项目所需的 ProjectRust 模块。
```

## 2. 实现

- `EditorCommandFeedback` 增加可选 `diagnostic_code`，旧序列化输入保持兼容。
- `command_feedback_from_result` 与直接 rejection producer 保留稳定诊断码。
- 红条先执行 Catalog 精确翻译；中文环境未命中时使用带诊断码的 Catalog 通用摘要。
- `en-US` 继续显示原始英文消息；原始诊断详情仍留在反馈/诊断模型中。
- `zh-CN` / `en-US` Catalog key 与 typed argument 合同保持一致。
