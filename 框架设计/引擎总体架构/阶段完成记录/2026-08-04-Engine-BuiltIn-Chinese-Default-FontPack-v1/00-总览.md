# 271 Engine Built-in Chinese Default FontPack v1 阶段完成记录

日期：2026-08-04

## 完成范围

Gate A-F 已完成。引擎导入 hash-pinned Noto Sans SC Regular 与 OFL provenance，基于
hash-pinned jieba-rs 高频语料和引擎 zh-CN Catalog 冻结确定性 glyph spec/lock，并离线生成
sealed `aife-default-zh-cn-common-v1` FontPack。普通 AUI 项目没有项目 DefaultUi profile 时，
`ProjectRuntimePackageAssembler` 直接注入编译期内嵌 FontBundle；项目 DefaultUi/Additional
profile 继续复用 261 cook 和 270 artifact cache。RuntimePackage 仍是 Runtime 唯一输入。

## 关键修复

1. producer 在进入公共字体 cook 前 canonicalize repo-owned FontPack 路径，不放宽项目路径安全合同。
2. hinted raster 正确接受 whitespace 返回的全零 bitmap，并保留 advance。
3. Noto Sans SC 不含 U+FFFD cmap mapping；sealed producer 显式将其映射到 U+25A1 可见方框，
   使用未占用 synthetic glyph id 满足 Runtime FontBundle 唯一键。
4. Font profile reference validation 改为“最多一个 DefaultUi”；Additional-only 项目可由
   built-in default 加项目 Additional bundle 组成。
