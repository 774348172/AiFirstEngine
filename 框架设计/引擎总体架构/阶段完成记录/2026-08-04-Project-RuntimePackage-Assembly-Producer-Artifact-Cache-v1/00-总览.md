## 结果

`ProjectRuntimePackageAssembler` 已从单一总耗时报告深化为类型化 `producerReports`。新增
`ProjectAssemblyArtifactCache` 使用 producer/recipe/schema、字体资产声明、源字体内容、规范化
codepoint/kerning requirements 与 raster/packing profile 构成内容寻址 identity；mtime、绝对项目路径
和 Editor 非运行状态不参与正确性身份。

`ProjectFontCookModule` 在 Bitmap/MSDF raster 前完成 recipe 准备和 cache lookup。命中后验证 envelope、
payload digest、typed FontBundle schema/page contract 和 output digest，直接复用 sealed
`ProjectFontRuntimePackageCook`；miss 才执行原有确定性 Cook 并原子 publish。同 key 并发 publish 复用
唯一 winner，冲突 output fail closed；Corrupt/Invalid artifact 隔离后重建。

Preview caller 显式在 `ProjectWriteScope` containment 后传入 `.aife/derived-data`；Runtime、Export 包和
项目资产不读取 producer cache。Assembly report v2 的 producer report 已嵌入 Preview assembly stage，
其它 producer v1 先提供计时边界，不谎报真实缓存。
