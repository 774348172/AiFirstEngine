# 280 Project-Level GameView Target / Editor Selector v1 完成记录

日期：2026-08-10

## 结论

普通 Editor 的项目级 GameView target 源码链路已闭环。项目可以在
`Settings/project_settings.json` 的可选 `editorPreview.gameViewTarget` 中声明默认 target；
OpenProject/RecentProject 会把该值装入 EditorSession，既有 PlayService 再把它传给 273
`GameViewPresentationModule`。GameView header 不再只是静态 `16:9 Landscape` 文案，而是提供
三个 target preset 与 `Contain/Stretch` session selector。

Tower 已声明 `720x1280 + Contain`。AUI 的 3 个 Canvas 仍全部使用 `1080x1920` reference，
项目 preview target 与 UI layout space 没有混淆。

## 首因与红绿证据

首个红测：

```text

left:  GameViewTargetSpec 1280x720 Stretch
right: GameViewTargetSpec 720x1280 Contain
```

实现后同一测试通过。无设置字段的旧项目继续得到 legacy default；非法 target 在 ProjectLauncher
open seam 以 `project_settings.game_view_target_invalid` 拒绝，不静默回退。

## 施工范围

- `engine_runtime`：公开复用 `GameViewTargetSpec::validate` owner。
- `editor_core`：typed settings、ProjectSession carry、open/recent adoption、session target command 与
  Play-active guard。
- `editor_ui_model/editor_ui_renderer/editor_input`：target view model、retained segmented controls、
  typed input payload、selected/disabled pseudo-state 与中文 catalog。
- `editor_window_winit`：command registry 与 viewport focus domain consumer。
- Tower：项目设置默认竖屏 target。

未修改 273 projection/input 数学、AUI reference resolution、Player/BuildProfile/export、字体/MSDF、
Tower gameplay 或 UI layout。
