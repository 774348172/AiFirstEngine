# 284 Editor GameView Normal-Frame Immediate AUI Input Dispatch v1 完成记录

## 结果

- 普通 Editor GameView 输入不再同步触发完整 runtime/fixed tick；AUI hit、按钮 feedback、业务 action 与
  observation/binding refresh 在 normal-frame input stage 完成。
- 战斗、物理、怪物移动和 Animator2D progression 仍属于 fixed tick；即时 stage 只 apply 离散
  Animator2D command，不推进动画时间。
- AUI 未消费的 gameplay input 进入 active Play instance 的有界 pending state，在下一 normal tick 消费一次；
  PointerMove 合并，FocusLost/cancel/Stop/session replacement 清理，不重放 AuiAction。
- `GameViewRuntimeFrame` 新增向后兼容的 `auiPresentationIdentity`。identity 只绑定可见 AUI stages、glyph plan
  和 canvas references，不包含 runtime frame index 或 diagnostics。
- `EditorFramePublicationModule` 统一拥有 last-good reuse 判断：runtime identity 相同但 AUI identity 改变时
  重新 publication；全部 identity 相同时继续复用。`real_window` 不再维护第二套 fast-reuse 条件。
- Tower linked RuntimeModule consumer 证明 `td.recruit` 在 fixed tick 前提交，下一 normal tick 不重放。
