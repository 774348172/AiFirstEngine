# 286-R1 GameView Contain / Camera2D / Texture Last-Good Minimal Repair v1 完成记录

## 结果

- GameView `ViewportTextureSlot` 与 `HitTarget::Viewport` 使用同一份
  `GameViewPresentationModule::resolve(...).display_content_rect`。`720x1280 Contain` 不再把纹理拉伸到
  整个 landscape panel，输入与可见区域保持一致；`Stretch` 兼容路径不变。
- `EngineHostLoop` 从已水合 World 中选择启用的 `kind=camera`、读取现有
  `project.camera2d.orthographicSize` 与 Transform，并写入 Game `RenderViewState`。Sprite2D 顶点消费
  view/projection matrix；场景没有合法 camera 时才使用原兼容默认投影。
- `RealWgpuBackend` 在 encoder、clear、submit、present 前验证必需纹理 handle 驻留状态。缺失时输出
  `wgpu.texture_binding_missing` Error 和具体 handle，不再使用无纹理 solid pipeline 绘制白色 fallback。
- Editor 在稳定 GameView texture allocate/resize 前执行相同预检；失败帧不调用 `mark_published`，
  `EditorFramePublicationModule` 保留上一张正常 receipt 与 publication index。
