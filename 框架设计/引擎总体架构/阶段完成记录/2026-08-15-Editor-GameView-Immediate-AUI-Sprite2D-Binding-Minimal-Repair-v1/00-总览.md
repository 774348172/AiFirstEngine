# Editor GameView Immediate AUI Sprite2D Binding Minimal Repair v1 完成记录

## 结果

290 已完成。普通 Editor GameView 的即时 AUI 输入重绘现在与普通 fixed tick 一样持有
Sprite2D texture bindings；点击或触摸按钮时，棋盘 Sprite2D 不再降级到白色 fallback。

## 红证据与根因

新增 owner 回归 `editor_gameview_immediate_aui_input_preserves_sprite_texture_binding` 在修复前
稳定失败：即时 PointerDown 后能找到 `texture-board` 的 Sprite2D textured draw，但
`fallback_used=true`。测试本体耗时 0.04 秒。

根因位于 `EditorRuntimePlayInstance::route_aui_input_immediately`。普通 fixed tick 会从
`RuntimeTextureBindingContext` 派生 `Sprite2DTextureBindingContext`，即时 AUI 重绘却把该参数
传为 `None`，随后 Sprite2D pipeline 合法但错误地选择白色 fallback。下一普通帧重新带回真实
binding，因此形成点击一次白闪一次。

## 最小修复

`EditorRuntimePlayInstance` 启动时从已经加载的 runtime texture bindings 派生并保留
Sprite2D bindings；即时 AUI 重绘把这份 bindings 交给原有 render-thread API。没有新增 schema、
owner、renderer 分支、fallback 策略或缓存协议。
