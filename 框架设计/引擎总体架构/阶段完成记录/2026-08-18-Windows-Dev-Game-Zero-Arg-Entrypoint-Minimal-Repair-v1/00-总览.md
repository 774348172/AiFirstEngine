# 297 Windows Dev Game Zero-Arg Entrypoint Minimal Repair v1 完成记录

状态：已完成并归档。

## 根因与修复

- `DesktopExportPipeline` 生成的是 `desktop-package-manifest.v1`。
- `Game.exe` 无参数入口此前只按 `release-package-manifest.v1` 反序列化，因此真实 Windows dev 包在约
  `0.27s` 内以 `release_manifest_invalid` / exit 2 退出。
- `runtime_cli` 现在先读取 `schemaVersion`。release manifest 继续走原有 file-role、hash、entrypoint
  和安全路径校验；desktop dev manifest 仅接受 `target=windows`、`profile=dev`。
- desktop dev 包不信任 manifest 内机器绑定的绝对路径，固定从当前可执行文件同目录解析
  `data/runtime_package`。

未新增 schema，未修改 exporter、Tower 项目或 RuntimePackage 内容。
