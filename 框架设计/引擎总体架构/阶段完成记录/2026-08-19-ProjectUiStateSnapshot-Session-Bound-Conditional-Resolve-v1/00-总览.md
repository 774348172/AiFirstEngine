## 完成范围

Project UI snapshot 主链路从无条件 `produce` 切换为一次原子 `resolve(previousIdentity)`。Core 统一
opaque session identity、canonical binding-set digest 与 `Reuse / Replace / Uncacheable`；ABI minor 更新为
1，SDK/wire callback 改为 `resolve_ui_state`。Native Adapter 通过 bind-local session bundle 让 gameplay
session 与 UI producer 共享同一非 NULL native handle，唯一 lease 负责 exactly-once destroy。

Tower 在项目 RuntimeModule 内维护 producer epoch、visible revision、active binding set、last visible
projection 和 FPS sampled revision。clean frame 在创建 `AbiWorldRead` 之前返回 Reuse，因此 World query、
component read、path/value production 与 values payload 均为 0；怪物普通 Transform/Animator/unchanged
projection 不推进 UI revision。Editor 与 Player 共用 `ProjectUiStateSnapshotCache` consumer。
