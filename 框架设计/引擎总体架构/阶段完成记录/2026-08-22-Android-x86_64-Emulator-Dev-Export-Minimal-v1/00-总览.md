## 结论

304-E1 已完成并归档，能力状态为 `sourceAvailable`。Android dev exporter 新增显式、单 ABI 的
`x86_64` 模拟器出口；不带 `--abi` 时仍保持 `arm64-v8a` 默认行为。

```text
arm64-v8a -> aarch64-linux-android -> android-arm64-dev -> Build/Android/dev
x86_64    -> x86_64-linux-android  -> android-x86_64-dev -> Build/Android/emulator-x86_64
```

typed ABI 同时驱动 RuntimePackage target、Rust target、NDK linker、Cargo env、JNI 目录、Gradle filter、
package manifest 与 APK 单 ABI 校验。未知 ABI、未知 RuntimePackage target 和多余 CLI 参数继续 fail-closed。
