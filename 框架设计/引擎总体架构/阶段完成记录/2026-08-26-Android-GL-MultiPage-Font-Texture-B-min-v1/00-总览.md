# 306 Android GL Multi-page Font Texture B-min v1 完成记录

## 结果

306 已完成。根因已由强制 GL 的实际像素回归确认：旧实现把同一 render mode 的字体页放入 array texture，
再以普通 `D2` view 绑定非零 array layer；GL 下 Bitmap page 1 实际读回 `[0, 0, 0, 255]`，与上传的
全覆盖页面不符。

`RealWgpuBackend::register_font_texture_arrays` 现在仅在 backend 为 `Gl` 时为每张 Bitmap/MSDF page 创建
独立二维纹理并上传到 `z=0`。Vulkan、Dx12、Metal 与其它 backend 保持既有 array texture 策略；page
handle、generation retirement、sampler、bind group 与 consumer 合同未改变。
