## 首因与修复

1. Windows extended path直接写入 generated Cargo manifest 无效：generator统一输出Cargo可接受路径。
2. generated descriptor曾使用模块摘要代替逐Rule artifact identity：改为从lease-owned Rule manifest结构化派生。
3. Editor builder曾把gameplay crate强制改成`cdylib`：gameplay保持普通Rust library，仅generated wrapper产出`cdylib`。
4. loader曾无条件要求全部optional capability：改为capability bit与callback成对校验，Sessions保持必需。
5. Gate D workspace编译被旧sample Module/Player阻塞：删除第二套checked-in ABI pipeline，E2E统一经Compiler生成DLL。
6. workspace check发现`editor_window_winit` production preparer漏接glue：迁为Context lease -> Compiler prepare，并新增窄owner test。
