## 失败、修正和边界

- 初次 Node 子进程环境下默认长缓存路径触发 LNK1181；改用任务专用短构建根 `G:/a323-cache` 和显式工具链后成功，未改系统设置。
- 一次构建期间项目 README 变化触发 revision drift 拒绝；冻结项目修订后重新构建通过。
- 场景 HP 的整数 3 与 number 合同不匹配，修为 3.0；真实失败保留 sourceLocation。
- 静止顶端航线不会稳定受伤：原玩法只接收敌弹伤害，自动双发又能提前击杀同航道敌人。改用真实穿越敌弹的输入，在 headless 上先得到确定通过信号；没有改玩法或 HP 来迁就场景。
- 柔光生成时 Math.Max 的整数重载使 alpha 二值化，改为浮点后 alpha 采样为 0/6/22/75/156/245；截图确认柔和过渡。
- Computer Use 能截图，但两个启动方式下点击/拖动/关闭均无可观察响应；没有判定具体宿主根因。转为既有入口的原生指针回放，实证完整游戏链；第 1 帧注入曾被初始化 OS CursorMoved 覆盖，测试移至第 61 帧，未屏蔽真实用户输入。
- 未安装/替换宿主 Provider、Editor 或 config。新 AUI 枚举由源码 Provider 的独立进程构建；安装版 Provider 不应被描述为已经支持本轮新增绑定。
- 未改 Boss、道具、声音、通用粒子编辑器；未做全 workspace、Local CI、全平台或三档性能矩阵，因为本轮不作这些资格声明。坐标转换仍使用项目 1280×720 / 正交跨度 15 的明确约定。
- 所有自动测试进程已结束。用户试玩窗口作为交付保留；独立 Provider 会话已关闭。`G:/a323-cache` 与 `G:/a323-opt` 保留为本轮拥有的缓存/产物/诊断目录，没有删除用户或共享目录，没有提交工作树。
