# 345 AUI GlyphRun 字体方案 C 完成记录

2026-09-16，`source_and_windows_dev_delivery_passed`。方案 C 的 Gate A–D 已完成，施工归档；最大化/精确 1600×1000 按原施工约定延后。344 保持暂停，本记录不授权恢复美术施工或更新安装。

## 完成能力

RuntimePackage 携带 digest 保护的 FontFace bytes；loader 校验后，AUI 调用 rustybuzz（HarfBuzz 算法的 Rust 实现），以 GlyphRun 的 glyph/cluster/advance/offset 和真实字体度量生成 LineLayout、GlyphQuadPlan。fallback 与按钮基线统一，旧无 source bytes 字体保留显式兼容路径，Renderer 不承担 shaping。

字体 cook 对 MSDF 重叠轮廓做 NonZero 合并，消除笔画交接内缝；沿用 atlas/Renderer 和 RuntimePackage 主链。激光小屋房间标题框高度适配真实行指标。Gate D 仅补跨项目与独立交付证据，没有额外引擎源码修改。

## 验证

- Gate B：127 项 runtime 与 19 项 authoring 回归，FontFace 磁盘往返/损坏拒绝、cluster/fallback/度量及真实 cook 消费闭合。
- Gate C：27 项 authoring 回归覆盖并替代前述 19 项；六字号 14/18/24/32/48/64、Bitmap/MSDF 真实样板，以及普通/断电/暂停/失败/通关 Windows dev 1280×720 截图通过。缺字/裁切 0，fallback false。
- Gate D：复核身份后复用 127+27 内部回归；149 文件激光小屋与 27 文件第二字体项目在仓库外运行通过。原版三房/失败恢复共 24 条断言、20 张捕获；第二字体实际显示“中界”，2 字形无缺字/裁切/fallback。
- 第二项目占位模块的格式检查和缺少 fixed_update/UI handler 曾失败，修复隔离副本后重新导出并验收；首因完整保留。通用窗口启动成功不替代真实字体截图。
