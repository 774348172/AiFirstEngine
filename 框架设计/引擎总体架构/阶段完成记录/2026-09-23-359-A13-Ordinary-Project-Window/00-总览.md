## 1. 实际完成

新增普通项目 `samples/three_d_lab_project/`，包含 v3 manifest、Scene/Prefab、GUID 资产、generated cube/plane、Unlit 材质、方向纹理、Input、AUI、Rust RuntimeModule 和 Windows dev profile。项目通过现有 Provider inspect/check/build/delivery verify 完成构建与真实窗口显示；没有专用启动旁路。静态 AUI 使用缓存的空 UI snapshot 回调进入正常 HUD 链，显示真实文字。

EngineHostLoop 在原 dirty 提取应用后投影 mainCamera，从现有 RenderSceneState 的 Mesh3D Projection 准备几何。内部 ProductionGeometryCache 按包路径/contentHash 与 mesh/material 引用缓存 Prepared 产品，继续使用原 RuntimeAssetLoader/RuntimeRenderAssetProducer 和 dispatcher/RenderThread 共享的同一个 RenderResourceManager。跨 worker 只传递不可变快照，不传 World、loader 或可变资源表。

RenderThread 根据实际 target/extent 构建原 GeometryFrame，经原 RuntimeRenderer::build_with_geometry、RenderGraph/RHI 执行。相机、变换和尺寸变化复用 Prepared buffers；零尺寸不产生几何绘制。缺少 runtime package、相机或资产时按原诊断链失败，不把空画面报告为成功。生产调用在 worker flush 后取回结果，共享资源锁不跨等待持有。

两个真实窗口消费路径都把 Prepared textures 交给原 WGPU texture map。相同句柄不重复上传，过期几何独占纹理由原 owner 回收，公开注册的共享纹理保留。没有增加第二上传 registry 或 Renderer。

普通生产 staging 现在接受既定的 aife-project.v2/v3，仍拒绝未知 v4。Compiler.build 的空间场景临时阻断已移除。`engine_runtime_run` 增加已有 `windowed` 模式，默认仍为 headless；窗口运行组合原 build 与 verify，使用固定 Host/Engine DLL，复用原结果、超时与诊断合同。没有修改包 schema、SDK/ABI 或九工具结构。
