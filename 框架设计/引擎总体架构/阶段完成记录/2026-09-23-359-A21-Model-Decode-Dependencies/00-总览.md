## 2. 已实现的输入合同

| 输入/风险 | A2.1 实际行为 |
| --- | --- |
| glTF/GLB | glTF 2.0；minVersion 缺省或 2.0；GLB v2 严格总长度、JSON/BIN 顺序、对齐、范围及尾随数据校验 |
| 闭包 | 选定 scene → node → mesh/primitive → accessor/material/texture/image/sampler → bufferView/buffer；记录 consumed/unconsumed |
| 几何 | triangle-list；indexed/nonindexed；u8/u16/u32 索引规范到 U1 u16/u32；FLOAT POSITION/NORMAL，FLOAT 或 normalized U8/U16 UV0/COLOR0；RGB 补 alpha=1 |
| 数据验证 | accessor/view offset、stride、组件对齐、计数/范围/溢出、索引范围、finite；颜色范围、真实 AABB/sphere；带 baseColorTexture 必须具备 UV0 |
| 图片 | PNG/JPEG；external/data URI/GLB bufferView；MIME 与内容匹配；输出真实 RGBA8，解码前检查像素和字节预算 |
| URI | 同目录下的安全项目相对引用，允许百分号编码空格；拒绝网络、绝对路径、冒号、反斜杠、`.`/`..`、编码穿越、query/hash/control、缺失依赖及 inventory reparse |
| 不支持语义 | 被消费的 sparse、Draco、meshopt、skin、morph、animation、UV1/其它顶点流及 texture transform 等明确失败，不生成占位几何 |
| 扩展 | 未支持 required extension 全局拒绝；未知 optional payload 记录位置与 ignored/degraded；未消费内容或仅声明的扩展记录 unconsumed；独立 root light 定义不等于 selected node 使用灯光 |
| 相机 | 源 camera 记录 notImported，不替换项目明确指定的主相机；A2.1 不装配节点变换 |

结构引用由成熟 parser 先验证，即使位于未选 scene，也必须是结构合法的 glTF；未消费的语义和外部文件不被误计为已支持。A2.2 的完整材质策略/采样/节点变换验收尚未完成，不能把本表的 decode accepted 解释为模型可直接发布运行。

预算沿用 A0 的 v1 默认上限：源依赖总计 256 MiB，单图片 16,777,216 像素，解码图片总计 256 MiB，2,000,000 顶点，6,000,000 索引，10,000 节点，深度 128，派生 payload 512 MiB。只允许向下收紧。完整文档节点数在 typed parser 分配前检查，选中层级深度在 DFS 进入前检查；初始 JSON 受源文件字节上限约束。

源字节按不同物理文件计一次，内嵌 data URI/GLB 不重复累计源文件体积。几何预算按规范 float 布局和最坏四字节索引在分配前预留；`reservedCookedBytes` 是预留上界，不冒充最终 Cook 文件大小。解码图片计入 decoder 原生输出与规范 RGBA8 中较大值，累加检查；不把压缩文件大小当作解码预算。
