## 1. 实际接通的链路

普通项目源文件 → Compiler snapshot → 私有model_import → 原neutral assembler/render_asset_cook → RuntimePackage → 原Prefab loader/Prepare/World Projection → GeometryFrame/RenderGraph/RHI/WGPU。

- Compiler.check完整检查导入语义，报告`stage=assembly`、`assemblyAvailable=true`、recipe `render-native.imported-static.v1`。该字段只表示可装配，不替代GPU/窗口验收。
- prepare移除旧的整体import execution-unavailable拒绝，输出实际Mesh/Material/Texture和层级Prefab。描述文件不再作为普通runtime asset重复输出。
- 原Cook新增共用finish入口；导入与原生资产共用CookedRenderAsset、资源管理和运行消费链，没有第二个Compiler、资产registry或运行时glTF parser。
- RuntimePackageSourceAsset携带可省略subAssetId，Prefab source可携带可省略identity；原索引保留GUID、稳定子资产key、descriptor源路径及依赖。缺失/重复GUID、空子资产key和无法解析的Prefab依赖在写包前拒绝。
- 普通原生材质可以引用导入图片。GLB内嵌图片进入实际纹理payload、manifest及依赖，材质sampler进入原typed texture variant。

## 2. 支持矩阵与身份边界

| 项目 | A2.2实际行为 |
| --- | --- |
| 材质策略 | 缺省strictUnlit只接受KHR_materials_unlit；PBR必须显式baseColorOnly，逐项报告lighting、metallic/roughness、normal/occlusion/emissive等丢弃语义 |
| 基础外观 | baseColorFactor、baseColorTexture、UV0、顶点色、OPAQUE/BLEND、doubleSided；BLEND沿用TestOnly与原排序，OPAQUE为TestAndWrite |
| 采样 | nearest/linear、repeat/clampToEdge/mirroredRepeat；缺省linear/repeat；MASK、mipmap filter、UV1及texture transform明确拒绝 |
| 坐标 | 默认RH/Y-up/米制为identity；Z-up转换为(x,z,-y)，left再翻Z，position/translation应用单位，normal变换并归一化，负determinant换三角绕序 |
| 节点 | local按C*M*C^-1转换，保留层级；有限、可逆、可无损分解的TRS进入原canonical Transform3D；shear/奇异/非法旋转定位到源node后拒绝 |
| Mesh | 同源Mesh的多个primitive合并，保留命名slot和独立material绑定；48字节规范POSITION/NORMAL/UV0/COLOR0布局，缺省值只用于未使用的optional stream |
| 预算 | 规范几何/图片分配前检查；非分配writer测量实际Mesh/Material JSON、格式化Prefab JSON、纹理元数据和RGBA payload；边界对照真实发布文件大小 |

预算针对该模型拥有的payload文件；整个包共享的manifest/index由既有RuntimePackage owner管理。纹理元数据和Prefab JSON在导入中构造一次，预算与assembler消费同一份数据，不维护第二套输出模板。

稳定身份仅来自**已提交**的outputs/nodes映射，不由数组index、name或内容hash分配长期GUID。A2.2约定sourceLocator为`/meshes/N`、`/materials/N`、`/images/N`、`/scenes/N`和`/nodes/N`；默认材质使用`/materials/default`及JSON null指纹。sourceFingerprint是locator对应JSON对象的canonical serde_json SHA-256。缺失、变化、重复或未消费映射均拒绝；选中node须恰好一个entityId映射，Prefab容器root为`{prefab.key}:root`且拒绝碰撞。

这只是消费既有映射的边界。首次映射规划、歧义处理、重排/重命名、显式重映射CAS、重导入事务、增量复用和实例override稳定性资格属于A2.3。check/build不回写source。普通Scene直接引用导入Mesh/Material，派生Prefab由原loader实例化测试；本阶段不新增Scene Prefab instance schema或spatial SDK。

## 3. 两处真实消费缺陷及修复

**OPAQUE alpha：** GPU红例得到`[255,0,0,0]`，违反glTF OPAQUE忽略输入alpha的语义。既有原生/generated Opaque只禁用混合，原GPU合同要求保留输出alpha，不能全局改写。CookedMaterial/DrawGeometry增加缺省false、序列化省略的`opaqueAlpha`；仅导入OPAQUE置true，原Prepare传递，原WGPU shader在此变体输出alpha=1。仅true派生新pipeline identity；true与非Opaque组合拒绝。导入GPU与原生alpha128/64的独立GPU测试均通过。

**派生预算漏计：** 初始计数漏掉纹理metadata及Prefab发布格式。按实际模型文件独立求和，红例为报告3433字节、实际5088字节。修复后两者一致；预算少1字节拒绝、恰好等于实际payload通过。首个探测夹具误把同项目generated资产一起计入10756字节，已收紧为本descriptor拥有的文件，保留17/18两份日志，不把夹具误计当产品缺陷数值。

另保留首轮编译usize/u64错误及unused re-export修复；坐标测试曾把f32单位0.01的乘积直接写成0.05，改为独立f64乘法再舍入的精确期望，未放宽产品规则或像素容差。Provider测试自审改用已有sha2和发布JSON记录，避免为了测试新增Runtime依赖。全阶段无需修改正式方案路线。
