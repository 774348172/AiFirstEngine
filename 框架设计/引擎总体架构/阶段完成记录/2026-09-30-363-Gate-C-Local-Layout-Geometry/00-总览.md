## 完成范围与依赖边界

`AuiLayoutSource` 共享不可变节点 Arc 和 ID/slot 索引，每 Canvas 的 Taffy 树只驻留其根可达节点。ParagraphContext 借用共用索引。冷挂载复制一次 N 个源节点；之后只准备真正变化的节点，新 Canvas 或结构基线变化可重新准备一次共用源。未新增公共节点模型、schema 或 ABI。

rect、slot、layout、字号、段落输入、显隐及 custom 输出更新已挂载 solver。整批源输入先安装再推导约束。Canvas 根尺寸变化更新约束，合成和拓扑稳定时局部刷新最终几何。结构按稳定 ID 重新映射；拓扑变化的根重建，独立根保留。Session 仅在结构事务成功发布时转移可复用布局，失败草稿不动旧实例。

布局隔离使用明确尺寸的 Anchor/manual 或 OutOfFlow 区域，局部求解后保留父级拥有的位置。Flow/Grid/Flex/content/baseline 依赖正常传播；custom 和隐藏布局依赖保守扩大到根。字体资源变化仍允许保守刷新测量和最终段落，不宣称全局资源输入已 O(k)。公开全量 `solve` 保留验证和源比较，同时补齐 rich text、placeholder、custom 输出的测量失效。

Translation 直接消费变化 ID 集合，覆盖零值恢复、移除和跳过呈现的多次观察；完整基线恢复比较新旧 key 并集。后代变换、裁剪和命中索引一致；共享 Canvas 根各有必要几何。RectOffsetX/Y 接入局部绑定准备，保持类型/有限值校验、覆盖顺序、Translation 合成、段落预检和旧帧 COW。Canvas 根绑定仍保守回退。非法约束淘汰失败根并强制重同步，不无条件清空独立 solver。

## 红测和修复

1. 单文字节点改宽度，原先 solver 构建数 1→2；现在宽度、字号和 Canvas 尺寸连续更新均保留 solver，与 fresh Layout/Paragraph 一致。旧测试要求字号/viewport 重载源，与新合同相反；改成零源重载、solver 不增长及 fresh 对照，保留实际高度/宽度变化断言。
2. 1000 个固定区域中改一处文字，红测访问 2004 个布局节点；隔离后通过 `< 20` 访问断言，只测量一个文字，几何及 overflow summary 与 fresh 相同。
3. 父节点 Fixed→Content 使百分比子节点非法，恢复后再合法编辑仍报 `aui_layout_indefinite_percent_basis`；修复失败根恢复。父改 Content、子 Percent→Fixed 的同帧合法批次也曾错误失败；修为整批输入后配置。
4. 旧 viewport consumer 直接匹配 `&Arc<AuiDrawCommand>` 导致三处 E0308；改用 `command.as_ref()`，保留 draw/hit/root 断言。混合绑定夹具缺 atlas glyph/page 而为 Partial，补齐真实 Noto 字体的 CPU 字形计划夹具后严格 Success/恢复通过；该夹具不是 GPU 视觉证据。平移夹具向不存在的 Binding owner 释放曾报 BindingUnavailable，改为真实零值恢复及实例卸载，不改变产品权限规则。
