## 完成范围

绘制缓存保存可见 computed slot、命令范围、stage 顺序及 command/item/glyph 片段索引。可信几何 journal 和反馈变化集合直接进入对应片段，不再先扫整个节点数组寻找变化。稳定 arity、stage、canvas、kind、order 时，只重建变化的 composition item；结构改变、公开值修改、历史不可信、资源改变走安全回退。可见命令、stage 引用及 glyph quad 的最终提交仍允许 O(V)/O(G)，不会把节点更新变成逐节点 draw call。

字形缓存只整形/投影变化文字，通过稳定 item→glyph slot 更新 hash 叶子。容量先预检再发布；空/非空字形结构变化可重建 hash 树并计数。完整回退建立一次可见 fragment 索引，移除了每个变化 group 再搜索全部 siblings 的潜在平方级工作。避免先克隆完整 quad 数组再清空，缓存超限/无文字路径释放对应索引身份。

悬停/按下/焦点样式、反馈动画及受影响后代通过局部派生节点进入同一绘制链。未产生反馈样式/变换时复用已资格化基础画面；基础 document/layout、字体、atlas、theme、presentation 的身份均参与判断。反馈索引以 Weak 保存源身份，Player 调度器在已安全预检的局部编辑前释放反馈源产品，避免内部旧画面迫使整个 prepared Document COW。外部保留旧帧仍触发正确 COW；失败恢复和资源失效继续保留。Editor 未接入这次可选反馈缓存交接，不能声称它同样消除源 COW。

复用 361 的 UiVertexStream chunk、projection delta、部分上传及有界 GPU 驻留策略；未重写上传协议、增加新 Canvas 模型、共享变换或离屏缓存。上传新增两类原因计数：同 stream 无可靠基线，以及没有 resident（冷启动/淘汰/后端重建）。跳版本归前者；反序列化的新 stream 无 resident 归后者。原因描述的是实际 owner 分支，不伪称已经逐项区分设备丢失、淘汰和新流。

## 工作量与计时口径

| 字段/阶段 | 实际范围 |
| --- | --- |
| production_exchange_diff_ns | producer.resolve 整个调用及 active binding path 比较；包含已有编码、跨模块交换与解码，暂为合并区间 |
| prepare_style_preflight_ns | scheduler 安全预检及 Presenter 绑定/主题/viewport 准备，包含失败/回退 |
| measure_arrange_ns | source 配置及真实 solver 求解；资源或布局依赖可以扩大范围 |
| transform_clip_finalize_ns | Translation、最终几何/裁剪、命中索引 journal 发布及最终段落；输入查询另见下面区间 |
| draw_projection_glyph_ns | 绘制提取、composition 更新和 glyph 构建 |
| feedback_cpu_ns | 完整反馈调用，包括样式、动画和反馈画面缓存命中 |
| input_dispatch_ime_ns | 指针映射、输入 dispatch/命中查询；真实连续窗口还含平台 IME 请求 |
| projection.cpu_ns | Renderer UiProjection owner 整个调用，包括命中、回退、批次准备；属于 render submit |
| cpu_draw_buffer_prepare_ns | 所有 UI 与 world draw buffer 准备/queue writes 的 CPU 区间，属于 render submit；不是纯 UI 上传时间或 GPU 时间 |
| GPU | 复用现有显式 timestamp capture 与原始 GPU samples；未取得时保持缺失/不支持，不填 0 |
| preparation_layout_geometry | 累积 owner 工作量的逐帧差值；真实 solve 才累加 layout visited/measure/source loaded，避免重复上一帧 last_stats |
| full_prepare_count/node_count | 全量准备发生次数及输入规模，显式暴露全树回退；不代表内部每一次节点读 |
| active_binding_paths_compared / paragraph_preflight_nodes_visited | Replace 的真实路径比较，以及段落安全预检进入节点次数 |
| drawing.nodes_visited/items_visited/text_items_visited | 绘制变化节点、composition 预检/回退及字形更新工作集；不含可见引用提交 |
| command_refs_submitted / quad_refs_submitted / item_refs_copied | 可见缓存命令/quad 引用提交以及变化 stage 的引用数组 COW；command_refs 不含随后生成的 scrollbar 命令 |
| glyph_hash_fragments_visited / structure_rebuilds | hash owner 处理的 fragment 位置数量及实际结构重建次数，包含完整回退 |
| built/reused/copy | 对应对象/片段 owner 的逻辑重建、判定复用和源/snapshot复制；未进入比较的重提交流量由 refs 单独体现 |
| uploaded | UI 顶点实际 queue write / buffer create 的字节和次数，不包含字体/纹理上传 |

`allocated` 的明确豁免：本 Gate 不引入进程 allocator hook、malloc 次数或全进程堆字节追踪。prepared 节点、绘制 payload、cache miss 和引用复制分别报告逻辑对象；旧 `tracked_cache_allocation_events` 是逻辑重建/cache miss 代理，不能解释为 malloc。所有区间包含对应 owner 的实际分配成本，不宣称零堆分配。生命周期内存与三关 Release 峰值仍由 E 验收。

保留原完整 CPU/AUI/update/render-submit/present-wait 边界，原始逐帧附 warmup/sampled 标签和工作量差值；不相加各分段 P95。未分类余项为 `input_ime_schedule_other_ns`；分段超出原 AUI 总区间时 `aui_intervals_consistent=false`，不通过缩短总区间隐藏异常。surface acquire 失败撤回该未完成帧的 AUI 相位，避免数组错位；重试带来的累计工作异常会保留一致性标志，E 应检查采样有效性。

测量仅显式 performance run 开启；Off 不读取新增区间时钟、不输出 raw CPU JSON。Renderer 遥测目前适用 inline dispatch；专用线程返回 None/setter false，不能把缺失当作零开销。保持 typed 接口、资产 schema、SDK/wire/ABI 不变。

## 红测、首因及修复

- 最初单节点变化仍访问两个节点：绘制按 changed slots 直接迭代后通过；400/1k/10k Rect consumer 同步要求只访问一个绘制节点/item。
- 文字夹具误写 Button.Text，SDK 正确返回 WrongNodeType（slot 1/Text）；改为独立 Text 的合法写入，不扩大按钮权限。两次编译中的 LayoutSpec.participation / Dimension.Px 是夹具字段拼写错误，改用 SlotSpec/Fixed。
- 原文字夹具参与自动布局，一处内容改变引起 399 个最终绘制更新；固定位置/明确尺寸 OutOfFlow 夹具后，单处文字/平移只进入一个基础节点，并与 fresh Document/Layout/Composition/Glyph 比较。Flow/content 的真实依赖传播仍保留。
- neutral 基础复用最初漏掉 atlas 身份，旧 atlas COW 回归红测；补齐全部资源身份后通过。旧 E7、反馈失效夹具要求 neutral 强制重建，与去掉冗余反馈的合同冲突；改为非 neutral 悬停，保留缓存边界、资源、公开 COW、scope/reset 断言。
- visual consumer 的空字体夹具放入文字，首因是 FontBundleMissing，draw_items=[]；该用例验证背景/前景样式，移除无字库的文字输入，仍严格检查 hover 两种 paint 以及 layout 不变。真实字体整形由 paragraph/文字专项覆盖。
- Player 旧 UI 编辑红测：prepared_document_nodes_copied=1003，预期 0；原因是 legacy 误走 C2 段落预检，不能安全释放旧内部帧。按实际 schema 路由后 v2/C2 单叶零复制和外部旧帧 COW 都通过。旧绑定用例要求全量准备，改为局部准备且只重建一个绑定节点。
- viewport/theme 用例修改 package document 却继续传旧 mounted instance，期望 rebuild 3 实际 2；修改夹具使 package 成为该测试的源，保持 DPI/尺寸、A→B→A、主题切换及命中次数断言；不让 package 绕过常驻实例源。
- 原始逐帧测试验证累积→差值、warmup/sample、完整区间、输入/反馈/上传计数、缺失 projection、区间溢出显式标志及 Off 无 raw report。

可复现首次 integration/Player 失败及终态原始输出保存在 [logs](logs)。早期 owner 的断言值、SDK 错误及修复在以上保留，不能用退出码摘要代替首因。
