## 失败与最小修复

坦克守卫战的补偿前包配置 `960×832 / contain`；原包 150 帧、约 7.39 秒复现截图 1501×1041 铺满窗口，没有应有的左右约 150 像素边带。源码中内容矩形已正确计算，但 Windows 正式 Project Runtime 提交遗漏矩形，调用不设置内容 viewport 的 GPU 接口；截图回读也遗漏矩形。Android 原有提交已经使用带矩形接口。

只修改两个既有 owner 文件：

- `rust/crates/runtime_player_winit/src/lib.rs`：正式 Project Runtime 各平台统一使用既有 `execute_plan_to_surface_view_in_rect`；普通与语义截图传递同一内容矩形；旧无共享 presentation 的路径维持 None。新增真实 GPU 截图与指针映射回归。
- `rust/crates/engine_runtime/src/wgpu_backend.rs`：将既有 `render_plan_to_rgba_bytes_with_rect` 开放给 Player，不改变底层缩放数学和渲染逻辑。

不修改项目补偿、AUI 布局/顶点数学、schema、游戏玩法、安装配置和发布包。实施预算为一次局部编译加秒级诊断；验证范围为共享 GPU 回读与直接 Player consumer。复用原包失败和四条件源码探针，不重新开发游戏或运行全 workspace。
