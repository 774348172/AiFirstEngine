## 最小修复与修改归属

1. 主线 `web/showcase/{index.html,showcase.js,showcase.css}` 增加预览弹窗、截图切换、缺封面样例及运行/预览入口。作品数据由本轮 `verified-games.json` 合入交付 `games.json`，模板本身仍可复用。
2. `web/player/index.html` 品牌改为原点；`player.js` 根据本包声明的按键绑定兼容 Left/ArrowLeft，避免重复动作。Rust panic 后先断开 Player 引用再尽力清理，使首错保留，页面显示重载按钮。旧 Brotato02 用作一次负例，见 `panic-error-page-fixed.png`。
3. B 独占的 `runtime_player_web/src/lib.rs` 使用 logical GameView 的 target extent 计算 AUI viewport，消除 physical surface/letterbox 二次缩放。先在独立375快照验修，所有13个新二维候选最终 WASM 均消费该修复；验证后精确复制该文件到主线，未接触 A 路共享 owner。
4. Web 独立项目副本中，Brotato/PVZ/合字/像素的原生 FPS `Instant` 采样只在 native 编译，固定 Tick 玩法保留；Brotato和像素的真实首错已保存。坦克的旧手动横轴补偿在 Web 副本还原为单位缩放，避免与 GameView contain 重复补偿。
5. 早期塔防的 `linearRepeat` 旧贴图键在 Web 副本改为 `linear:linear:repeat:repeat`，保持线性过滤和 Repeat 语义，修复 `InvalidAssetPayload at texture.payload (AssetDecode)`；不是降低资源校验或改成 Clamp。
6. 激光 Web 副本字体子集保留文本资产与项目源码全部可用码点及 ASCII，10.56MB→44,480bytes/222glyphs；元数据哈希更新。准备阶段超时后有界重试成功116秒，但没有据此断言字体是超时唯一原因。后续真实运行仍失败，未晋升试玩。

原游戏源码、V0.0.5冻结内容、SDK/schema/World/session和原生后端均不由本轮修改；未安装、未改公共能力合同、未删除粒子/音频功能来换取可玩。三个 run-owned 项目文件仅在导出后做了 rustfmt 排版，确切编译前版本保留在 `export-consumed/`；格式变化未冒充已重新导出的新 sourceDigest。

- 13 个新二维候选各完成原 exporter 准备、静态 glue 生成、独立 WASM Release 构建与 bindgen；最终13项构建exit0。11项新项目在浏览器通过，加上复用的lights为12项运行入口。两项粒子失败保留首错，不计通过。
- 坦克重建遇到旧 release ABI 产物类型冲突，保存 `tank-viewport-first-abi-error.log`，仅清理375 Release target的 glue/Web consumer，重建成功，未清除全局缓存。
- 6 个受影响 Rust 文件使用 edition2021、skip_children 的定向fmt通过；两份 JavaScript Node语法检查通过。没有为一处 Web viewport 修复运行无关 native/全workspace/性能资格。
- 首页实测17卡片、12运行/5预览、无横向溢出或已加载坏图。真实iframe进入、暂停、继续、重开、关闭、iframe移除与回焦通过；预览第二图切换、隐藏独立运行链接、Esc关闭通过。见 `gallery-play-final.png`、`gallery-preview-final.png`、`homepage-final.png`。

- lights的原WASM/包不重编；新平台壳与画廊组合单独验证。主线Web文件同步仅声明源码接入，不冒称A路在途主线整体已编译/已安装。

## 延期能力与退出

Web v1 导出器对3D/Spine明确拒绝，三个3D项目按能力边界保留预览。激光/粒子的首错与 `engine_render_native/src/particle_gpu.rs`、`particle_render.rs` 中同步 `pollster::block_on(device.pop_error_scope())` 路径一致；同步阻塞不适合浏览器事件循环。本轮不改 A 路原生后端，不删除 error scope 或省略粒子。后续需独立设计异步管线适配及真实粒子验收，不能把本轮成功编译冒称该能力可用。

网页预览暂不含音效，土豆存档不持久化；Switch是早期纯文字样例，早期塔防小屏建议全屏。未授手机/其它浏览器/全平台资格，也未证明所有游戏全关卡规则与桌面版一致。

本轮声明的画廊接入、逐项兼容性结论和通过项试玩出口已闭合，施工归档并释放B。5项完整网页支持仍待续；374仍保留partial和成果，不在本轮自动恢复。A路371 S3按其原授权继续。最终时间、服务及无本路构建后台见本轮 `closeout.json`。
